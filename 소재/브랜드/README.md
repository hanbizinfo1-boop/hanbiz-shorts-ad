# 한비즈 브랜드 소재 — 여기에 넣어 주세요

브랜딩 모션(로고 애니·브랜드 카드·엔딩 CTA, `references/motion-typo.md` 카드 C)에 쓴다. **로고는 새로 그리지 않고 이 파일을 그대로 쓴다.**
이미지·글꼴 파일은 git 에 올라가지 않는다(`.gitignore`). 이 README 와 색표(`colors.json`)만 커밋된다.

| 넣을 것 | 파일 이름 예 | 형식 |
|---|---|---|
| 로고(가로형) | `logo_horizontal.png` · `.svg` · `.ai` | **배경 투명** PNG(가로 2000px 이상) 또는 SVG/AI |
| 로고(심볼만) | `logo_symbol.png` | 배경 투명 |
| 로고(흰색 반전판, 있으면) | `logo_white.png` | 어두운 배경용 |
| 브랜드 색 | `colors.json` 또는 아무 메모 | 주색·보조색·강조색 hex(예: `#1A3C8B`) — 모르시면 로고에서 뽑아 시안으로 드린다 |
| 브랜드 글꼴(있으면) | `fonts/…ttf·otf` | 상업 사용 가능한 라이선스인지 함께 |
| 브랜드 가이드(있으면) | `guide.pdf` | 여백·금지 사용 예 |
| 캐릭터·마스코트(있으면) | `mascot_*.png` | 배경 투명 |

받은 뒤 할 일(설계자): 파일 목록·해상도 확인 → 색표 `colors.json` 정리 → `motion-typo.md` 카드 C «필요한 것» 칸 갱신 → 브랜드 오프닝 시안.
