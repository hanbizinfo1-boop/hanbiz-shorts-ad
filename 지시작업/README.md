## 병목 피하기

- 무거운 렌더(`html_motion.py`·`edit_render.py`)는 다른 세션(빡이사-롱폼·숏폼자동화 등) 렌더와 겹치면 둘 다 느려진다 — `--workers 1~2` 로 돌린다.
- **바깥 폴더 의존(10-15)**: `tools/story_fx.py` 는 `C:/Users/user/Desktop/숏폼자동화/tools/caption_fx.py`·`ref_caption.py` 를 import 만 한다(읽기 전용). 그쪽 세션이 고치면 이쪽 결과가 바뀔 수 있다 — 다시 만들기 전에 결과 프레임을 눈으로 본다. 오래 쓸 거면 사본을 `지시작업/tools/` 로 들여온다(사장님 확인 뒤).
- **settings.json·hook 은 세션이 직접 못 쓴다(10-15)**: 안전 검사(Self-Modification)에 막힌다. 사장님이 프롬프트에 `! <명령>` 으로 실행할 명령을 만들어 드린다.
- Codex(`codex-run.ps1`)는 세션끼리도 병렬 금지 — 다른 세션이 Codex 를 돌리는 중이면(루트 `_tmp/codex/` 최신 로그로 확인) 기다린다. 프롬프트의 복사 대상 경로는 `지시작업/` 아래로 지정한다.
- 유료 생성(Kling·힉스필드)은 사장님 지시 건만 — 크레딧은 두 세션이 같이 쓴다.
- 커밋은 사장님 요청 때만, **이 폴더 경로만** 골라 커밋한다(`git add 지시작업/`).
