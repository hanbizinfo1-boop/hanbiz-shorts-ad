## 3. 만드는 흐름 (실제 명령)

```
python 지시작업/tools/ad_build.py prep        # 목소리·자막(V4+V5)·SRT·단어 시각·a_times.js
  ↓ 장면 HTML(지시작업/tools/scenes/*.html, seek(t)) — 소재는 지시작업/소재/
AD_VER=meta2 python 지시작업/tools/snap.py --scene 지시작업/tools/scenes/a_direct_meta2.html --times … --out 지시작업/_tmp/look/x.jpg   # 스토리보드(사람+자막+장면 정지 화면)
  ↓
bash 지시작업/tools/rebuild_meta2.sh          # 장면 렌더 → 배치표 → 미리보기 → XML 대조 → _새판 교체 → 효과음 점검
bash 지시작업/tools/rebuild_meta2_sound.sh    # 소리만 고칠 때(장면 MOV 그대로, 수 분)
```

- 장면 렌더(메타v2 판): `tools/html_motion.py --alpha --fps 30 --workers 2 --sub 3` (약 15분 — 메타v2 는 30fps 판. **4번·7번 사장님 시퀀스는 59.94**, 아래 «4번·7번식»). `data-box` 겹침 ERROR가 나면 멈춘다. 일부러 겹치는 판들은 `data-box-group="layer"`로 묶는다.
- 조립: `ad_build.py plan`(효과음 역할표 `ROLES` · 들리는 시각 보정 `NUDGE` · 클로즈업 `CLOSEUP`) → `tools/edit_render.py`(규칙 점검 · −14 LUFS) → `tools/edit_xml.py`(XML + media + PSNR·소리 어긋남 대조)
- 납품 교체: `_새판/`에 만든 뒤 `tools/deliver_swap.py`로 바꿔 끼운다. 사장님 프리미어가 끊기지 않는다.
- 판 바꾸기: `AD_VER` 환경변수(`meta2` = 지금 판)로 SRC·자막 y·출력 폴더를 바꾼다. 새 판을 만들면 `ad_build.py`에 분기를 하나 더 두고 `rebuild_<판>.sh`를 만든다.

## 5. 효과음 — 이번에 배운 것

> **기준은 `.claude/skills/shorts-ad/references/sfx.md` 맨 위 «사장님 의도 — 세 저장소 피드백 통합(10-19)».** 아래와 다르면 그쪽이 이긴다.

- 역할마다 파일 이름을 고정한다(`ROLES`: 파일, 맞춤 기준 onset/peak, 목소리 대비 dB, 길이 상한).
- **끊겨 들리면 자르지 말고 원래 짧은 파일로 바꾼다.** 겹침을 피하려 0.84초 휙을 0.45초에서 잘랐더니 «끊긴다» 반려를 받았다. 자연 0.32초 sweep로 바꾸니 해결됐다. 탭도 0.25초에서 자르지 않고 0.1초짜리 딸깍으로 바꿨다.
- 계속 움직이는 숫자(실시간 소진)는 짧은 소리 한 번이 아니라 **움직이는 내내 이어지는 굴림**을 깐다(`소재/효과음/카운터_굴림_길게.wav`, A·B·A로 이어 붙인 2.15초).
- «소리가 빨리 나온다» → 들리는 시각을 재서(`지시작업/tools/sfxchk.py`) 계기 시각을 옮긴다(`NUDGE`, 계기 시각).
- 점검: `python 지시작업/tools/sfxchk.py <납품> <배치표>`로 낱개 wav 실측 겹침·밀림을 확인한다. 밀림이 ±34ms를 넘으면 NUDGE로 고친다(~~2프레임~~ — fps마다 달라짐, `sfx.md` 결정표 ⑥).
- 소리는 귀로 못 들었으면 «못 들었다»고 보고한다.
- 청음본은 먼저 드리지 않는다. 같은 자리 소리를 반려하셨는데 다음 후보가 흐릴 때만 그 구간 A~F 청음본 하나(10-20 4번 «c»).
- 사진이 주인공인 장면은 훅·휙 대신 셔터·종이 소리(10-21).
