# 병행작업 — 별도 세션 전용 작업 폴더 (10-12)

사장님 지시(10-12): «이 세션은 지금 작업중인 다른세션이랑 독립적으로 병목이나 충돌현상없이 별도 폴더를 하나 만들어서 진행한다»

같은 저장소에서 다른 세션(3안 타이포 → 기존 방식 자료 설명 구간)이 돌고 있다. 이 폴더의 세션은 그쪽과 파일을 함께 쓰지 않는다.

## 쓰는 곳 / 읽기만 하는 곳

| 구분 | 경로 | 이 세션 |
|---|---|---|
| 작업 기록 | `병행작업/기록/작업기록.md` | **쓴다** (루트 `기록/작업기록.md` 는 읽기만) |
| 납품 | `병행작업/납품/` | **쓴다** — 작업이 끝나면 이 폴더를 탐색기로 연다 |
| 소재 | `병행작업/소재/` | **쓴다** (루트 `소재/` 는 읽기만 — 효과음 라이브러리·브랜드·견본 참조) |
| 장면 도구 | `병행작업/tools/` | **쓴다** — 루트 `tools/` 는 import·실행만, 수정 금지 |
| 임시·중간 렌더 | `병행작업/_tmp/` | **쓴다** — 렌더 도구에 `--out` 으로 이 경로를 준다 |
| 규칙·스킬 | `.claude/skills/shorts-ad/`, `CLAUDE.md`, 루트 `.gitignore` | **읽기만** |

## 규칙을 새로 얻으면

10-13 첫 이관 완료: 대본·문구 규칙은 이제 `.claude/skills/shorts-ad/references/copy.md`(+ checklist F표 · `python tools/rule_check.py --copy <대본.txt>`)가 기준이다 — 대본을 쓰기 전에 연다.

스킬 문서(`references/`, `checklist.md`, `feedback-log.md`)를 바로 고치지 않는다(다른 세션과 같은 파일). 대신 `기록/작업기록.md` 의 «스킬 반영 대기» 칸에 **사장님 원문 + 규칙 한 줄 + 점검표 한 줄**을 적어 두고, 두 세션이 겹치지 않을 때 한 번에 옮긴다.

## 병목 피하기

- 무거운 렌더(`html_motion.py` 등)는 다른 세션 렌더와 겹치면 둘 다 느려진다 — `--workers 1~2` 로 돌린다.
- Codex(`codex-run.ps1`) 는 세션끼리도 병렬 금지 — 다른 세션이 Codex 를 돌리는 중이면 기다린다. 로그는 루트 `_tmp/codex/` 로 가므로 프롬프트에 복사 대상 경로를 `병행작업/` 아래로 지정한다.
- 커밋은 사장님 요청 때만, 이 폴더 경로만 골라 커밋한다.
