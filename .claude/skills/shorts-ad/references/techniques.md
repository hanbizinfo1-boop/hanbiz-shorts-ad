# 기법 카탈로그 — 한 화면에서 모든 기법을 보고 고른다

이 표 하나로 «이 말에는 어떤 기법을 쓰나 → 본보기 코드는 어디 → 사장님이 통과/반려한 요점 → 상세는 어느 문서 몇 장»을 찾는다. 세부를 다 읽기 전에 **먼저 여기서 후보를 고르고**, 고른 기법의 상세 문서만 연다(컨텍스트 절약).
**범례**: 통과 = 사장님이 «통과/좋아/오케이» 하신 것. **검수 대기 = 10-08 제작, 사장님 반응 없음 — 통과로 읽지 않는다.** 본보기 «없음» = 이 폴더에 코드를 옮기지 않았다(기법은 상세 문서에 서술). 본보기는 모두 `tools/examples/`(실행 보장 없음, «이런 식으로 짠다»를 본다).

## 고르는 법 5줄 (SKILL 3장 1번 구도 결정 요약)

1. **그 말이 실제로 일어나는 자리를 구도로 한다.** 설정·버튼 → 실제 설정 화면에 값을 넣는 느낌(녹화 확대 + 타자) · 개념 비교 → 비교 판(쪽마다 색 하나, **연달아 금지**) · 과정·알고리즘 → 의인화·모션 · 보는 사람 시점 → 휴대폰 · 일상 상황 → 2D 애니 · 현실 공간·사람 → AI 영상.
2. **직전 통과 틀을 복붙하지 않는다** — 휴대폰·비교 판은 기본값이 아니다(08 반려). 한 편 안에서 같은 기법·같은 전환이 바로 연달아 붙지 않게 사이에 다른 움직임을 둔다.
3. **그림은 Codex 가 먼저**(유료 영상화 전에 시작프레임·마스터피스·레퍼런스·시안은 전부 Codex). 도형으로 사물을 흉내 내지 않는다. 한글은 AI 에 맡기지 않는다(`design-paths.md` 핵심).
4. **화면 글은 말 따라 쓰기 금지**(말을 받치는 개념어), «» 따옴표 대사 금지, 밋밋한 아이콘 카드 대신 캐릭터·말풍선. 새 요소는 혼자 0.6초 이상.
5. 이 폴더의 주 유형은 **T2(소재 몽타주) · T3(AI 영상 중심)**(`workflow.md`). T1(말하는 사람 위 얹기)용 기법(반반·노트·녹화 확대)은 사장님 프리미어 초안 위에 얹을 때만 쓴다. 한 편 안에서 기법이 섞이면 컷마다 해당 행을 본다.
