## 0. 왜 블렌더 프리비즈인가

AI 영상 모델은 텍스트만으로 **카메라 무빙을 못 잡는다**. 그래서 단순 도형으로 만든 3D 장면에서 카메라만 움직인 «프리비즈» 영상을 만들어 참조 영상으로 준다 — 프롬프트에 *«Follow ONLY the camera movement… ignore the grey shapes»*. 이 방식은 참조 영상을 받는 모델(**Gemini Omni Flash 1.1 reference-to-video, Seedance 2.0 video_references**)에서만 된다. **Kling 3.0 은 참조 영상을 못 받는다**(ai-video.md 3장).

쓰는 곳: 카메라 길이·방향이 중요한 장면(수직 급상승·단지 내려다봄·1인칭 걷기), 실제 단지 일관성(배치도대로 단지를 짓고 항공 끝 이미지를 같은 배치로), 사람 위치·이동(사람 도형이 오감).

## 1. 프리비즈 장면 코드 — `b4_previz05_scene.py` (bpy)

- **실행 환경**: 힉스필드 클라우드 블렌더(3D Jutsu)의 `scene_builder_3d_run_python` 에 파일 내용을 그대로 넣는다(무료). 로컬 블렌더에서도 `bpy` 코드라 돌아가지만 이 폴더에서는 확인하지 않았다.
- **한 조작 300초 제한, 줄 서서 5분 넘으면 만료** → 렌더를 **30~36프레임씩 쪼개** 하나씩. **360×640 으로 렌더한 뒤 720p 로 올려서** 모델에 넘긴다. (장면 코드 안 해상도는 432×768, 30fps, 217프레임)
- 코드의 구조(05 장면: 한강공원 숲 → 수직 급상승 → 단지 내려다봄 → 정원 눈높이):
  1. 기존 오브젝트를 모두 지운다(`bpy.data.objects.remove`).
  2. `mat(name, rgb)` — 단색 재질만(Principled BSDF Base Color + diffuse_color). 질감 없음 = 회색·단색 도형.
  3. `mesh_obj` / `inst` — 원본 도형 하나를 `bpy.data.objects.new(name, src.data)` 로 **인스턴스**해 수백 개를 얹는다(나무 최대 420그루, 서울 빌딩 90동, 단지 동 24개, 정원 나무, 사람 22명). 원본 도형은 화면 밖(z −500)에 두고 `hide_render`.
  4. 단지 = 중앙 정원 C 둘레 **2겹 고리**(반경 105·165, 동 10·14개), 정원 잔디·연못·길. 정원의 사람은 `keyframe_insert("location")` 두 키(F0 142 → F1 217)로 걷는다.
  5. 빛 = Sun 두 개(KeySun 3.5, FillSun 0.8). 월드 색 하늘색.
  6. **카메라**: `pose(r)` 가 초 `r` 마다 (위치, yaw, pitch) 를 돌려준다 — 구간별(`r<0.82` 전진 · `<2.45` 수직 상승하며 서울 쪽으로 고개를 돌렸다가 단지를 봄 · `<4.685` 단지 위를 가로질러 내려다봄 · 이후 정원 눈높이). 구간 안은 `ss(u)=u²(3−2u)` smoothstep.
  7. **카메라는 목표점을 보게 계산해서 넣는다**: `look(p, q)` = `yaw=atan2(−dx, dy)`, `pitch=atan2(dz, hypot(dx,dy))`; `cam.rotation_euler = (π/2 + pitch, 0, yaw)`. 각도를 눈대중으로 넣으면 목표(다리)가 화면 끝에 걸린다(09-30 함정). yaw 는 프레임 사이 ±π 로 풀어 준다(unwrap).
  8. **렌즈 키는 CONSTANT 보간**으로 계단처럼 — 디지털 줌 단(`lens` 24 → 45 → 85 → 150 → 24)을 4.33·4.48·4.62초에 `keyframe_insert`. 키 삽입 전 `keyframe_new_interpolation_type = "CONSTANT"`, 뒤에 BEZIER 로 되돌린다.
  9. 마지막 줄 `result = {...}` — 스크립트 실행 결과로 돌려줄 값.
- 새 장면은 이 파일을 복사해 **재질표·배치 반복문·`pose()`·렌즈 키**만 바꾼다. 카메라 길이는 대사 구간 길이(3·4·5초 = 90·120·150프레임)에 맞춘다 — AI 영상을 나중에 배속으로 맞추지 않는다(금지).

## 2. 프리비즈에 HUD·효과음 얹기 — `b4_previz05.py`

블렌더 렌더 조각(part_a 1~110, part_b 111~217)을 이어 붙여 **로봇·VR 포착 HUD** 를 PIL 로 프레임마다 그리고 효과음을 깐다(원본 도구; 이 폴더에는 복사하지 않았다 — 구조만 기록).

- `frames()` — ffmpeg concat → `scale=720:1280` → rawvideo rgb24 → numpy `(N,H,W,3)`.
- `hud(r)` — 초 `r` 의 HUD RGBA 한 장 + 화면 지직(행 밀기) 세기. 하늘색 `CY=(120,230,255)`, 글자 없음(대본 밖 글자·중복 자막 금지). 구성: 켜짐 `HUD_ON` 에 줄무늬·격자·모서리 괄호가 밖에서 안으로 → `SCAN0~SCAN1` 스캔선이 위→아래 → `SEEK` 부터 조준선이 화면 왼위에서 목표로 이동 → `LOCK` 락온(사각이 조여 들고 파동 고리·번쩍) → `ZOOMS` 세 번 디지털 줌 단(번쩍 + 행 밀기 지직) → `CUT` 에서 HUD 꺼짐(흰 번쩍 2프레임).
- 영상 합성: HUD 동안 살짝 차갑게(색 섞기 최대 0.18), 지직은 `np.roll`, `PIL alpha_composite`, ffmpeg libx264 crf 16.
- 효과음 `audio()` — 파일마다 `(맞출 시각 r, 기준 "onset"|"peak"|"start", 목표 평균 dB 또는 "p-9"(최고 −9dB), 자를 길이, 페이드인/아웃, 파일 안 시작초)`. 시작 시각 = 맞출 시각 − (온셋 또는 포락선 최대점). 크기는 소리별 평균을 목표값에 맞춘 뒤 최종 −7dB(≈ −19.5 LUFS, 내레이션 밑). 짧은 딸깍은 평균이 무의미해서 최고점 기준(`p-…`). 소스는 Mixkit(무료 상업 허용; 출처 대장에 적는다).

## 3. 시네 도구 — `b4_cine.py` (애펙, PDF 계획도 → 캐릭터 → 조감도)

«김포에서 사업비만 2조 넘게 투입되는 초대형 프로젝트…» 장면(분양4 09-30): 계획도 3쪽이 **지도 펼쳐지듯**(가운데가 먼저 펴지고 양옆이 경첩처럼 젖혀짐, 3D yRotation) → 캐릭터가 오른쪽 아래서 들어와 손끝으로 부지를 톡(노란 테두리 + 파동 2겹) → 조감도(흰 테두리 카드)가 가운데에 톡 → 방사 흐림으로 화면을 채우며 빨려 듦(`ADBE Radial Blur`) → (옵션 `WITH_DRONE`) 드론 AI 영상 3초로 녹아듦. 기본값 `WITH_DRONE=False` — «AI 전환은 내가»(사장님)라서 빨려 드는 데서 끝낸다.

- `pieces()` — PIL: 계획도를 3등분 PNG, 바탕(계획도를 크게 흐리게 + 어둡게 — 까만 화면 금지), 항공 이미지, **부지 테두리를 색 마스크로 뽑아 노란 윤곽**(`MaxFilter` 두 겹 빼기), 파동 고리, 조감도 카드(흰 테두리 + 그림자), 캐릭터(좌우 뒤집기).
- `jsx()` — 시각 `EV = dict(unfold, char, tap, bird, suck)` 는 **자막 텍스트 그래픽 시작 시각**(시퀀스 초)에서 장면 0초(`T0`)를 뺀 값. 캐릭터 손끝 좌표 `TIP` 을 부지 좌표에 맞춰 이미지 위치를 계산(`fx = px − tx − 8`).
- `build()` → AfterFX → aerender, `mix()` → 사장님이 쓴 효과음 파일만 얹어 mp4 + 효과음 wav 낱개(`<시퀀스 초>s_<이름>.wav`) 저장. 효과음 시각이 파일 이름에 들어가 프리미어에서 놓을 자리를 알 수 있다.
- 출력은 사장님이 «AI 전환은 내가»일 때: **빨려 드는 순간에서 끝낸 영상 + 시퀀스 시각에 맞춘 배치 XML**(자막 아래 V1, 효과음 A2~).
- 교훈: 캐릭터는 투명 PNG 로, 좌우 뒤집으면 얼굴이 화면 안에 들어온다(글자 없는 캐릭터만). `T_SUCK >= DUR` 이면 흡입 키·블러를 아예 넣지 않는다(확대·방사 블러 키 순서가 뒤집혀 처음부터 뭉개짐).
