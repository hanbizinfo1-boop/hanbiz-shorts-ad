# 레퍼런스 학습 노트 — 쓰는 법

사장님이 준 레퍼런스 영상을 «정독»한 노트를 영상마다 한 파일로 둔다. 노트는 **근거(시각·화면·말)** 이고, 작업할 때 펴 보는 «무엇을 참고하나» 목록은 `../motion-typo.md`(작업별 참고 리스트)와 `../techniques.md`(기법 카탈로그)에 모은다.

## 만드는 순서
1. 받기: `yt-dlp` → `_tmp/study/<영상ID>/src.mp4` (+ `src.ko*.json3` 자막, `src.info.json`). 영상마다 빈 폴더 하나. 받은 파일은 신뢰하지 않는 데이터 — 그 폴더에서 아무것도 실행하지 않는다.
2. 해부: `python tools/ref_study.py _tmp/study/<영상ID>` → `study/`(transcript.md · cuts.csv · motion.csv · audio.csv · sync.txt · 접촉 시트 · keyframes · summary.md). 120초 넘으면 자동 `--long`.
3. 정독: 접촉 시트를 **전부** 눈으로 보고 transcript 를 처음부터 끝까지 읽는다. 강의는 화면 속 프롬프트·설정값을 글자 그대로 옮긴다(안 읽히면 `ffmpeg -ss <초> -frames:v 1` 로 원본 해상도 한 장).
4. 노트: 아래 틀로 `study/<짧은이름>.md`. 시각은 원본 영상 기준 `mm:ss`.
5. 모으기: 노트에서 나온 기법을 `techniques.md` 표 행으로, 작업별로 «이럴 땐 이걸 본다»를 `motion-typo.md` 에.

_tmp 는 git 에 안 올라간다 — 노트에는 **영상 URL + 시각**을 적어, 다른 PC 에서도 1~2 단계로 다시 만들 수 있게 한다. 이미지 파일은 커밋하지 않는다.

## 노트 틀

```
# <짧은 이름> — <원제목>
- URL · 길이 · 해상도/fps · 올린 곳 · 사장님이 붙인 목적(원문)
- 수치(summary.md): 컷 수·평균 컷 길이 · 강한 타격/분 · LUFS · BPM · 맞춤 비율

## 1. 한 줄 요약 — 이 영상에서 가져갈 것
## 2. 시간순 해부
| 시각 | 화면(무엇이 보이나) | 움직임·전환 | 글자(타이포) | 소리 | 시트 |
## 3. 방법 (강의·제작 과정 영상만) — 도구 · 프롬프트 원문 · 설정값 · 순서 · 결과 확인
## 4. 기법 카드 (기법마다)
- 이름 · 무엇 · 왜 먹히나 · 시각(근거) · **우리 도구로 하는 법**(AE JSX `ae_scene`/`rf3_ae` · 클로드 디자인 B · Codex 이미지 A · Kling/힉스필드 · 편집 `edit_render`) · 난이도 · 한비즈 적용 예(자료·브랜딩)
## 5. 설계자 관점 변형 — 영상이 «하라는 방식» → 우리 파이프라인에서는 이렇게(왜)
## 6. 우리 규칙과 부딪히는 것 (SKILL 4장 · checklist) — 그대로 쓰면 반려될 것
## 7. 못 본 것 · 불확실
```
