## 1. 한 줄 요약 — 이 영상 후반에서 가져갈 것

1. **강의의 핵심 주장은 «가챠(뽑기) 의존을 줄이는 순서»다**: 레퍼런스 → 캐릭터 시트(3면도) → 라인 드로잉 → 7요소 디렉팅 → (한 번에 전부 적어) 이미지 → 샷별 스크립트 → 영상. 그리고 영상 뒤에 **사람이 편집·사운드·색보정·모션그래픽**으로 «AI티»를 지운다. 이 순서의 앞 3분의 2(이미지·시트·샷 스크립트)가 **우리의 «무료 단계(Codex·설계자)»와 정확히 겹친다.**
2. **돈이 드는 곳은 한 군데 — 영상 생성 노드**(Seedance 2.5 480P 5초 100크레딧, 15초 300크레딧 ≈ 3,600원, 강사 환산 100크레딧 ≈ 1,200원). 강사도 **마음에 안 들어 15초를 한 번 더 뽑았다**(94:24–94:40) — 우리 규칙 «유료는 장면당 1건»과 정면으로 부딪히는 지점이다. 해법은 **강사의 말 그대로 «이미지 단계에서 끝내고, 영상은 이미지에서 시작한다»(93:46 «AI를 한 번도 안 만들어 봤으면 이미지 먼저. 영상은 무조건 이미지에서 시작»)** 를 우리 확인②로 앞당기는 것.
3. **«AI티 지우기» 4개 원칙(스타일 선택 · 샷 분할 · 완벽함 깨기 · 사람 편집/사운드)은 우리 영상미 원칙·편집 문법과 같은 방향**이라 가져오되, **수치(컷 길이·플래시 횟수)는 가져오지 않는다**(Maestro 는 말 없는 타이틀 필름, 우리는 말이 있는 광고 — `koba-maestro.md` 5장).
4. **강사 도구(Newtake 노드 캔버스·포토샵)는 모두 대체 가능**(Codex·Pillow·설계자 콘티·AE/코드) — 대체 불가는 **«2D 캐릭터 연기 영상»(Seedance 급)** 뿐이고 그것도 한 편에 1~2 덩어리만(5-3).

### 3-2. 단계 순서 (강사가 보여 준 것)
1. **레퍼런스**를 먼저 고른다(색감·스타일 레퍼런스, **내용은 달라도 됨**).
2. **캐릭터·제품 시트(3면도)** 를 만든다(실패 확률↓, 일관성).
3. 포즈·구도를 정확히 지정할 땐 **라인 드로잉**(포토샵 Find Edges)을 만든다 — 선만 참고하게 하려는 것(색·스타일 묻어남 방지, 열화 방지).
4. 이미지 프롬프트는 **7요소**로 쪼개 쓰되 **한 번에 전부** 적는다(열화 줄이기).
5. 이미지 생성 → 마음에 안 들면 재생성(가챠) → 색 같은 수정은 가능하면 **처음 프롬프트에 포함**(나노바나나 단계는 열화 1단계 추가).
6. 배경 이미지를 따로 준비.
7. 텍스트 노드에 연출 한 단락(+금지·긴장과 이완·준비 동작·스쿼시 앤 스트레치·앵글/샷 사이즈 지시)을 쓰고 **LLM 으로 «샷별 스크립트»** 를 만든다(영어로 넣는 것이 좋음).
8. 비디오 노드에 **스크립트 + 캐릭터(+시트) + 배경들**을 연결 → 모델(Seedance 2.5) → 480P·5~15초 → 3~4분 대기.
9. 결과를 보고 안 되면 재생성(네거티브·프롬프트 수정). 완성 후 **프리미어/AE 에서 편집**(좋은 부분 선택 → 컷 → 타이밍 → 사운드 → 컬러 → 모션그래픽).
- 결과 확인 방식: 화면에서 재생·스크러빙(프레임 검수 단계는 없음). 강사: 「**결과가 안 나오는 건 가챠**」(83:38, 97:39).

### 5-1. 설계자의 결론 (한 문단)
**후반 강의가 하라는 방식 = «이미지 단계에서 가챠를 줄이는 의식(레퍼런스·시트·라인·7요소·한 번에 전부) → 샷 스크립트를 LLM 에게 → 노드에 모아 Seedance 로 15초 한 덩어리 → 사람이 편집으로 AI티 제거».** 우리는 이 흐름의 **앞쪽(이미지·콘티) 전부를 무료로 가져온다**(Codex·설계자) — 이미 우리 규칙(`design-paths.md` 8장 «레퍼런스 없이 상상한 이미지는 별로»)과 같은 철학이다. **버리는 것은 «영상 생성 → 불만 → 재생성(가챠 3,600원)» 루프**(CLAUDE.md 3: 유료는 장면당 1건)와 **Newtake/힉스필드 구독·Photoshop·Astra 같은 도구 자체**(대체 가능). **가져오는 것은 K1~K11 의 «지시 방식»**, 그리고 **«생성 덩어리 1건 → 편집에서 컷 N개»(K9)** 라는 비용 구조다 — 강사 자신도 «영상 먼저 말고 이미지 먼저», «AI 아웃풋은 누구나 뽑는다, 차이는 편집·연출»이라고 말한다. 따라서 **우리가 이 강의에서 돈을 내고 얻을 것은 «2D 캐릭터 연기 영상 1~2덩어리»뿐**이고 나머지는 전부 무료로 대체된다(5-3).

```
SIZE/ANGLE  <Wide|Medium/CU|Detail|Insert|POV|Metaphor> | <low|eye|high|dutch> | <렌즈 느낌>   # K5
BEATS (≤4)  1) … 2) …                             # 동작 불릿(준비 동작이 있으면 ≥0.3 s 유지 명시)
SQUASH/STRETCH  <눌림 → 늘어남 순서와 어느 동작에서>   # 캐릭터 컷에만. UI·타이포 등장은 오버슈트 0
TENSION→RELEASE  <긴장 구간 t… → 해방 순간 t…>      # 강의 «긴장과 이완»
TRANSITION  <전 컷 → 다음 컷을 잇는 형태/움직임>      # 강의 «트랜지션:» 줄 — 매치 컷 우선
SOUND  <역할 → 파일 이름(sfx.md)>                    # 강의 «사운드:» 줄은 설명문 — 우리는 파일 이름 고정
IMPERFECTION  <비대칭 구도 | 렌즈 왜곡 | 모션블러 중 쓴 것>   # K6
DON'T  <금지 목록, 긍정형 문장으로 변환>               # 강의 네거티브 → 긍정 문장
```
- **강의와 다른 점**: ① 시간 = 단어 시각(SKILL 3장 2) ② «준비 동작 필수·스쿼시 앤 스트레치 무조건»은 **캐릭터 연기 컷에만**(영상미 원칙 3 «바운스 금지»는 UI·타이포 등장 규칙 — `design-paths.md` 4장이 마스코트 눌림·스쿼시를 이미 허용) ③ 사운드 줄은 설명문이 아니라 파일 이름 ④ 한 컷에 요소 간 간격 ≥0.6초(인지 텀) — 강의 샷 길이 1.5~4초는 말 없는 필름 기준 ⑤ 타이틀 글자(JOHNKOBA DESIGN)는 영상 모델에 시키지 않는다 — 렌더러가 그림.

### 5-5. 돈 규칙에 맞춘 순서 (강의: 생성 → 마음에 안 들면 재생성 · 우리: 무료 먼저 → 확인② → 한 번)
1. **무료 단계에서 후보를 전부 본다**: Codex 한 세션(첫 호출 약 60초 + 장당 약 21초)에 ① 캐릭터 시트 ② 7요소 스타일프레임 3안 ③ 배경 ④ T3 컷 시작프레임 후보 3안 ⑤ 스토리보드 9칸 한 장(`2d-mg-newtake.md` K7 과 같음).
2. **확인②**: 위를 사장님께. **고른 것만** 3으로.
3. **«생성 덩어리» 단위로 유료 1건씩**: 강사 방식(15초 한 덩어리 → 편집에서 컷 N개, K9)을 **«장면당 1건» 의 «장면 = 생성 덩어리 1개»로 읽을 것을 설계자 제안**(사장님 확인 필요 ☐ — 기존 정의는 «컷 장면»이었다). 15초 덩어리 1건 ≈ 300크레딧(≈3,600원)으로 Maestro 식 20~36컷을 낼 수 있는지는 **미검증**(강의에 그런 편집 결과의 «소스 길이 대비 컷 수» 데이터는 없음).
4. 렌더(글자·타이틀·엔드 카드·플래시)는 AE/HTML(무료), 후반 색·노이즈·사운드는 ffmpeg·`sfx.py`.
5. 불만 결과 → **재생성하지 않고** 원인 하나만 바꾼 다음 건을 사장님께 제안.
- 강사의 «480P 시험 + 최종» 은 쓰지 않는다. 최종 해상도 후보: 힉스필드 MCP 모델별 `get_cost` 로 720P/1080P 단가 확인 ☐.

## 7. 못 본 것 · 불확실
- **소리는 귀로 못 들었다.** 강사 말은 유튜브 자동자막(오인식 많음)과 로컬 whisper small 대조로 읽었고, 슬라이드·UI 화면과 일치하는 것만 인용했다. 숫자(1,200원·3,600원·10만 원·20만 원·AI 약 75~80 / 프리미어 10~20 / AE 5 안팎 — 번복해 불명확)는 **강사 말**이며 화면 UI 의 크레딧(⚡)과는 «100크레딧 = 1,200원»으로만 이어진다 — **원화 환산은 강사 추정**이다.
- **슬라이드 번호(x/90)**: 읽은 것만 적었다(60·62·65·68·69·73·76·77·79·80·81·82·83·85·86·87). 나머지 슬라이드 번호는 확인 못 함. 이 슬라이드 덱의 «90장»이 앞 구간과 연속인지는 앞 노트 몫.
- **데모 첫 합성 이미지(84:23)가 «무엇이 이상했는지»**는 캡처로 못 봤다(생성 완료 직후 화면이 바로 재생성으로 넘어감).
- **Seedance 2.5 15초 결과의 프레임 단위 품질**: 강의 화면 속 재생이라 480P 압축본. 타이틀 글자 정확성·선 품질은 판정 불가.
- **MiniMax H3 와 Seedance 2.5 의 우열**: 강사 말 «연출이 더 많이 들어가면 Seedance» 한 줄뿐. 직접 비교 결과 없음.
- **LLM 스크립트 샷 05~06 의 뒷부분 글자**와 «스쿼시 앤 스트레치 / 긴장과 이완 / 트랜지션 / 사운드» 줄 전체는 일부만 읽음(extra/5325~5385). 텍스트 노드 7 의 «점프 …(예방/해방?)» 부분은 글자가 작아 못 읽음.
- **프리미어 `Maestro.prproj` 안의 컷 수·전환·효과음 트랙 내용**: 한 장면(extra/4200)에서 시퀀스 이름 6개·클립 이름·트랙 구성만 읽음. 타임라인을 스크롤하지 않아 **컷 편집 상세는 못 봄**(그래서 Maestro 편집 분석은 완성본 컷 표 `cuts.csv` 와 소리 타격으로만).
- **«Maestro 0에서14.19 / 14에서 24 / 24에서…» 파일명의 뜻**은 추정(생성 구간 분할로 보임). 강사가 직접 설명하지 않음.
- **하이엔드 정도·업계 사용처**: 채팅 질문(BB, 61:16)에 강사가 한 말(약 113:30 부근 자동자막)은 「하이엔드급 회사 관련 업계 분에게 들은 바 AI 를 골자로 기존 방식이 서포트하는 사례는 거의 없다」 — 전언이라 근거 약함.
- 5-5 의 «생성 덩어리 1건 = 장면 1건» 읽기, 5-3 의 «쇼츠 한 편 1~2만 원대 상한»은 **설계 추정**이며 강의 근거가 아니다(강사의 15초 300크레딧을 곱한 산수).
- 세로 쇼츠 안전영역·글자 최소 크기·fps 는 SKILL 6장 ☐ — 5-4 틀은 자리표시.
- Codex `image_gen` 이 선화 앵커를 지키는지, 시트 한 장 3면 생성이 한 번에 되는지 — **미검증(무료 시험 가능)**.
