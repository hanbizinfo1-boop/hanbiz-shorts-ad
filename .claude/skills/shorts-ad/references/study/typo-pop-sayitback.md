## 1. 한 줄 요약 — 이 영상에서 가져갈 것
1. **한 곡 안에서 장면마다 바탕색·도형 모티프를 통째로 바꾼다**(분홍 하트 → 보라 → 연두 → 파랑 → 검정 …). 같은 문구 `say it` 가 그때마다 다른 색·방향·3D 각도로 다시 나옴. 시트 기준 색 전환 약 14번/33초.
2. **하드컷 말고도 «색 번쩍임 연타»로 전환**: 6.42~6.75초 **3프레임(60fps)마다 바탕색이 바뀌며 글자는 RGB 3층으로 갈라짐**, 27프레임 뒤 `to be` 거대 글자로 하드컷.
3. **글자 크기 대비**: 같은 장면에 `to`(화면 높이 45%) vs 작은 글자 `be/explain`(7%), 또는 `say it` 대 `if i`(약 1:2).
4. **글자가 도형을 만나 변형**(`?` 상자 → 빈 상자 → `!` → 원, `explain` → 암호 치환 `fyqmbjo`) — 글자 자체가 연출 소재.
5. **정지가 없다**: 착지 뒤에도 글자가 천천히 계속 움직임(`back` 26.2~26.5 약 0.25%/프레임 축소).

## 4. 기법 카드

### 카드 1 — 색 번쩍임 연타 전환(3프레임 × 9색)
- 무엇: 화면 형태는 거의 그대로 두고 **바탕색만 2~3프레임마다** 바꾸며 글자는 RGB 3층으로 갈라짐 → 하드컷으로 마무리. 27프레임(0.45초).
- 왜 먹히나(추측): 번쩍임이 «에너지 ↑» 신호, 마지막 컷이 도착점.
- **우리 도구로 하는 법**: `html_motion` — 장면 하나에 글자 요소 3개(`.r .g .b`), `color:#f00/#0f0/#00f; mix-blend-mode: screen; transform: translateX(±8px)`, `seek(t)` 에서 `Math.floor(t*FPS/3) % palette.length` 로 배경색 교체. 한 편에 한 번만(motion-typo 4번 «글리치 한 편 한 번»).
- 난이도 중. 한비즈 적용: 영상 중간 «반전» 직전 0.45초.

### 카드 2 — 글자 → 도형 변형(`?` → `!` → 원)
- 무엇: 글자가 도형으로 변하고(상자 squircle 흔들림 4프레임) 도형이 다음 글자를 품음.
- **우리 도구로 하는 법**: SVG `<rect rx>` 의 `rx` 를 6프레임 안에 `0→50%`(사각→원)로, 글자 교체는 1프레임 하드 교체. 흔들림은 `rotate(±3deg)` 4프레임.
- 난이도 중.

### 카드 3 — 암호 치환 텍스트
- 무엇: 같은 단어가 0.3초마다 `explain → fyqmbjo → gzrnckp → lewshpu`(알파벳 +1, +2…)로 바뀌다가 원래 단어로 복귀.
- **우리 도구로 하는 법**: JS `shift(word, k)` 로 매 `seek` 마다 텍스트 교체, 한글이면 자모 치환 대신 초성만 바꾸는 방식(`가→나→다`). 0.3초 간격 3~4번.
- 난이도 하. 한비즈 적용: «숨은 보험금» 같은 개념어가 «열리는» 느낌.

### 카드 4 — 거대 글자 → 78% 감속 착지 + 글로우
- 무엇: 화면보다 큰 글자가 8프레임에 줄어들며 글로우(블룸)를 잃고 이후 서서히 계속 축소.
- **우리 도구로 하는 법**: `transform: scale(2.4→0.95)` 8프레임 지수 감속, 이후 25프레임 `scale(0.95→0.9)`; `text-shadow: 0 0 24px rgba(255,255,255,.8)` 를 같은 8프레임에 `blur 24→8px`; `--sub 4`.
- 난이도 하.

### 카드 5 — 중앙 정사각 + 블러 복제 배경(세로 변환 구조)
- 무엇: 정사각 장면 하나를 화면 중앙에 두고 나머지는 같은 장면을 확대·블러해 채움.
- **우리 도구로 하는 법**: 1080×1920 에서 중앙 1080×1080 이 본 연출, 위·아래 420px 은 `iframe`/캔버스 복제 `transform: scale(2)` + `filter: blur(40px) brightness(.7)`. 자막 자리를 위쪽 복제 영역에 둘 수 있음(사장님 규칙은 SKILL.md 확인).
- 난이도 중.

### 카드 6 — 장면별 팔레트(바탕+글+강조)
- 무엇: 장면마다 3색 팔레트를 새로 정하고 모티프 도형도 바꿈. 같은 문구를 매번 다른 방식으로 다시 보여 줌.
- 우리 규칙의 «3색»과 **장면 안에서는 일치, 편 안에서는 불일치**(motion-typo T4 예외가 이미 있음).

## 5. 설계자 관점 변형
- 영상은 말 없이 가사 4초 간격 + 박. 우리는 말의 단어 시각. **«한 문구를 다른 방식으로 반복 연출»**(say it × 12)은 우리 CTA 반복 구간(마지막 5~8초)에만 쓰기 좋다.
- 네온 3D 구간(24~32초)은 CSS 3D 로 가능하지만 장면 점검(`html_motion` BOXES 겹침) 때문에 겹침 허용 그룹이 필요.
