## 4. 기법 카드
### 카드 1 — 키워드 카드 → 문장 카드 2박 구조
- 무엇: 판 색이 다른 두 카드를 한 쌍으로 묶는다. 앞(주황/검정, 0.33~0.6초): 단어·숫자 하나만 크게. 뒤(흰, 0.47~1.23초): 같은 단어가 들어간 완성 문장, 핵심어만 주황.
- 왜 먹히나: 앞 카드가 «무엇이 나올지» 한 단어로 던지고 뒤 카드가 답한다. 판 색 반전이 시선을 리셋한다. 한 쌍이 약 1.1~1.8초라 쇼츠 템포에 맞다.
- 시각(근거): 5.13→5.73 · 6.90→7.50 · 8.67→9.37 · 10.50→10.97 · 11.60→12.23 · 3.30→(3.77→4.10).
- **우리 도구로 하는 법**: `html_motion` 장면 1개에 카드 CSS 클래스 3종(`.o` 주황 #FE370C · `.k` 검정 · `.w` 흰) → `seek(t)` 안에서 `cards=[{t0,t1,cls,html}, ...]` 로 `display:none/flex` 전환(전환 효과 없음 = 하드컷). 한 쌍 길이는 말 단어 시각에 맞춰 설계자가 정한다(우리는 말이 있으므로). 판 색은 **브랜드 색 1 + 검정 + 흰**(3색 규칙과 정확히 일치).
- 난이도: 하. 한비즈 적용 예: «2,063개 브랜드» → 분양 «○○세대 / 입주 ○○월 / 청약 ○○일» 숫자 카드(숫자는 말에 나온 것만).

### 카드 2 — 번짐 → 정착 «톡»(스캔라인 번짐 5프레임)
- 무엇: 글자가 등장할 때 가로 스캔라인 번짐이 5~11프레임 있다가 선명해진다(크기 변화 0, 오버슈트 0). 붓글씨·카운터·«2023» 모두 같은 처리.
- 왜 먹히나: 튕김 없이 «지직» 하는 에너지로 «톡» 같은 인상. 단색판 위에서 글자만 «살아 있다».
- 시각(근거): 0.03~0.77 · 1.60~1.80 · 5.133~5.267 · 6.933~7.0 · 12.68~13.05.
- **우리 도구로 하는 법**: `html_motion` 에서 글자 `<div>` 에 SVG 필터 `feTurbulence`(baseFrequency 0.001 0.2)+`feDisplacementMap`(scale 20→0, 가로 방향만)을 걸고 `scale` 을 `seek(t)` 로 5프레임 선형 감소. 가장자리 RGB 색 번짐은 글자를 3겹(red·green·blue `mix-blend-mode: screen`, ±2px 오프셋)으로 그려 오프셋을 0 으로 수렴. `--sub 4` 서브프레임 블러는 켜지 않는다(번짐이 필터로 이미 있음). 한 편에 **1~3곳**.
- 난이도: 중. 한비즈 적용 예: 후킹 첫 카드·핵심 숫자 카드.

### 카드 3 — 가속·감속 카운터(숫자 롤링)
- 무엇: 숫자가 목표값에서 먼 값으로 시작해 감속하며 목표에 착지(11~13프레임). 첫 5프레임 번짐, 마지막 4프레임은 ±1 단위.
- 시각(근거): 5.133~5.567(2,063) · 6.933~7.333(223,986).
- **우리 도구로 하는 법**: `html_motion` `seek(t)` — `u=clamp((t-t0)/0.43,0,1); v=target-(target-start)*(1-u)**3`(ease-out cubic) → `Math.round(v).toLocaleString()`. 숫자 칸은 `font-variant-numeric: tabular-nums` + 고정 폭 컨테이너(자릿수 흔들림 방지). 앞 5프레임에 카드 2의 번짐. **숫자는 말에 나온 것만**(SKILL 4장), 업체명 ○○.
- 난이도: 하.

### 카드 4 — 블록 커서 타자
- 무엇: 줄 오른쪽 끝의 사각 블록(주황)이 줄어들며 글자를 왼쪽부터 드러낸다(10프레임, 15자).
- 시각(근거): 4.10~4.43.
- **우리 도구로 하는 법**: 문장은 전체를 그려 두고 `clip-path: inset(0 X% 0 0)` 을 100→0% 로 10프레임 이동, 같은 위치에 블록 `<div>`(폭 90→8px, 색 1개)를 따라 붙인다. 오버슈트 0.
- 난이도: 하. 한비즈 적용 예: «문의 → 카톡» 같은 CTA 문장.

### 카드 5 — 아웃라인 반복 타일 → 솔리드 1개
- 무엇: 같은 단어를 선만 있는 글자로 3×7 타일, 약 10프레임 천천히 흐르게 하다가 1프레임에 솔리드 1개로 교체.
- 왜 먹히나: 단어 «역대급»의 규모감(많다)을 반복으로 보여 주고 곧바로 하나로 압축.
- 시각(근거): 11.60~11.97.
- **우리 도구로 하는 법**: `html_motion` — 글자 `-webkit-text-stroke: 2px #fff; color: transparent` 를 CSS grid 로 3×7 배치, 행마다 `translateX` 를 `seek(t)` 로 ±30px 느리게. 교체는 `display` 토글. 3색 안.
- 난이도: 하. 한비즈 적용 예: «○○세대» «○○세대» 반복 → 한 숫자.

### 카드 6 — 도착 후 푸시 인(드리프트)
- 무엇: 하드컷으로 나타난 카드 글자가 가로 −60~−120px 흐르고 높이 +3~11% 커진다(0.4~1.2초, ease-out).
- 시각(근거): 2.07~3.27(x0 508→388) · 5.73(380→288) · 7.50(404→284, 폭 +4.8%) · 10.97(h 140→156) · 12.23(h 140→152).
- **우리 도구로 하는 법**: 글자 컨테이너 `transform: translateX(-x(t)) scale(1+s(t))`, `x(t)=120*ease_out(u)`, `s(t)=0.03~0.10*ease_out(u)`, `u=(t-t0)/(0.4~1.2)`. 오버슈트 0(ease-out cubic). 글자가 정지한 카드는 «죽어 보이지» 않는다.
- 난이도: 하. **가장 먼저 적용할 수 있는 기법** — 현재 «단색배경판에 글자만» 형식에 바로 붙는다.

## 5. 설계자 관점 변형
- **우리 쇼츠에는 «2박 구조(키워드 카드 → 문장 카드)» 와 «번짐 → 정착»·«푸시 인» 을 가져온다.** 판 색은 브랜드 색 1 + 검정 + 흰 3장으로 고정하고 판 전환 자체를 하드컷 박으로 쓴다.
- 영상은 **말이 없다**. 우리는 말(목소리)이 있으므로 한 쌍을 말 단어 시각에 맞추고 문장 카드는 말의 반복이 아닌 개념어·숫자로 쓴다(`motion-typo.md` 6번). 키워드 카드 0.33초는 한글 읽기에 짧다 → **0.6초 이상**(5번 규칙 유지).
- 세로 1080×1920 변환: 문장 카드 폭 54~73% → 세로에서는 폭 80~90%로(높이 6~8%, 두 줄 허용). 숫자 카드 높이 40% → 세로 폭 90% 제한으로 한 줄 숫자는 높이 10~12%가 한계(자릿수 많은 숫자는 두 단으로). 컬럼 마스크·블록 커서는 가로 방향이라 세로 폭에서 그대로 동작.
