## 1. 한 줄 요약 — 이 영상에서 가져갈 것
1. **«작은 글자(높이 3~4%) + 거대 콘덴스트 글자(높이 55~65%)» 동시 사용**. 한 장면에 읽는 글(작은 자막)과 보는 글(거대 장식)을 분리.
2. **거대 글자는 한 글자씩 0.17~0.19초(3~4프레임@18fps) 간격으로 들어와 줄을 만들고**, 줄 전체가 가로로 밀리거나 화면 밖으로 흐른다(`KITYAWA` 16.9~18.2).
3. **전환은 «넓은 변형» 으로**: 액체 워프(18.5~19.0, 글자가 손 모양으로 흘러내림), 아이리스(31.0 원형 와이프), 디포커스 5프레임(22.48~22.70), 픽셀 해체(27.0), 세로 줄무늬 스트레치(25.5), 1프레임 암전/흰 프레임(4.51, 22.42, 33.5).
4. **배경이 «색 면 + 질감 + 종이 단면» 으로 층이 많다**: 빨강 광택 그라데이션 + 방사선(16~) + 만화경(22.8~) + 입자 별(27.2~), 글자 뒤에 인물 사진(흑백 하프톤 + 종이 오리기 테두리)이 들어감.
5. **글자 연출 수단이 «슬라이드 인» 중심이고 튕김이 없다**(오버슈트 0, 프레임 단위로 본 8사건).

## 4. 기법 카드

### 카드 1 — 작은 글 + 거대 글 병행(15~20배 대비)
- 무엇: 읽는 글(작은 타자)과 보는 글(거대 장식)이 한 장면에 공존.
- 왜 먹히나(추측): 큰 글자가 시선을 잡고 작은 글이 정보를 준다.
- **우리 도구로 하는 법**: `html_motion` — `.giant{font:900 62vh/0.9 "HM Archivo"; font-stretch:62%; letter-spacing:-0.02em}` + `.small{font:600 3.6vh "HM Pretendard"}`. 세로 1080×1920 은 거대 글자를 **두 줄로 쌓아** 폭 100% · 높이 각 15~20%(1줄당)로. 한글은 콘덴스트 글꼴이 없으므로 `HM BlackHanSans` 400 을 `scaleX(.78)` 로 눌러 사용(글꼴 왜곡이라 설계자 판단).
- 난이도 하.

### 카드 2 — 한 글자씩 슬라이드 인으로 줄 만들기(3~4프레임 간격)
- 무엇: 거대 글자 한 개가 3~4프레임(0.17~0.19초@18fps) 간격으로 우측에서 밀려 들어와 줄이 만들어지고 줄 전체가 좌로 이동.
- **우리 도구로 하는 법**: 각 글자 `translateX(100% → 0)` 4프레임 감속 + 줄 컨테이너 `translateX(-i*글자폭)` 같은 프레임. 29.97fps 로는 5~6프레임 간격. 한글은 음절 단위 간격 0.2초.
- 난이도 중. 한비즈 적용: 핵심 키워드 4~6음절.

### 카드 3 — 디포커스 5프레임(블러 일정 → 스냅 선명)
- 무엇: 가우시안 블러 약 25px(1080 기준 추정)이 5프레임 일정 유지된 뒤 한 프레임에 선명.
- **우리 도구로 하는 법**: `filter: blur(24px)` 를 5프레임 고정 후 0. 18fps 영상이라 «스텝» 으로 보이지만 우리 29.97fps 에서는 `blur(24px)` 8프레임(0.27초) → 선명 1프레임 스냅. 전환 입구에서 장면 시작 직후.
- 난이도 하.

### 카드 4 — 1프레임 플래시/암전 프레임
- 무엇: 4.51 검정 1프레임 · 22.42 흰 1프레임 · 8.656 어두운 빨강 1프레임을 컷 사이에 삽입.
- **우리 도구로 하는 법**: 컷 사이에 `background:#fff` 한 프레임(29.97fps 에서 1프레임 = 0.033초). 효과음(쿵/클릭) 앞에 쓰기 좋다.
- 난이도 하.

### 카드 5 — 액체 워프 / 아이리스 / 픽셀 해체 / 줄무늬 스트레치
- 무엇: 글자·사진이 변형되어 다음 장면이 됨.
- **우리 도구로 하는 법**: SVG `<feTurbulence baseFrequency="0.012 0.03"/><feDisplacementMap scale="0→140">` 를 글자 요소에 적용(`filter:url(#warp)`), `seek` 에서 `scale` 을 9프레임 동안 증가. 아이리스는 `clip-path: circle(r at 50% 50%)`, 픽셀 해체는 캔버스 `ctx.imageSmoothingEnabled=false` 로 축소 → 확대(축소 비율 1/4→1/32 6프레임), 세로 스트레치는 `transform: scaleY(1→6)` + `blur(2px)`.
- 난이도 중(워프) / 하(아이리스·스트레치).

### 카드 6 — 윤곽선 거대 글자(스트로크만)
- 무엇: `KARTU` 를 빨강 스트로크만(채움 없음) 으로 높이 100% 에 한 글자씩 올림.
- **우리 도구로 하는 법**: `-webkit-text-stroke: 3px #e00; color: transparent`, 글자별 `translateY(110% → 0)` 2프레임 간격(29.97fps 에서 3프레임).
- 난이도 하.

### 카드 7 — 방사선 + 만화경 배경(글자 뒤 층)
- 무엇: 검정 바탕에 얇은 빨강 방사선(알파 20%)이 중심에서 퍼짐 / 만화경 패턴.
- **우리 도구로 하는 법**: `repeating-conic-gradient(from 0deg, rgba(224,0,0,.2) 0 .4deg, transparent .4deg 12deg)` 로 방사선, 만화경은 SVG `<pattern>` + `rotate`·`scale` 360도 천천히 회전.
- 난이도 하(방사선) / 중(만화경).

## 5. 설계자 관점 변형
- 영상은 가사 의미보다 «글자 위에서 놀기» 가 목적이라 거대 글자가 의미 전달을 가린다. 우리는 **작은 글이 정보, 거대 글은 핵심 단어 한 개** 로 줄인다.
- 종이 오리기 콜라주(하프톤 인물 + 톱니 테두리)는 Codex 이미지(흑백 하프톤)로 만들 수 있다 — 인물 얼굴 없이 손·제품·아이콘으로.
- 4:3 → 세로: 거대 글자를 두 줄 쌓기, 카드 3D 원근 배치는 세로 비율이 오히려 유리.
