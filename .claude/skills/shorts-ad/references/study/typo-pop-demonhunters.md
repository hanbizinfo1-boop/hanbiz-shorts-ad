## 1. 한 줄 요약 — 이 영상에서 가져갈 것
1. **글자가 화면의 거의 전부를 채운다**: 글자 높이 약 45~90%, 폭 약 85~95%(`WE KILLIN'` `WE BRING IT` 3프레임 안에 폭 37% → 55% → 86%). 한 줄 `NOTHING TO US` 같은 작은 글자(높이 약 5%)와 **10배 이상 크기 대비**.
2. **착지는 «아주 빠른 확대 3프레임 + 이후 서서히 계속 커짐»**. 오버슈트 0. 정착 뒤에도 4프레임에 +4%·약 8프레임 만에 화면 밖으로 잘릴 정도로 계속 확대(카메라가 밀고 들어오는 느낌).
3. **글자 뒤·앞에 캐릭터 레이어**: 3D 캐릭터가 글자 앞을 지나가거나 글자가 캐릭터 뒤로 감(알파 매트). 글자 뒤 레이어 최대 3(바탕 · 글 · 캐릭터).
4. **배경이 «색 면 4종 순환» + 실루엣**: 짙은 남색 / 분홍(핫핑크) / 라벤더 그라데이션 + 등고선 패턴 / 흰색 → 가사 줄마다 교체. 바탕만 1프레임에 바뀌고 글자는 유지되는 컷이 있음(6.675).
5. **전환은 글자 자체를 쓴다**: 거대 글자 속 창(마스크)으로 다음 장면을 보여 줌(22.13~22.30), 글자가 줄어들며 분홍 면으로 넘어감(22.68~22.80), 글자 창 안에 실루엣(43.1~44.0).

## 4. 기법 카드

### 카드 1 — 3프레임 거대 확대 + 서서히 계속 커짐
- 무엇: 단어가 1프레임에 작게 컷으로 나타나 3프레임에 폭 37 → 86% 로 커지고, 이후에도 6프레임에 +4% 더 커지다가 다음 컷(0.4초).
- 왜 먹히나(추측): 첫 3프레임이 «쿵», 이어지는 느린 확대가 «계속 다가옴».
- 시각(근거): 17.567~18.0.
- **우리 도구로 하는 법**: `html_motion` — `transform: scale(s)`, s = 0.43 → 1 를 3프레임 `1-(1-p)^3`, 이후 `1 → 1.05` 를 단어 길이(10~12프레임) 선형. `--sub 4` 로 첫 3프레임 모션블러 자동. `font-stretch`/폭: `HM Archivo` 가변(font-stretch 62%) 같은 콘덴스트 + `font-weight:900`. 세로 1080 폭에서는 두 줄(`WE` / `KILLIN'`)로 쌓아 높이 비율을 유지.
- 난이도 하. 한비즈 적용: 핵심어(숫자·혜택) 한 단어.

### 카드 2 — 글자별 세로 워터폴 → 정렬(7~9프레임)
- 무엇: 줄의 글자마다 y 오프셋이 오른쪽으로 갈수록 커졌다가 0 으로 정렬.
- **우리 도구로 하는 법**: 글자 `<span>` 에 `translateY(calc(var(--i) * 3% * (1 - ease(p))))`, p = 8프레임. 한글이면 음절 span.
- 난이도 하. 한비즈 적용: 한 줄 카피가 처음 뜰 때(오프닝).

### 카드 3 — 거대 글자 속 창(마스크 전환)
- 무엇: 화면보다 큰 글자(330%)의 획이 화면을 덮고 획 사이로 다음 장면이 보였다가 100% 로 스냅.
- **우리 도구로 하는 법**: 글자 요소 `scale(3.3)` 5프레임 → `scale(1)` 1프레임 스냅, 글자는 `background-clip:text` 또는 `mix-blend-mode:difference/multiply` 로 아래 장면과 합성. 마스크 버전 `-webkit-mask`(요소 마스크 = 큰 글자 SVG).
- 난이도 중. 한비즈 적용: 장면 전환(문제 → 해결) 1회.

### 카드 4 — 글자 창 + 실루엣 / 후광
- 무엇: 글자 안쪽이 흰 후광, 그 안에 어두운 인물 실루엣. 글자가 «빛이 나오는 창».
- **우리 도구로 하는 법**: 검정 레이어 위에 글자를 흰색으로, 실루엣 PNG 를 `mix-blend-mode: multiply` 로 글자 위에, 글자 뒤 `radial-gradient` 후광 + `filter: blur(18px)`. 실루엣은 Codex 이미지(검정 단색)로 생성 후 `<img>`.
- 난이도 중.

### 카드 5 — 글자 뒤·앞 캐릭터 레이어(깊이)
- 무엇: 3D 캐릭터가 글자 앞으로 지나감(`I'LL SHOW` 의 `O` 위, `MIRROR` 앞).
- **우리 도구로 하는 법**: 글자 레이어(z 1) → 인물 알파 PNG(z 2); 인물 알파는 AE 매트 또는 Codex 로 배경 제거 PNG. `motion-typo.md` 카드(깊이 타이포 T5)와 같은 계열.
- 난이도 중.

### 카드 6 — 반사(미러 바닥)
- 무엇: `MIRROR` 글자 아래에 알파 50% → 0 그라데이션 반사.
- **우리 도구로 하는 법**: `-webkit-box-reflect: below 0 linear-gradient(transparent 50%, rgba(0,0,0,.5))`(크롬 헤드리스 지원). 글자 요소 복제 + `scaleY(-1)` + `mask-image: linear-gradient(...)` 도 가능.
- 난이도 하.

### 카드 7 — 바탕만 컷, 글자 유지 / 글자만 컷, 바탕 유지

### 카드 8 — 윤곽선만 있는 거대 글자 → 채움 / 워터마크
- 무엇: 한글 `갑자기` `먼저` `이제야` 를 스트로크만(알파 15~25%)으로 아주 크게 깔고 그 위에 작은 자막.
- **우리 도구로 하는 법**: `-webkit-text-stroke: 3px rgba(255,255,255,.4); color: transparent; font-size: 55%높이` → 0.3초 뒤 `color` 로 채움. 한글에 잘 맞음.
- 난이도 하.

## 5. 설계자 관점 변형
- 영상의 배경 연출 중 3D 캐릭터·유리 파편·무대 장면은 우리가 못 만든다 → **색 면 4종 순환 + 등고선 패턴 + 실루엣(Codex 이미지) + 필기체 워터마크** 만 가져온다.
- 가사 줄마다 배경이 바뀌는 속도는 우리 대본(말) 속도보다 빠르다. 한 가사 줄 = 우리 «한 개념(말 2~3초)» 으로 환산.
- 1920×800 와이드 → 세로는 글자를 두 줄 이상으로 쌓고 거대 글자 폭을 화면 폭 90% 에 맞춘다.

## 7. 못 본 것 · 불확실
