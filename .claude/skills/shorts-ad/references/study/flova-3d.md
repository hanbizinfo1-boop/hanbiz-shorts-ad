## 1. 한 줄 요약 — 이 영상에서 가져갈 것

1. **Flova(플로바) = «에이전트가 샷 설계 → 이미지 시안 → 샷별 영상 병렬 생성 → 자동 편집(타임라인·BGM) → 내보내기»까지 한 화면에서 해 주는 AI 영상 웹 서비스.** 영상 모델은 **Seedance 2.5**(자막 «시덴스 2.5 모델»), 이미지 시안은 **Nano Banana Pro**(스킬 카드에 표기). 사용자가 한 일 = 제품 사진 1장 첨부 + 스킬 «Product Promo Video_v2» 선택 + 프롬프트 + 에이전트 질문에 클릭 응답.
2. **결과**: 애플워치 제품 사진 1장 → **15초 7샷 세로 광고**(풀샷 → 액정 클로즈업 ×2 → 마이크로샷 ×3 → 엔딩 풀샷). 눈으로 본 범위에서 컷 사이 형태·질감 일관, 금속·직조 질감 좋음. **단, 내보내기 사양이 «9:16 세로 480p, 30fps»** — 우리 납품 1080×1920 과 거리가 있다.
3. **과금**: 화면에 «**최대 60% 할인 & 1+1 혜택 · 9월 17일까지 · 480p 기준 초당 약 35원대**»(00:55.0). 프로모션은 오늘(2026-10-08) 기준 **이미 끝났다**. 한 번 돌리면 **샷 7개가 병렬로 생성**(샷당 «00:04» 표시)되므로 우리 «유료 생성은 장면당 한 건»(CLAUDE.md 3장)과 **그대로는 맞지 않는다**(6장).

## 4. 기법 카드

### 4-1. 에이전트가 샷 리스트를 설계하고 병렬 생성하는 «스킬» 방식
- 무엇: «풀샷 → 액정 클로즈업 ×2 → 마이크로샷 ×3 → 풀샷» 7샷 구조를 **스킬(Product Promo Video_v2)** 이 정해 주고, 에이전트가 제품 사진을 보고 샷별 영어 프롬프트를 쓰고 7개를 동시에 생성.
- 왜 먹히나: 제품 광고 문법(풀샷으로 시작, 디테일 클로즈업, 풀샷 엔딩)이 스킬에 박혀 있어 사용자는 «뭘 찍을지» 안 정해도 됨.
- 시각: 00:15.8~00:44.0.
- **우리 도구로 하는 법**: 우리는 이 역할을 **설계자(배치표 `edit_plan` + `ai-video.md` 5장 샷 설계)** 가 한다. 샷 구조 자체(풀 → 디테일 3 → 풀)는 `edit_plan.json` 컷 구조로 그대로 쓸 수 있는 «제품/공간 디테일 몽타주» 템플릿.
- 난이도: 구조는 쉬움 · 생성은 유료. 한비즈 적용: 모델하우스·인테리어 디테일 컷(수전·대리석·조명) — 단 **실제 공간이 아니면 «분양 광고 허위 우려»** 확인 필요(사장님).

### 4-2. «이미지로 시안 먼저 → 퀄리티 체크 → 영상» 순서
- 무엇: 영상 생성 전에 이미지 시안을 먼저 보여 줘 **실패를 싸게 걸러 낸다**(00:34.2~38.1, «퀄리티 체크가 바로 되구요»).
- 우리와: **우리 순서와 같다**(Codex 시작프레임 → 사장님 확인 → 유료 1건). 차이는 시안이 Flova 안(과금)이냐 Codex(무과금)이냐.
- 우리 도구: 시안은 계속 **Codex**(CLAUDE.md 3장). Flova 로 갈 때도 시안 이미지는 Codex 로 만들어 `+`로 첨부하는 쪽이 비용상 맞다 — 단 **스킬 내부가 Nano Banana 로 시안을 또 만드는지(과금 추가)** 는 모름.

### 4-3. 자막/타이포 — 3어절 덩어리 + 핵심어 민트 확대
- 무엇: 자막이 **1~3어절 덩어리**로 0.3~0.7초마다 교체. 핵심어(«3D», «30초 내로», «Flova.AI», «에이전트를», «생성하기를 누릅니다», «Flova.AI 플랫폼 내에서», «내보내기 누르고 나면», «댓글»)만 **민트색**, «3D»·«Flova.AI» 는 **박스 없이 확대**(약 1.3배). 마지막 «마지막»만 빨강.
- 왜 먹히나: 화면 녹화처럼 정보량 많은 화면에서 눈이 갈 곳(핵심어)을 색으로 찍음. 자막 위치(0.68H)는 UI 확대 화면의 아래 빈 곳.
- 우리와: **«강조어만 색»은 우리 규칙과 같다.** 차이: 저쪽 자막은 불투명 박스(스타일 A) — 사장님 «띠가 어색하다»(09-22) 이력.
- 우리 도구: `edit_plan.captions` 의 `emph`/`emph_color`(`g` 초록) — 민트는 팔레트에 없으니 «g 초록»으로 대체, 박스는 쓰지 않고 외곽선(B).

### 4-4. 화면 녹화 줌·패닝 + 후편집 «클릭 표시» 손 아이콘
- 무엇: 가로 PC 화면을 세로 프레임에 맞춰 **확대·패닝**하고, 클릭 지점마다 흰 손 아이콘을 얹어 «여기 누르세요»를 분명히.
- 우리: `bisa_ab_live`(CAM 카메라·커서·타자)의 같은 계통. 우리는 **업체명·계정이 보이는 실화면을 쓰지 않는다** — Flova 같은 외부 서비스 화면은 우리 영상에 쓸 일이 없고, 쓴다면 **가짜 화면 재현**(`design-paths.md` 6장).

### 4-5. 훅 = 결과물 몽타주 (00:00~05.0) + 엔딩 재사용 (북엔드)
- 무엇: 첫 5초에 **완성 결과**를 0.3~0.8초 컷으로 쏟고(12컷), 끝 3초(00:51~53.5)에 같은 클립을 다시. 말은 «이 정도 퀄리티의 전문가 같은 영상 30초 내로 만들 수 있습니다».
- 우리: **결과 먼저 → 과정 → 같은 결과로 닫기**는 원칙 12(북엔드)와 같다. 훅이 0.3~0.8초 컷이라 **인지 텀 0.6초 규칙과 부딪힘** — 단 소재가 «같은 제품의 다른 각도»라 새 정보가 아니라 반복이라는 점이 다름.

### 4-6. 타이틀 오버레이 «30초 만에 / 3D / 모션 만들기»
- 민트 이탤릭 초굵은 3줄, 크기 대비(«3D» 가장 큼), 인물 영상 위 파란 틴트 오버레이 0.0 → 100% 즉시(약 2프레임). 우리 T2/T3 타이포 설계안(`typography-remotion.md` 5-2)과 같은 계열 — **기울임(합성 이탤릭)은 한글에서 얇은 부분이 깨지기 쉽다**(추정, 미확인).

### 우리 파이프라인에서의 자리 (판단)
1. **Codex 이미지 → Flova?**: **가능은 하다**(Flova 입력이 이미지 첨부를 받음). 그러나 ① 과금 구조가 «샷 7개 병렬» ② 영상 모델이 **Seedance 계열 — 사장님 10-01 «웬만하면 시댄스 말고 제미나이, 시댄스 너무 비싸»**(`ai-video.md` 3장) ③ 480p ④ 가격 구조 미확인(아래) — **지금 도입하지 않는 쪽을 권한다**. 사장님이 «제품 디테일 컷을 한 번에 많이»라는 요구를 하실 때 «시험 1회»로 올릴 후보.
2. **블렌더 프리비즈 대체?**: **아니다.** 프리비즈는 공간 카메라 경로용, Flova 스킬은 제품 디테일 샷 목록용. Seedance 가 참조 영상(프리비즈)을 받는지(우리 문서: Seedance 2.0 은 받음)는 Flova 의 `+ → 동영상`에서 쓸 수 있을 가능성이 있으나 **Flova 의 스킬 흐름에서 확인된 바 없음**.
3. **얻을 것(비용 없이)**: 샷 구조(풀 → 액정·디테일 3종 → 풀) · «이미지 시안 먼저 → 질문으로 사양 확정 → 샷 병렬» 순서 · 자막 덩어리 크기(1~3어절) · 훅 결과 몽타주 + 북엔드 — 전부 **우리 `workflow.md`/`edit_plan` 에 이미 있는 것의 재확인**.

### 과금 관점 (CLAUDE.md 3장)
- 화면에 보인 가격: **«480p 기준 초당 약 35원대»**(00:55.0, 프로모션가로 보임 — 할인율 «최대 60%»·«1+1» 와의 관계는 화면만으로는 불명). **15초 편집본 × 35원 ≈ 525원, 샷 7개 × 4초 = 생성 28초 × 35원 ≈ 980원**(내 계산 — 과금이 최종 길이 기준인지 생성 길이 기준인지 **알 수 없다**). **프로모션은 2026-09-17 종료**(오늘 2026-10-08) → 현재가는 모름. 구독·크레딧 구조는 웹 검색에서도 **공식 요금표를 못 찾았다**(2차 자료: 무료 크레딧·월 $20 개인 플랜 언급, 확인 필요).
- **«장면당 한 건» 규칙과의 충돌**: 한 번 실행 = 영상 7건 + 이미지 시안 N건. 그대로 허용하면 규칙 위반 — **설계자가 임의로 «7건 = 1건»으로 해석하지 않고 사장님 확인**이 필요(제안만, 호출·가입 하지 않음).
- `get_cost` 같은 발주 전 비용 확인 도구가 **Flova 에는 없다**(웹 UI) — 사전 견적이 안 되면 CLAUDE.md 3장 «발주 전 get_cost, 발주 뒤 크레딧 누계 기록»을 지킬 수 없다 → **웹에서 소모 크레딧 표시를 수동 기록**해야 함.
- 가입·유료 호출은 **이번에 하지 않았다**.
