## 1. 한 줄 요약 — 이 영상에서 가져갈 것
1. **글자를 움직이지 않고 «글자가 놓인 판(배경)»에 연출을 몰았다.** 글자 사건은 전부 컴퓨터 UI 동작(커서 깜빡임 · 드래그 선택 · 지우기 · 타자)이고, 바탕은 밝은 회색 한 장 + 모서리 비네팅. 글자 등장에 크기 변화·튕김은 **0**(실측).
2. **커서(캐럿)가 글자보다 먼저 주인공**: 23~41초 약 18초 동안 화면에 글자는 없고 파란 캐럿 하나가 깜빡인다(높이 화면의 59%, 폭 1.25%). 말(내레이션)이 글자 자리를 대신한다.
3. **사진 36장이 «딱» 한 프레임에 켜진다(하드컷, 크기 애니메이션 없음)**, 간격이 0.63초 → 0.21초로 **빨라지다** 54.72초에 5프레임 만에 걷히며 글자가 드러난다. 속도 가속 = 클라이맥스.
4. **카피는 «Great ideas start here» → «_Mac»** 으로 선택→삭제→타자 4칸(0.125·0.125·0.083초 간격). 브랜드명은 새로 타자 쳐서 들어온다(로고 아이콘이 먼저, M·a·c 가 뒤).
5. 끝 2.8초(61.5~64.3)는 글자·바탕이 함께 흰색으로 페이드 아웃(회색 #E3 → #FA, 선형에 가까움).

## 2-3. 사장님 중점 4개 + 추가 요소 정리
- **배경 연출**: 종류 = ① 실사(어두운 방, 심도) ② **밝은 회색 단색 + 방사형 비네팅**(코너 #BBB, 중앙 #E3) ③ 마지막에 흰색으로. 움직임: 앞 단계만 카메라 이동, 회색 판은 **정지**. **블러**: 실사 앞쪽 물체의 심도 흐림(눈대중 10~30px), 글자 모션 블러 없음, 블러 인/아웃 없음. 바뀌는 방식: 연속 확대(실사→회색) · 사진 하드컷 쌓기 · 5프레임 걷힘 · 흰 페이드. 글자 뒤 레이어 수: 글자 순간 **1장**(회색 판), 콜라주 때 최대 사진 5~7장 겹침. 대비 확보: 밝은 회색 판에 검정 글자, 어두운 효과 없음.
- **글자 등장**: «사진이 걷히며 드러남(마스크식)» → «선택→삭제→타자 한 칸씩»(타이핑 + 커서). 튀어오름·스케일 펀치 **없음**.
- **강조**: 핵심어 «Mac» 을 **지우고 다시 쳐서** 보여 준다(카피 문구를 새 단어가 대체). 숫자 없음. 색 강조 없음(선택 파랑만).
- **전환**: 확대 연속(7초) · 하드컷(사진) · 5프레임 걷힘 · 흰 페이드(2.8초).
- **카피**: 첫 문장 «Great ideas start here» 4단어 22자(공백 포함) → 54.88~57.38초 **2.5초 노출**(이 중 선택 0.33초 + 선택 유지 0.58초, 약 8.5자/초 — 느린 편), 끝 «Mac» 3자 약 6.9초 노출(57.9~64.8). 문법: 내레이션이 질문(«what do you see?»)을 던지고 글자는 대답(«Great ideas start here»).
- **브랜드·CTA**: 로고(Apple 아이콘 + Mac)는 마지막에만, 1회, 약 6.8초(57.54~64.3). CTA 문구 없음.
- **글자 크기·위치**: 중앙, 높이 4.6%(헤드라인) · 9%폭(Mac). 안전 영역 문제 없음(정중앙).
- **색**: 회색/검정/파랑(선택) 3색.
- **글꼴**: 시스템 UI 계열 산세리프(SF 추정, 브랜드 전용 서체로 보임).
- **박자·소리**: 도구 수치로는 컷과 소리 타격이 맞는 비율 0%(우연 이하) — 소리 컷을 화면에 맞췄다고 볼 근거 없음. **귀로 못 들었다.**

## 4. 기법 카드
### 카드 1 — 커서 주인공 + 말
- 무엇: 글자 없는 18초(23.2~41.5) 동안 캐럿 하나가 깜빡이고 내레이션이 이야기를 한다. 59% 높이 캐럿이 «빈 페이지»를 상징.
- 왜 먹히나: 글자가 없으니 «곧 쓰겠다»는 기대가 쌓인다. 깜빡임 주기(1.28초)가 느려 «호흡» 처럼 읽힌다.
- 시각(근거): 20.0~41.1 (ON/OFF 목록 실측).
- 우리 도구로 하는 법: `html_motion` — 세로 1080×1920 에서 폭 14px·높이 900px 캐럿 `<div>`(색 1개). `seek(t)` 안에서 `((t % 1.28) < 0.58) ? 1 : 0` 으로 불투명도(전환 없이 on/off, CSS transition 금지). 바탕은 단색 + `radial-gradient(ellipse at 40% 40%, #E3E3E3 55%, #BBB 100%)` 하나(비네팅). 3색(회색·검정·파랑) 안.
- 난이도: 하. 한비즈 적용 예: «○○○ 문의 한 줄» 입력창 연출 도입부(자막 자리 비우고 말이 이어짐).

### 카드 2 — 사진 하드컷 가속 쌓기
- 무엇: 이미지 36장이 1프레임에 켜지고 간격이 0.6초→0.2초로 줄며 쌓인다. 크기 애니메이션 없음, 그림자 없음, 겹침만.
- 왜 먹히나: 컷 속도가 서서히 빨라져 «곧 무엇이 나온다» 기대 → 5프레임 걷힘으로 글자 드러남.
- 시각(근거): 41.79~53.64 (간격 35개), 54.717~54.884.
- 우리 도구로 하는 법: `html_motion` `<img>` 36장은 Codex 이미지(무료)로 만들거나 실제 소재(업체명 보이면 쓰지 않음). `seek(t)`: 사진 i 의 등장 시각 배열 `T=[0,0.63,1.21,...]`(간격 0.63→0.21 선형 보간), `opacity = t>=T[i]?1:0`(전환 없이). 걷힘은 마지막 5장을 5프레임에 하나씩 `opacity 0`. 사진 배치는 `data-box` 로 자막 자리 침범 점검.
- 난이도: 중. 한비즈 적용 예: «분양 자료·현장 사진 → 한 줄 카피» 도입.

### 카드 3 — 선택→삭제→타자 교체
- 무엇: 기존 문구를 드래그 선택(8프레임) → 한 프레임에 삭제 → 새 단어를 한 칸씩 타자(2~3프레임 간격).
- 왜 먹히나: 강조 수단이 크기/색이 아니라 «교체 행위». 같은 자리 같은 크기라 안정감.
- 시각(근거): 56.425~57.88.
- 우리 도구로 하는 법: `html_motion` — 선택 영역 = 글자 뒤 `<span>` 배경 `#B4D4FB` 폭을 `seek(t)` 로 0→100%, 삭제 = 텍스트 `display:none`, 타자 = 글자 배열을 시각 배열(0.125, 0.125, 0.083초 간격)에 맞춰 `substring`. 오버슈트 0, 모션 블러 불필요.
- 난이도: 하. 한비즈 적용 예: «문의 → 상담» 처럼 한 단어 교체.

### 카드 4 — 실사 → 추상 페이지 연속 확대
- 무엇: 실사 책상에서 노트북 화면 안으로 7초 확대해 회색 페이지로 이어진다.
- 시각(근거): 16~23.2.
- 우리 도구로 하는 법: **Codex 이미지(무료)로 책상 장면 한 장 + 회색 화면 판**을 만들고 `html_motion` 에서 이미지 `transform: scale(1→N)` + 판 `opacity 0→1`, 앞 물체 `filter: blur(0→20px)` 를 `seek(t)` 로 7초 이징. 또는 실사 영상이면 편집에서 크롭 확대(`edit_render`). 확대 중 블러는 앞 물체에만.
- 난이도: 중. 한비즈 적용 예: «스마트폰 화면 속으로 들어가 카피» 오프닝.

## 5. 설계자 관점 변형
- 영상은 **말 중심(내레이션)** 광고라 글자를 아껴 쓴다. 우리는 말이 있는 쇼츠이므로 글자는 **핵심어 하나만 마지막에**: 카드 3(교체)이 가장 맞음.
- 세로 1080×1920: 회색 판 + 중앙 글자 4.6% 높이 → 세로에서는 높이 5~6%(≈100~115px)로 올려야 가독(가로 50px = 4.6%, 세로 폭이 좁아 글자 폭 656/1920=34% → 세로 폭의 70%까지 키울 수 있음). 캐럿 높이 59% = 세로에서 1130px 은 과함 → 25~30%.
- 사진 콜라주는 가로 비율 사진을 세로 판에 쌓는 데 맞다(세로 중앙 열 + 좌우 어긋남).
