### 소리 ↔ 화면 대조 요약
- 소리는 **음악(킥 + 얕은 패드) 한 겹**으로 읽힌다. 별도 효과음(와이프 휙, 글자 등장음)은 audio.csv 모양으로는 보이지 않는다(귀로 못 들음 — 7장).
- 킥 밀도가 섹션과 함께 올라간다: 섹션 1 은 2박마다(1.12초), 섹션 2 부터 박마다(0.557초), 섹션 3·4 는 −5dB 로 일정. 와이프 시점마다 소리가 바뀌지 않고 «와이프 직후 0.16~0.2초에 킥이 온다».
- **와이프 중심은 박과 박의 가운데**(와이프 1: 박 4.01·4.57 사이 중점 4.29 ↔ 와이프 4.2–4.4 / 와이프 2: 8.51·9.07 중점 8.79 ↔ 8.7–8.9 / 와이프 3: 13.0·13.57 중점 13.28 ↔ 13.1–13.4). 섹션 길이 약 4.45~4.5초 = 8박. 우연이라고 하기엔 세 번 모두 맞는다(근거는 beats 목록·motion.csv).
- 섹션 안의 글자·그림 등장(0.2·0.8·1.8·4.5·5.2·9.0·13.5·13.8…)은 박 격자와 일치하지 않는다 — summary 의 «맞춤 0%» 는 그래서다. **음악과 화면을 맞춘 곳은 섹션 경계 한 곳뿐.**

### 카드 1 — 8박 섹션 + 반 박 와이프(구조 틀)

- 우리 도구로 하는 법: AE JSX 에서 와이프 = 얇은 무지개(우리는 브랜드색 단색 + 명도) 띠 쉐이프 레이어를 위치 키프레임(6프레임, 감속) + 바탕 컴프 두 개를 마스크로 전환. `ae_scene.comp_open/comp_close` 로 섹션별 프리컴프, 와이프 시각은 BGM 박 사이에. 또는 코드 렌더(5장 B).
- 난이도: 중. 한비즈 적용 예: 1) 상담 → 2) 자금 종류 → 3) 서류 → 4) 한비즈 로고 와 같은 4단 소개.

### 카드 2 — 라벨-제목-그림-부제 템플릿 + HUD 잔글씨
- 무엇: 눈썹(영문 소형 caps) → 굵은 제목 두 줄 → 그림 → 작은 한 줄. 모서리에 장면 번호·진행선·초 카운터.

- 우리 도구로 하는 법: 클로드 디자인(B 경로)에서 1080×1920 아트보드 하나를 템플릿으로 만들고 `design_layers.py` 로 레이어 분리(제목·그림·푸터 따로) → AE 에서 레이어별 감속 등장. 글꼴 Pretendard(한글 굵기 대비), 영문 소형 라벨은 자간 +200.
- 난이도: 하. 한비즈 적용 예: 상단 «한비즈» 워드마크 / 눈썹 «POLICY FUNDING»류 / 제목 두 줄 / 푸터 «01 / 상담».

### 카드 3 — 글자 단위 그라디언트 타이틀(PRISM)
- 무엇: 큰 워드마크를 글자마다 다른 세로 그라디언트로 채우고 0.1~0.2초 간격으로 한 글자씩 올림.

- 우리 도구로 하는 법: AE 텍스트 → 글자별 레이어 분리 + 그라디언트 램프 + 트랙 매트, 또는 HTML(`background-clip:text`) → PNG 레이어. **원칙 4(글은 단어 단위·반 박 간격)** 와 같은 결.
- 난이도: 중. 한비즈 적용 예: «한비즈» 3글자를 한 글자씩(브랜드색 한 톤의 명도 그라디언트).

- 무엇: 반투명 삼각 조각 60개가 원형으로 모여 천천히 회전하고, 가운데 한 조각만 선명·채색.
- 시각: 9.0–13.0. 확대 0.2초(작게 시작 → 순식간에 커짐) 뒤 느린 회전.
- 우리 도구로 하는 법: ① 코드로 조각 좌표를 시드 고정 난수로 생성 → 시각마다 위치·각도 계산 → AE 로 가져오거나 직접 렌더 ② 조각이 «서류 이미지»인 경우 Codex 서류 일러스트 8~10종을 AE 에서 반복 배치. 가운데 조각 = 한비즈 로고.
- 난이도: 중. 한비즈 적용 예: 시안 3(아래).

### 카드 6 — 소리 단계 올리기(섹션별 킥 밀도)
- 무엇: 섹션 1 은 2박마다 킥, 섹션 2 부터 매 박. 와이프에는 전용 SFX 를 달지 않고 와이프 직후에 킥이 온다.
- 우리 도구로 하는 법: BGM 한 곡 구간 편곡(킥 많은 쪽을 뒤 섹션에 두기)이지 SFX 작업이 아니다. SFX 는 `sfx.md` 규칙대로 «그래픽 등장 계기»에만. 와이프 휙 −5dB(2-1 컷·전환)는 우리 규칙상 붙여도 되고, 붙일 때는 peak 를 와이프 중심(반 박)에.
- 난이도: 하.

## 5. 설계자 관점 변형
영상의 «하라는 방식»(= 제작자 진술): AI 에게 영상 제작 스킬을 만들게 하고 한 번에 18초를 코드로 뽑는다. 우리 파이프라인에서는 이렇게 바꾼다.
- **A. 말이 있는 한비즈 쇼츠에는 그대로 못 쓴다** — 이 영상은 말·단어 시각이 없는 브랜드 무드 클립이라 박 격자로 짰다. 우리는 기준이 «말의 단어 시각»이다(`motion-graphics.md` 6장). 이 영상 문법은 ① 오프닝/클로징 브랜드 카드(말 없는 3~5초) ② 섹션 구분 화면 ③ 한비즈 소개 15초 단독 영상 에서만 쓴다.
- **B. 제작 길 두 갈래**
  1. 코드 렌더(Remotion 또는 HTML/Canvas → 프레임 캡처): 이 영상과 같은 길. 이 PC 에 Node v24 가 있다. Codex(구독 한도 안, 추가 과금 없음)로 코드를 짓게 하면 제작자와 같은 방식. **Remotion 라이선스: 직원 3명 이하 영리 법인은 무료, 4명 이상이면 유료**(공식 가격 페이지) — 한비즈 인원 확인 필요(7장). 자체 HTML 캡처(헤드리스 크롬은 `design_layers.py` 가 이미 사용)는 라이선스 없음 — 단 «시간을 프레임 번호로 고정하는 렌더러»를 `tools/` 에 새로 만들어야 한다(현재 없음).
  2. AE JSX(`ae_scene`) + 클로드 디자인 레이어: 정지 디자인(템플릿)을 클로드 디자인에서 확정 → `design_layers` 로 PNG 레이어 → AE 에서 감속 등장·와이프. 모핑 리본·군집처럼 «수학 생성 그림»은 코드 쪽이 편하고, 로고·글자 중심 장면은 AE 쪽이 사장님이 프리미어에서 후속 손보기 쉽다.
- **C. 납품 형태**: 사장님은 프리미어에 얹어 쓰신다 → 코드 렌더는 **PNG 시퀀스/ProRes 4444(투명) 또는 mp4 + 섹션별 개별 파일**로 내서 «같은 이름 제자리 덮어쓰기»(CLAUDE.md 9번).
- **D. 브랜딩 정직하게**: 한비즈의 **로고 파일·브랜드 색·글꼴이 이 폴더에 없다**(CLAUDE.md·기록 어디에도 없음). 시안에서 «브랜드색»은 자리만 두고 사장님께 받는다 — 지어내지 않는다.

### 한비즈 적용 시안 3개 (정책자금 · 중소기업 컨설팅 / 업체명 없이 «한비즈» 브랜드만)
공통: 숫자(한도·금리·승인율)는 넣지 않는다 — 대본·사장님 자료에 나온 것만. 단계·항목 이름도 대본에서 받아 쓴다. 강조색은 브랜드색 1개(미확인 — 받기 전엔 자리만), 바탕은 남색/미색 교대(이 영상 틀) 또는 미색 단일. 효과음은 BGM 이 있을 때 `sfx.md` 규칙.

**시안 1 — «하나의 상담, 갈라지는 자금»(프리즘 구조 번안, 15초 소개 영상)**
- 자료: 정책자금 종류(대본 확정 항목) 4~6개, 한비즈 로고.
- 움직임: ① 어두운 바탕에 한비즈 로고 판(프리즘 자리)이 떠오르고(0.3초 감속) ② 흰 선 한 줄(사장님의 한 건)이 왼쪽에서 들어와 로고에 닿으면(1.0초) ③ 브랜드색 한 톤의 명도 단계 광선 4~6줄이 오른쪽으로 갈라지며 끝마다 항목 이름표가 0.6초 간격으로 하나씩 붙음 ④ 와이프로 미색 장면(시안 2)으로.
- 브랜드·로고 모티프 자리: 프리즘 대신 **로고 평면판**(유리 3D 프리즘을 도형으로 흉내 내지 않음 — SKILL 4장), 로고 안의 가장 작은 도형 하나를 북엔드로 처음·끝에. 상단 좌측 «한비즈» 워드마크 + 우측 소영문.
- 소리: 광선 갈라질 때 짧은 라이저 + 맑은 한 음, 이름표마다는 붙이지 않고 묶음 1번(원칙 4·13).

**시안 2 — «겹겹의 절차가 한 줄로»(리본 모핑, 자료 = 지원 절차)**
- 자료: 지원 절차 단계(예: 준비 서류 → 신청 → 심사 → 실행 — 실제 단계는 대본 확정, 지어내지 않음). 단계 수 = 리본 겹 수.
- 움직임: 미색 바탕, 겹 수만큼의 곡선 띠가 출렁이며 나타나(0.3초) 4초간 연속 모핑 → 마지막 1초에 곡선이 한 줄로 수렴하며 한비즈 로고로 맺는다. 하단 선 7개(이 영상의 7색 선)는 **단계명 라벨이 붙은 진행선**으로 쓴다.
- 브랜드: 띠 색 = 브랜드색의 명도 5단계(3색 규칙 안), 수렴 후 로고만 강조색.
- 그림 길: 코드 렌더 또는 AE 사인 표현식. 말 따라 쓰기 금지 — 띠 위 글자는 단계 이름 한 단어씩만.
- 리스크: 4초 이상 쉬지 않고 움직임 → 원칙 7(그림이면 멈춰라)과 충돌 → 모핑은 배경 역할로 낮은 불투명도, 글자는 고정.

**시안 3 — «같은 서류, 다른 결과»(조각 군집 → 한 조각, 자료 = 필요 서류)**
- 자료: 서류 일러스트 6~10종(사업계획서·재무제표류 — 이름은 대본/사장님 확인, 업체명 ○○, 실제 문서 이미지 금지) = Codex 이미지(평면 일러스트 톤 한 세트, 글자 없이).
- 움직임: 0.2초에 작은 군집이 확대되어 원형 군집 → 3초 천천히 회전 → 가운데 서류 하나가 브랜드색으로 채워지며 앞으로 나오고 한비즈 로고 도장으로 닫힘. 제목 «다르게 보면…» 자리는 개념어 한 줄(말 따라 쓰기 금지; 예: 정리 / 구성).
- 브랜드: 군집 = 회색-청색 단색 투명도 단계, 중앙 한 장 = 브랜드색 + 로고.
- 소리: 군집 확대에 짧은 휙(−5dB), 도장 순간 쿵 1번(큰 강조 칸).

세 시안 공통 모티프(원칙 2): 이 영상의 «대각 띠 와이프»를 한비즈 브랜드색 띠로 바꿔 한 편의 문법으로.

## 7. 못 본 것 · 불확실
- **소리를 귀로 못 들었다.** 와이프에 SFX 가 «없다»는 판단은 audio.csv 의 onset 모양만 근거다(약한 휙이 묻혀 있을 수 있음).
- 프리즘 유리·광선이 CSS/SVG 인지 three.js 인지 모른다(Remotion 은 둘 다 가능). 렌더 방식만 «코드»로 확정(제작자 진술).
- «GPT 6 Astra» 가 실제 어떤 모델인지·Codex 가 얼마나 걸렸는지 모른다(설명란에 시간·프롬프트 없음).
- 바탕 배경의 비네트·그레인이 있는지는 접촉 시트 해상도에서 확인 못 함.
- 와이프 방향(왼 → 오)과 띠 모양은 0.25초 간격 시트 한 장씩이라 중간 프레임을 놓쳤다(4.2·8.8·13.2 시트 + motion.csv 로 추정).
- 한비즈 인원(Remotion 라이선스), 로고·브랜드색·글꼴은 이 저장소에 없어 **시안의 브랜드 부분은 자리 표시**.
