  - 우리 도구로 하는 법: `html_motion.py`(제안) 소용돌이 + `edit_render` 플래시 2프레임. 터널 안 UI 카드는 한글 글자 없는 카드(도형이 아니라 «화면» 암시). 난이도 중. 한비즈 적용: 문제 제기 구간 → 해결 구간 전환(섹션 바뀔 때만 플래시).
- **M5. 거대 타이틀이 사람 뒤에서 솟고 3초 홀드**
  - 무엇: 검은 세리프 대문자(원근 왜곡)가 흰 스포트라이트 원뿔을 배경으로 인물 뒤에서 올라오고, 새 요소 없이 컨페티·반짝임·눈 깜빡임만 3초(31.0–34.0).
  - 우리 도구로 하는 법: 한글 타이틀은 **PIL + Noto Serif KR/Pretendard Bold**(AI 글자 금지) → AE 에서 스케일/Y 이동 + 지휘자 레이어 앞에 두기(글자 가림은 의도 — 단 «가리면 안 되는 글자»는 겹침 검사로 방지). 컨페티는 AE 입자 대신 소수 PNG 조각 + 낙하. 난이도 중. 한비즈 적용: 브랜드명 한 단어(5-5 V8).
- **M6. 엔드 카드 = 앞 장면 하이라이트의 듀오톤 고스트 + 좌하단 작은 글**
  - 무엇: 앞 장면 5초를 낮은 대비 + 파랑 그라디언트 오버레이로 재활용하고 글자는 작게 좌하단에. 새로 만든 영상이 필요 없다.
  - 시각: 34.03–39.11(extra/36.0·37.0).
  - 우리 도구로 하는 법: `edit_render` 에서 소스 구간 재사용 + ffmpeg `colorchannelmixer`/`hue` + 반투명 그라디언트 PNG(알파 255 규칙은 «카드»에 해당 — 오버레이는 영상 전체라 예외). CTA 는 한 줄 + 로고(☐ 파일). 난이도 하. 한비즈 적용: 모든 쇼츠 엔드 카드 틀 후보.
- **M7. 던져 올림 → 변형(기둥·리본) → 소용돌이(메타포 샷)**
  - 무엇: 캐릭터가 하늘로 던져지다(23.2) 기둥(24.0)이 되고 리본이 되어(24.8) 소용돌이로 빨려듦(25.0). **한 대상이 모양을 바꾸며 다음 장면이 된다**(강의 `claude-motion-graphics.md` 의 «앞 장면이 다음 장면이 되는» 전환과 같은 말).
  - 우리 도구로 하는 법: 서류 캐릭터가 한 줄 기둥(서류 스택)으로 정렬 → 리본(한 줄) → 다음 컷. Codex 이미지 3장(캐릭터·스택·리본) + AE 형태 보간 또는 유료 영상 1 덩어리. 난이도 상. 한비즈 적용: «정리됨» 메타포(세로 화면에 기둥·스택이 잘 맞음).
- **M8. 2D 스타일 일관 + 광각 왜곡·더치 앵글 같은 «촬영 말투»**
  - 무엇: 평면 2D 그림인데 카메라 용어(로우앵글·광각 왜곡·더치·클로즈업)를 그대로 쓴다. 강의 K6 의 «불완전성» 구현.
  - 우리 도구로 하는 법: 시작프레임 프롬프트에 «low angle, wide-lens distortion, dutch tilt» 영어 문장(K3·K6). 난이도 하.

### 5-1. 설계자의 결론 (한 문단)
**Maestro 는 «유료 AI 영상 몇 덩어리 + 36컷 편집 + AE 타이틀/엔드 + 사운드 5층»의 결과다.** 우리는 이 중 **편집 구조(5박 리듬, 컷에 쿵, 타이틀 홀드, 엔드 고스트)와 글자·전환 렌더 = 무료 영역을 그대로 가져올 수 있다.** 가져올 수 없는 것은 **«캐릭터 연기 영상 자체의 퀄리티»**(Seedance 급 모델이 필요, AE 리그로는 단순 연기만)와 **«36컷을 낼 만큼의 소스 분량을 확보하는 비용»**(15초 약 3,600원짜리 덩어리 몇 건 — 강의 후반 3-3장 환산). 따라서 **한비즈에는 «브랜드 오프닝/엔드 약 17~19초» 한 종류에 한정해 Maestro 틀을 쓰고**, 본편(정보 전달 T2)은 소재 몽타주·타이포로 간다. 대본이 있는 광고 본문에는 Maestro 의 **컷 길이(1.09초)·플래시·6색을 쓰지 않는다**(6장).

### 5-4. 유료 장면 수를 줄이는 설계 규칙 (Maestro 36컷 → 우리 컷 수)

## 7. 못 본 것 · 불확실
- **소리는 귀로 못 들었다.** 타격 시각·레벨은 `audio.csv` 수치뿐이고 악기·효과음 종류·BGM 곡 구성은 모른다. «컷에 쿵» 은 컷 시각과 강한 타격 시각이 ±0.05초로 겹치는 것만 근거다(컷-타격 20%).
- **강의 단계 #3(라인 드로잉)·#13(영상 모델 구간 분할)의 Maestro 적용은 추정**이다. 3-2장 표에서 확신 «낮음» 으로 표시했다.
- **프리미어 `Maestro.prproj` 의 컷 단위 편집·전환·효과음 클립 내용**은 70:00 화면 한 장으로만 봤다(스크롤 없음). «영상 한 줄 + 사운드 5층»은 그 스냅샷에서의 읽음이다.
- **파일명 근거의 추정**: 3-1장의 «앞/중/뒷부분·0에서14.19·14에서24»가 생성 구간 분할이라는 해석, «젠쥬츠»(힉스필드 Genjutsu 와 관련 있는지)·«Tripo AI»(3D 모델 생성)의 쓰임은 강사 설명이 없어 모른다.
- **S10~S11 사이 흰 플래시(11.5~11.8)에서 파스텔 캐릭터가 보이는 것이 합성인지 AI 생성인지**, S21 소용돌이 속 UI 패널이 생성물인지 AE 합성인지 모른다.
- **S24 엔드 카드 고스트 장면이 S16~S20 의 «같은 소스» 인지 «리플레이스» 인지**: 프레임 형태가 같아 재사용으로 읽었지만(36.0 ↔ 22.8, 37.0 ↔ 21.5~22.5 비교), 정확한 시작·끝 시각 맞춤은 시험하지 않았다.
