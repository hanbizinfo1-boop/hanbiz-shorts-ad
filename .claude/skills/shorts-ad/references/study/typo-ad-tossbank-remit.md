## 4. 기법 카드
### 카드 1 — 1프레임 하드컷 자막 + 같은 자리 교체
- 무엇: 글자는 on/off·교체 모두 1프레임. 크기·위치 고정.
- 왜 먹히나: 글자가 흔들리지 않으니 «정보» 로만 읽힌다(신뢰). 움직임은 배경이 맡아 시선이 분산되지 않는다.
- 시각(근거): 0.876 · 3.92 · 7.34 · 11.01 · 19.65 · 22.19 · 29.32 · 30.78(on), 2.42 · 5.59 · 9.76 · 12.93 · 21.06 · 24.78 · 32.57(off).
- 우리 도구로 하는 법: `edit_render` 자막 레이어 또는 `html_motion` `seek(t)` — `opacity = (t>=on && t<off)?1:0`(전환 0). 교체는 문자열 배열을 시각으로 인덱싱(`seek` 안). 폰트 `HM Pretendard` 700, 색 1개.
- 난이도: 하. 한비즈 적용 예: 금융·분양처럼 신뢰가 중요한 장면의 사실 문구.

### 카드 2 — 휩팬으로 컷 숨기기(21프레임)
- 무엇: 카메라가 옆으로 확 돌며 번지고 번진 정점에서 다음 장면으로 바뀐다.
- 시각(근거): 13.0~13.9(변화율 6.7 → 37.5 → 8.8).
- 우리 도구로 하는 법: **Codex 이미지(무료)로 «지구 장면 A» «사람 장면 B» 두 장** → `html_motion` 에서 A·B 를 가로로 이어 붙인 판을 `translateX` 로 이동, `--sub 8`(서브프레임 모션 블러, 셔터 180°)로 방향성 번짐을 만들고, 정점 프레임에서 A→B 교체. 상승 14프레임 · 하강 7프레임. 영상 실사면 `edit_render` 전환(whip) 대신 AE 방향 블러.
- 난이도: 중. 한비즈 적용 예: 분양 «현장 → 내부» 장면 전환.

### 카드 3 — 폰 UI 진행 단계 + 배경 심도 흐림
- 무엇: 실제 앱 UI 의 단계(점·글자 굵기)가 아래로 이동하고 폰 뒤 배경은 크게 흐림.
- 시각(근거): 17.7~19.4, 20.6~24.8.

- 난이도: 중. 한비즈 적용 예: 계약 단계·접수 단계 표시.

### 카드 4 — 종이 접힘 와이프(오브젝트 확대로 화면 채우기)
