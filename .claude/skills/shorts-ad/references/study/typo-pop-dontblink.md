## 4. 기법 카드

### 카드 1 — 역팝(큰 것이 100%로 줄어들며 착지, 오버슈트 0)
- 무엇: 새 글자는 첫 프레임부터 불투명 100%·큰 크기(127~290%)로 나타나 8~10프레임에 100% 로 감속 착지.
- 왜 먹히나(추측): 첫 프레임에 이미 읽히고, 줄어드는 움직임이 «착지» 신호가 된다. 튕김이 없어 우리 규칙(오버슈트 0)과 같은 결.
- 시각(근거): 8.03 · 35.55.
- **우리 도구로 하는 법**: `html_motion` — 글자 요소 `transform: scale(S)` 를 `seek(t)` 에서 계산. 127% → 100% 12프레임@29.97fps(0.4초), 이징 `cubic-bezier(.16,1,.3,1)` 에 해당하는 지수 감속(`1-(1-p)^3`). 286% → 100% 는 12프레임 `1-(1-p)^4`. `transform-origin:50% 55%`. `--sub 4` 모션블러가 처음 3프레임을 자동으로 번지게 한다. 편집 `edit_render` 자막 팝은 이미 «130→100» 이 있으므로 같은 계열 — 크기만 130 → 127~290 로 키운 «큰 팝» 으로 확장.
- 난이도 하. 한비즈 적용: 숫자·핵심어 한 단어가 처음 뜰 때.

### 카드 2 — 자간 확대(트래킹 팽창)
- 무엇: 단어가 뜬 직후 8프레임 동안 글자 사이만 +55% 벌어짐, 글자 크기는 불변.
- 왜 먹히나(추측): 글자 크기를 못 키우는 정지 화면에 «숨 쉬는» 느낌을 준다. 1프레임 단위 변화라 눈이 계속 가는 곳.
- **우리 도구로 하는 법**: `letter-spacing: calc(-0.01em + 0.35em*ease(p))` 8프레임, 이징 지수 감속, 폭 변화로 가운데 정렬이 흔들리지 않게 `text-indent:` 로 마지막 글자 자간 보정(`margin-right:-0.35em*ease`). 한글은 자간이 이미 넓으므로 +0.15em 정도로 시작.
- 난이도 하.

### 카드 3 — 배경만 1프레임 반전, 글자는 이어짐
- 무엇: 글자 위치·크기는 그대로, 검정 판 ↔ 흰 종이 판만 한 프레임에 바뀜(9.48→9.53, 12.1, 19.7, 20.2, 33.2 등).
- **우리 도구로 하는 법**: 배경 div `background` 를 `seek` 에서 단어 인덱스로 교대, 글자 `color` 도 같은 프레임에 반전. 흰 판에만 `background-image: url(noise.png)` 먼지 질감(정지, 불투명 6~8%).
- 난이도 하.

### 카드 4 — 대각 삼각 와이프 + 디포커스 도트
- 무엇: 흰 판을 대각선으로 쓸며 검정 판이 들어오는 9프레임 와이프(15.93~16.14) 뒤, 점 패턴이 8프레임 흐려졌다 선명(16.14~16.5).
- **우리 도구로 하는 법**: `clip-path: polygon(0 0, X 0, 0 X)` 로 삼각형을 키우다가 `polygon(0 0,100% 0,100% 100%,0 100%)`; 도트는 CSS `radial-gradient` 반복 + `filter: blur(10px→0)` 8프레임. 가로형이라 세로 변환 시 대각선 각을 9:16 비율에 맞춘다.
- 난이도 중.

### 카드 5 — 글자별 들썩임(캐릭터 오프셋)
- 무엇: 한 줄 안 일부 글자(`h w a n i s e d`)만 이탤릭·±3px 오르내림 9프레임.
- **우리 도구로 하는 법**: 글자를 `<span>` 으로 쪼개 `transform: skewX(-12deg) translateY(sin(t*…)*3px)`; 한글은 글자마다 span.
- 난이도 하.

## 5. 설계자 관점 변형
- 영상이 «하라는 방식»: 말 없이 박에만 걸어 단어를 컷한다. 우리는 **말의 단어 시각**에 건다(motion-typo 핵심 12줄 3번). 카드 1~3 은 단어 시각에 그대로 쓸 수 있다.
- 영상은 배경이 단색 + 입자 클립 3개뿐이라 **배경 연출은 이 영상에서 가져갈 것이 적다.** 가져갈 것은 «글자 + 배경 컷 시각을 따로 둔다» 는 점.
- 한글은 읽는 시간이 길어 0.3초 컷은 못 쓴다 — 속도 대신 «큰 → 100%» 를 쓴다.

## 7. 못 본 것 · 불확실
- 소리를 귀로 못 들음. 자동 `kind` 분류도 믿지 않음. 박 격자는 컷 간격 규칙성만 말해 줄 뿐 소리가 컷에 맞았는지는 모름.
- 글꼴 이름 · 정확한 글자 색 코드(검정이 `#0c0c0c` 인지 등)는 시트로 어림한 값.
- 입자·DNA 클립 3컷의 출처(스톡)와 연출은 시트로만 봄.
