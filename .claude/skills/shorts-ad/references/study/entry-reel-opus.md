- 사장님 목적(원문, 10-08): «약간 이런 생동감있는 모션그래픽 되게좋은거같아» · 이 영상 화면 두 장(«블록을 조립하면» 초록 · «애니메이션» 빨강)과 함께 «일단 화려한 모션그래픽은 그냥 이런식으로 tts없이 진행할수도있어»
- 설명란(원문): «편집 프로그램 없이, AI가 코드만으로 엔트리를 15초 모션그래픽으로 소개해봤습니다. 클로드 오푸스 5.5에게 "모션 디자이너처럼 엔트리를 설명하는 15초 영상"을 맡겼습니다. After Effects 같은 툴은 쓰지 않았어요. 모든 프레임을 코드로 그리고, 배경음악도 샘플 없이 코드로 합성해 128 BPM 박자에 화면을 맞췄습니다.»

- 정독: 0.25초 시트 4장 전부 설계자가 직접 봄(10-08). 말(나레이션) 없음 — whisper 한 문장은 음악 오인식.

## 1. 한 줄 요약 — 가져갈 것
1. **«1마디 = 1장면»**: 128 BPM 1마디 = 1.875초, 실제 컷 1.83 · 1.93 · 1.90 · 1.88초 — 장면이 마디에 정확히 붙는다. 말이 없으니 **음악 박이 시간 축**이다.
2. **제품 자신의 언어로 말한다**: 엔트리의 블록·시작하기 버튼·실행 화면·마스코트·로고 글자를 그대로 모션의 재료로 쓴다(남의 그림·도형 장식이 아님). → 한비즈는 **신청서·서류·체크리스트·심사 진행·상담 버튼**이 재료.
3. **장면마다 배경 단색을 바꾸되, 한 장면 안은 3색**(배경 + 흰 글자 + 강조 하나). 편 전체 팔레트는 **브랜드 색**(엔트리 블록 색)에서 온다 — 그래서 화려해도 산만하지 않다.
4. **같은 틀(HUD)을 끝까지**: 네 모서리 괄호 · 위 타임코드 · 섹션 라벨 «04 — CREATE 2/4» · 진행 대시 · 아래 «128 BPM» 표기 · 큰 고스트 번호(01~04). 장면이 바뀌어도 «한 브랜드 영상»으로 묶인다.

## 4. 기법 카드
- **E1 마디 격자 편집** — 무엇: BPM 을 정하고 «1마디 = 1장면, 1박 = 몽타주 한 칸». 근거: 컷 길이 1.83/1.93/1.90/1.88 · 05.5–07.5 4칸. 우리 도구: html_motion 장면의 `structure` 를 박 시각표로(말 없는 릴에서만). BGM 의 BPM 은 `ref_study`(librosa) 로 잰다.
- **E2 제품 UI = 시각 언어** — 무엇: 서비스의 실제 부품(블록·버튼·실행창·로고·마스코트)을 재료로. 우리: 한비즈 서비스 흐름의 UI(상담 신청 버튼 · 서류 체크리스트 · 심사 진행선 · 결과 카드)를 **코드로 다시 그린 UI**(업체명 ○○, 실제 고객 화면 금지). 도형으로 사물 흉내가 아니라 **UI 그 자체**라 규칙(SKILL 4장)과 맞는다.
- **E3 장면별 단색 + 브랜드 팔레트** — 무엇: 장면 바탕색을 바꾸되 브랜드 색 집합 안에서만, 장면 안은 3색. 우리: 브랜드 색 4~5개 정의(☐ 사장님 파일) → 장면마다 하나.
- **E4 HUD 템플릿** — 무엇: 모서리 괄호 · 타임코드 · 섹션 라벨 «NN — 이름 n/4» · 진행 대시 · 고스트 번호. 우리: html_motion 공통 레이어(장면 HTML 에 include). 업체명·번호 금지 → 섹션 이름·진행만.
- **E5 거대 2줄 헤드라인 + 영문 라벨** — 한글 2줄을 화면 폭 85~90% 로, 아래 작은 영문 대문자 라벨(자간 넓게). 강조어는 색 또는 **검은 박스**(03.0 «코드»). = `typography-remotion.md` T2(폭 맞춤)의 실전형.
- **E6 «원인 → 결과» 한 화면** — 블록(원인) → 점선 궤적 → 실행 화면 결과(03.8–05.5), 블록 → 코드(07.5–09.4). 한비즈: «서류 → 심사 → 승인 카드», «체크리스트 → 정리된 계획서».
- **E7 소용돌이 링 + 단어 교체** — 소재가 원형으로 돌고 가운데 큰 단어만 바뀜(혜택 나열). 한비즈 CTA 직전 «처음이어도 / 상담부터 / 지금 바로» 같은 3단(문구는 사실 확인된 것만).
- **E8 로고 조립 엔딩 + CTA 파동** — 로고 조각이 떨어져 맞춰짐 → 태그라인 → CTA 버튼 + 원형 파동. 한비즈: **실제 로고 파일을 조각내 조립**(로고를 새로 그리지 않음), CTA «상담 신청».
- **E9 글리치는 한 번** — 9.2초 단 한 번(우리 원칙 «글리치/흔들기 한 편 한 번»과 같다).

## 5. 설계자 관점 변형 — 한비즈 «말 없는 모션그래픽 릴»(T4) 설계
- **형식**: TTS·나레이션 없음, BGM + 효과음 + 타이포가 메시지(사장님 10-08 «화려한 모션그래픽은 그냥 이런식으로 tts없이»). 시간 축 = **BGM 박 격자**(말 없는 릴만 예외 — 설명형은 여전히 단어 시각).
- **15초 가상 콘티(128 BPM, 8마디)** — 문구는 시안, 숫자·혜택은 사실 확인 전 넣지 않음:
  1. 남색 · 서류 카드(사업자등록증·재무제표·사업계획서 — 글자 없는 서식 모양 + 렌더러 라벨)가 하나씩 쌓임 · 하단 타자 «서류를 모으고»
  2. 브랜드 색 플러드 · 거대 «조건을 / 맞추면» + «CHECK · MATCH · APPLY» · 체크리스트 UI 정렬 → «**자금**이 된다»
  3. 크림 · 상담 → 심사 진행선(점선 궤적) → 승인 카드(금액 없음)
  4. 4칸 몽타주 1박씩: 운전자금 · 시설자금 · R&D · 수출(각 바탕색 + 그림 하나 — Codex 이미지 또는 코드 UI) — ☐ 실제 취급 분야로
  5. 남색 탭 «혼자 \| 한비즈와» · 흩어진 서류 → 정리된 계획서 줄이 타자
  6. 사례 카드 벽 — **실제 고객·업체명 금지**, 같은 결의 가짜 카드(○○)
  7. 링 소용돌이 + 단어 교체 3단
  8. 한비즈 로고 조립 + 태그라인 + CTA «상담 신청» 파동
- **만드는 길**: 장면마다 html_motion HTML(공통 HUD include) → 알파 없이 풀화면 mp4 → `edit_plan` 컷으로 이어 붙임 + BGM(사용 허락 범위 기록) + 효과음(`sfx.md` — 블록 착지 «틱», 플러드 «휙», 로고 조립 «뿅·반짝», CTA «띵»). 이 영상처럼 BGM 을 코드로 합성하지는 않는다(우리 라이브러리·허락 범위 규칙).
- **필요한 것**: ☐ 한비즈 로고(조각낼 수 있는 벡터면 최고) · ☐ 브랜드 색 · ☐ 한비즈 서비스 흐름(실제 절차 이름) · ☐ BGM 1곡(128 BPM 근처, 사용 허락).

## 7. 못 본 것 · 불확실
- 소리는 귀로 듣지 않았다(BPM·타격 수치만). 효과음이 BGM 에 섞여 합성됐는지 분리 SFX 인지 모른다.
- 정확한 이징·프레임 수는 0.25초 시트라 ±4프레임. 필요하면 해당 구간을 60fps 로 다시 뽑는다.
- 코드(렌더 방식)는 공개되지 않았다 — 설명란 «모든 프레임을 코드로»만.
