## 1. 파이프라인 한 줄

```
단어 시각 → PIL 로 조각 PNG(투명, 제자리) → 겹침 검사 → JSX(ASCII) → AfterFX.exe -r → aerender → ffmpeg mp4 → 효과음 → 점검 → 납품 3종
```

- 도구: `tools/ae_scene.py` (조각 저장 `save` · 겹침 검사 `check_boxes` · JSX 틀 `comp_open/comp_close` · 감시 실행 `run_ae_guarded` · `render` · `voice` · `mix_sfx`), `tools/rf3_ae.py`(JSX 공용 함수 `HEAD`·`js`), `tools/design_layers.py`(B 경로 레이어).
- JSX 는 **ASCII** 로 쓴다. 한글 문자열은 `json.dumps(ensure_ascii=True)` 의 `\uXXXX` 이스케이프(`AE.js()`)로 넣는다. AE 2026 한국어판의 출력 모듈 템플릿 이름이 **«고품질»**(ProRes 422 HQ) — JSX 안에서는 `om.applyTemplate('\uACE0\uD488\uC9C8')`. 알파가 필요하면 «고품질(알파 포함)».
- 흐름: `scenes → build.jsx → AfterFX.exe -r (프로젝트 만들고 저장, 종료) → aerender (렌더 큐 전부) → .mov`. AfterFX.exe 가 먼저 돌아오는 경우가 있어 로그가 닫힐 때까지 기다린다.
- 사람이 움직이면(반반 등) 사람까지 넣어 mp4 로, 안 움직이면 알파 mov 로 낸다.
- 작업 폴더는 **영문 경로**가 안전하다(분양 애펙 규칙). 한글 경로를 쓰면 JSX 안에서 `\u` 이스케이프.
(원본: 길라잡이/후킹애펙-워크플로우.md 1장 · 제작-레퍼런스.md 3장 · 도구/광고편집/rf3_ae.py)

`ae_scene.EO_JS / HOLD_JS`:

- **`eo(p)`** — 출발 빠르게(influence 0.1) · 끝 감속(influence 85). «빠르게 들어와 감속해 멈춘다»(영상미 원칙 3)의 구현. **공간 속성(위치)에는 ease 가 1개**라 `var n=p.isSpatial?1:(p.value.length||1)` 로 개수를 맞춘다 — 안 그러면 «setTemporalEaseAtKey 배열 요소 1개» 오류.
- **`hold(p)`** — 모든 키를 HOLD(계단) 보간. 불투명도 on/off 를 칼같이 켤 때.
- 튕김(오버슈트)용 `ez` 양쪽 감속은 03 말풍선에서 «버벅거려» 반려 → 등장은 `eo`.

## 3. 널(Null)과 식 — RIG · CAM

**RIG 널** — 무대 전체가 밀려 들어오고 빠지게(06·07 B 결, 18, 19): 널 하나의 위치에 `[W,0] → [0,0] (0.45초, eo) … [0,0] → [−W,0] (0.36~0.45초)` 키를 걸고, 무대 레이어들은 위치 식으로 따른다.

```js
RIG.enabled = false;                       // 널은 안 보이게
// 무대 레이어 위치 식 (카메라처럼 가운데 c 기준 확대 + 슬라이드)
var r = thisComp.layer('RIG').transform; var k = r.scale[0]/100; var c = [1180,560];
var p = value; [c[0]+k*(p[0]-c[0])+r.position[0], c[1]+k*(p[1]-c[1])]
// 스케일 식
var k = thisComp.layer('RIG').transform.scale[0]/100; [value[0]*k, value[1]*k]
```
RIG 스케일은 `100 → 106 (1.4초) … → 100` 처럼 «관찰자 쪽으로 살짝 다가감»에 쓴다(18).

**CAM 널** — 녹화 화면 위에서 «카메라가 말하는 칸으로 밀고 당긴다»(13 2판):

```js
// 화면 = P + k·(p − 가운데)
var c = thisComp.layer('CAM'); var k = c.transform.scale[0]/100; var P = c.transform.position;
[P[0]+k*(value[0]-960), P[1]+k*(value[1]-540)]        // 위치 식 (960,540 = 가로 틀의 가운데 → 세로는 540,960)
```
- 카메라가 **기본 틀 밖을 비추지 않게 묶는다**: `cam_at(k, f, g)` — 기본 틀의 점 f 를 화면 g 에 놓는 CAM 위치를 `px = min(max(px, W−k·cx), k·cx)` 로 잘라 준다. 틀 밖에는 녹화본 주소창·북마크·탭(계정 정보)이 있다(10-08 정지 화면 확인).
- 겹침 검사는 **CAM 을 따라가는 레이어**를 «쓰는 동안의 카메라 위치»로 환산해서 잰다(`to_screen`).
- 커서 크기도 카메라 스케일을 곱한다.

**부모 묶기 함정** — 부모가 키프레임으로 50%에서 시작하면, 자식을 묶는 순간 자식이 200%로 보정된다. 묶은 직후 `scale.setValue([100,100])`, 위치는 그 뒤에 부모 좌표로 건다. 판에 묶은 레이어 좌표 = 화면 x − 판 기준점 x(가로 장면은 900), y 는 그대로.
(원본: 후킹애펙-워크플로우.md 5장 · bisa_ab_live.py 69~104·476~478행 · bisa_need_drop.py 217~250행)

## 4. 트랙 매트 프리컴프 — 휴대폰 화면 안에 움직이는 화면 넣기 (17)

1. 화면 크기(SW×SH) 컴프 `scr` 를 따로 만든다 — 피드 띠(위로 넘어가는 사진 4장), 손가락 터치·꼬리, 빨강 틴트, 눈길, 글줄 페이지, 인사말 카드가 이 안에서 움직인다.
2. 본 컴프에 `scr` 를 얹고 `SL.parent = PN`(판), 위치는 휴대폰 사진의 **흰 화면 칸**(`matte` PNG: 사진 흰 칸만 알파) 가운데.
3. `SL.setTrackMatte(matte, TrackMatteType.ALPHA); matte.enabled=false;` — 실패하면 `matte.moveBefore(SL); SL.trackMatteType=TrackMatteType.ALPHA`.
4. 손가락이 화면 왼쪽 아래를 덮는 사진이면 글은 왼쪽 여백 50px 이상 비운다(17).
5. 같은 카드가 모양을 바꾸며(가로 크기 100→0→100으로 뒤집혀) 다음 상태로 — 원칙 8.
(원본: bisa_scroll_view.py 445~590행)

## 5. 반반 판 · 손글씨 · 형광펜 — 통과한 틀(02 목차, 12 노트)

**가로 1920×1080 실측** (세로 쇼츠 수치는 첫 작업 때 재서 채운다):
- 반반: 사람 = 원본 4K 50%를 **x 960→480 (0.45초, ease)**, 판 = 오른쪽 밖에서 **x 900(그림자 60px 포함)** 으로. 끝에 거꾸로 **0.36초**. 판 위 요소는 판에 **부모로 묶어** 같이 빠지게 한다.
- 손글씨: 줄마다 딱 맞는 PNG 한 장 + **Linear Wipe(각도 270, 완료 100→0, 페더 12)** — 왼쪽부터 써진다. 기준선은 노트 줄(90px 간격)에 맞춘다. 강조는 형광펜(노랑, 곱하기)을 글 아래에 깔고 같은 방식으로 드러낸다.
- 게이지(형광펜이 차오름): `ADBE Linear Wipe` — `property(2)=270`(방향) · `property(3)=페더(6~10)` · `property(1)`=완료(100→0), 0.45초. **차오르는 그림에는 차오르는 소리를 꼭 붙인다**(sfx.md).
- 카드형: 흰 속 + 메타 파랑 그라데이션 테두리 + 파란 알약 배지(01 업종 카드 결).
- 손글씨 글꼴 **개구 굵게(Gaegu Bold, OFL)** — 없으면 도구가 받는다(`config.FONTS["gaegu_bold"]`). 개구에는 «·»«…»«①»«→» 가 없다 → 빈칸으로 찍힌다. 쉼표·«등»·«1.»·말(«그다음»)로 쓴다. Pretendard 에도 «①» 없음. 맑은 고딕엔 «✓»«✕» 없음(선으로 그린다).
- 펜 그림은 쓰지 않는다(02 3판 «연필이 너무 흔들려서 집중이 분산돼» → `SHOW_PEN=False`). 글씨는 왼쪽부터 써지는 것만.
(원본: 후킹애펙-워크플로우.md 2장 · 기록.md 02·12)

## 6. 영상미 원칙 1~13 (모션그래픽 레퍼런스 두 편 해부, 10-07)

사장님 «우리 영상미 살리는 데 도움 되는 부분은 길라잡이에 잘 정리해서». 근거 수치는 7장. **상태: 학습분(통과 전)** — 시안·장면에 하나씩 써 보고 통과하면 8장 표로, 반려되면 9장 표로 옮긴다. 8·9장과 부딪히면 그쪽이 이긴다.

**우리 장면에 맞게 바꾼 점** — 레퍼런스는 음악만 깔린 영상이고, 우리는 **말하는 사람 위**다.
- 시각의 기준은 그대로 **말의 단어 시각**. 음악 박자 맞춤은 말이 없는 구간(인트로·아웃트로·몽타주·장면 사이 연결)에만. 그때는 박 격자보다 **소리가 치는 순간(온셋)** 에 맞춘다(온셋 70~87% · 박 격자 16~40%).
- 반반 판은 유지하고, 아래 원칙은 **판 안의 그림·글자 움직임**에 쓴다.

- 음악 맞춤은 «박 격자»가 아니라 «소리가 치는 순간(온셋)» 에. 장면(배경) 바뀜은 2~3박(1.2~1.5초) 단위로 규칙적, 그 안에서 글자·요소는 반 박(약 8프레임) 간격. 타이포 몽타주는 정지 20~45%, 작업물 쇼릴은 정지 65%.
- A 연출: 장면 묶음마다 «바탕+글자+강조 한 색» 3색(인트로 검정·흰·전기 파랑 / 쇼릴 검정·흰·주황 / 아웃트로 노랑·검정). 첫 2초는 **주장 한 줄**. 단어가 박자마다 하나씩 + 흰/파랑 상자 라벨 번갈아. 픽셀 글리치는 한 번만. 큰 단어로 화면 가득 + 0.5초마다 바탕 흰·검·파랑 뒤집기. 상자 와이프 = 글자 등장의 기본기. 한글 문장은 핵심어 하나만 색 상자. 블롭(파란 물방울)으로 화면을 삼키며 장면 닫기. 한 단어 안 굵은 고딕 + 기울인 세리프(제목 한 곳). 아웃트로는 노랑/검정 1.2초마다 뒤집기, 굵은 한글+가는 영문 짝, 세로로 세운 글자, 위아래 반대로 흐르는 띠. 구석 HUD 잔글씨(타임코드·«02 / 14»·진행 눈금).
- B 연출: 미색(#F1EEE8 근처) 둥근 카드 + 검정 + 빨강 한 점. 컷이 거의 없고 **한 물체가 계속 모양을 바꾼다**(글자→알약→글자, 원→사진 원→십자로 피어남→격자 콜라주, 원형 아이리스 전환, 홈페이지가 휴대폰으로 줄어듦, Idea→Script→Recording 29%→100%→Editing→Uploaded ✓ 진행률 UI, 북엔드). 설명 도식은 모눈종이 미색 + 가는 선 + «01→02→03» 계단 + 마지막 줌아웃, 금지 목록은 줄 그은 칩(«바운스»·«그라디언트»·«템플릿 느낌» ✕).
- 두 영상이 말한 만드는 법: 스토리보드부터 / 금지 목록(안 주면 클로드는 늘 쓰던 기본 스타일로 돌아감) / 먼저 묻고 계획을 보여 준 뒤 코드 / 박자마다 무엇이 일어나는지(장면·박자·금지 효과) / 음악 먼저 고르기.

## 10. 함정 (시험에서 확인)

- **프리미어 볼륨 저장값: 0dB = 0.17783**(+15dB 여유). dB = 20·log10(v ÷ 0.17783). 1.0 을 0dB 로 보면 «올리신 걸 내리셨다»고 거꾸로 읽는다(10-07 반려). `sfx.db()`.
- **위치(공간 속성)에 `eo` 를 걸면 «setTemporalEaseAtKey 배열 요소 1개» 오류** — `var n=p.isSpatial?1:(p.value.length||1)`.
- **애펙 «충돌 복구 옵션» 창**이 `AfterFX -r` 를 멈춘다(10-07 밤 14·15·16, 15분 타임아웃). 앞 실행이 비정상으로 끝나면 생긴다. `tasklist` 에 AfterFX 가 떠 있는데 `log.txt` 가 안 생기면 이 창. 스크립트가 «ok» 를 썼는데 AfterFX 가 안 닫히면 aerender 만 따로 돌려 이어 간다. **자동화**: `ae_scene.run_ae_guarded()` — 20초 로그 없으면 Enter(25초마다 다시, 최대 20번), 끝났는데 20초 안 닫히면 강제 종료. 그래도 Enter 가 안 닿으면 마우스로 «계속»을 누른다.
- **애펙 부모 묶기** — 3장.
- **글꼴 글리프 없음**: 손글씨(개구)에는 «·»«…»«①»«→», Pretendard 에는 «①», 맑은 고딕에는 «✓»«✕» 가 없다.
- **맑은 고딕(malgun.ttf)은 PIL 25px 안팎에서 받침을 뭉개 그린다**(«같»이 «갇-»처럼). 녹화 화면 UI 글자를 바꿔 쓸 땐 `C:/Windows/Fonts/NotoSansKR-VF.ttf`(굵기 500). 렌더 뒤 그 글자를 원본 크기로 잘라 확인한다.
- **효과음 낱개 wav 이름이 판마다 바뀌면** 예전 파일이 폴더에 남는다(지우지 않는다). XML 은 새 이름만 가리킨다.
- 녹화본 실화면을 쓸 때는 주소창(계정 ID)·탭·북마크를 잘라 낸다.
- **짧은 클릭 소리 과증폭**: 크기를 50ms RMS 로 맞추면 10ms 짜리 클릭은 작게 잡혀 수십 배로 키워지고 wav 에서 0dB 로 잘린다. `sfx.prep` 에 피크 −6dBFS 상한. 미리보기 합본은 섞은 뒤 피크 0.8 로 낮추고 리미터.
- 사장님 클립에 건 효과(흐림 등)는 **새 클립에 따라오지 않는다** — 흐림이 필요하면 구워 넣는다(14).
- 크롬 `--screenshot` 은 **절대경로**만(상대경로면 조용히 안 떨어짐). 투명은 `--default-background-color=00000000` + `html,body{background:transparent}`. 레이어 안 레이어는 부모 PNG 에서 빠진다.
- 애펙 셰이프 속성 추가 후 참조가 무효화된다 → 다시 받는다. 3D 레이어 ALONG_PATH 금지. Radial Blur 속성은 번호 말고 `ADBE Radial Blur-0001`(양)·`-0003`(종류) 이름으로.
- 애펙 장표 장면의 흐린 배경 영상이 장면보다 짧으면 끝난 뒤 검은 화면(규칙 1-4 위반) → 배경은 긴 영상.
- `-i 그림.png` 로 넣은 정지 이미지는 프레임이 t=0 한 장뿐이라 시간 기반 필터(`fade`·`geq`)가 안 먹는다 → ffmpeg 에는 `-loop 1 -framerate 30 -t <길이>`.
- 겹침 검사 문턱: 자료가 같은 자리에서 시간이 달라 겹치지 않는 경우(인스턴트 카드 뒤 웹사이트 칸 흐림)는 시각별로 잰다.
- 같은 분량이라도 렌더 시간: 장면당 1~3분(분양 애펙). 무거운 분석(OCR·sound_scan)은 한 번에 하나씩 — 동시에 돌리면 메모리가 넘쳐 렌더가 죽는다.

## 11. AE 템플릿(.mogrt) 제작 — 사장님이 프리미어에서 글자만 바꿔 끼우게 (ae-template 스킬 요점)

한 장면을 한 번 만드는 JSX(1~3장)와 달리, **레퍼런스를 받아 반복해서 쓸 모션그래픽 템플릿**을 코드로 만들어 내는 길이다. 사장님이 AE 를 열 일은 없다 — AE 는 템플릿을 만들 때만 쓴다. 한비즈 쇼츠에서 아직 요청된 적은 없고, 자막·강조 자막 템플릿이 필요해질 때 쓴다(공장 코드는 이 폴더에 없다 — 아래 함정 목록이 이식된 전부다).

**순서**: ① 레퍼런스(이미지·영상 링크·설명)·**바꿀 항목**·규격(세로 9:16, fps)을 받는다. 폰트를 안 정하면 맑은 고딕(`MalgunGothic`) ② **사양서(spec.json + 설명)를 먼저 사장님께 확인받는다** — 특히 **«바꿀 항목»은 나중에 추가할 수 없다**(추가하려면 템플릿을 다시 만든다) → 넉넉히. 레퍼런스에서 읽은 값(글자 크기 비율·HEX·등장 방향/속도·박스/밑줄·위치)은 추정이면 «추정» 표시 ③ `.jsx` 작성 → `AfterFX.exe -r "<절대경로.jsx>"` ④ **3중 검증** ⑤ 인계(.mogrt 경로 · 프리미어에서 바꿀 항목 · **폰트 요구사항**(쓰는 PC 에 설치) · 확인 못 한 것).

**노출(프리미어에서 바꿀 수 있는 것)은 네 가지뿐** — 텍스트 · 색 · 숫자 슬라이더 · 체크박스. 위치·크기는 직접 노출이 안 되므로 **슬라이더를 만들어 표현식으로 연결**. 노출 순서는 **추가한 순서의 역순**으로 나온다 → 원하는 순서의 역순으로 호출. 컨트롤 `type` 코드: 텍스트 6 · 색 4 · 슬라이더 2 (나머지 미확인; 판별은 `value` 형태 — 문자열 dict=텍스트, bool=체크박스, 숫자=슬라이더, 배열=색/좌표).

**3중 검증 — 통과해야만 «완성»이라고 말한다**
| 층 | 보는 것 | 잡아내는 실패 |
|---|---|---|
| 1층 AE 안 자가보고 | 규격 · 레이어 수 · **폰트 대체 여부**(`TextDocument.fontObject.isSubstitute`) · 노출 컨트롤 · 파일 생성 | 스크립트 오류, 폰트가 조용히 바뀜 |
| 2층 `.mogrt`(ZIP) 구조 | `definition.json` 의 `clientControls[]` 이름·종류, `usedFontsLocalized` | 프리미어에서 안 바뀌는 항목 |
| 3층 프레임 이미지 | 글자 깨짐 · 화면 이탈 · 움직임 유무(`comp.saveFrameToPng`) | 구조는 맞는데 화면이 엉망 — **눈으로 본다**(스크립트 판정만 믿지 않는다. 색 노출 방식 때문에 외곽선이 지워진 것을 1·2층이 통과하고 눈으로만 잡았다) |
1·2층은 폰트를 서로 독립적으로 검증한다. 검증기는 **실행 전에 이전 산출물(리포트·`.mogrt`·프레임)을 지운다**(어제 만든 것이 통과로 보이는 착시 방지).

**ES3 · AE 함정 (이 PC 실측)**
- **ES3**: `let`/`const`/화살표 함수/템플릿 리터럴 금지, **`JSON` 객체 없음**(탭 구분 텍스트로 직렬화), `var`·`function` 만.
- `exportAsMotionGraphicsTemplate(true, **폴더**경로)` — 두 번째 인자는 폴더. **파일 경로를 주면 빈 디렉터리가 생기고 AE 가 죽는다**(재현 2회). 폴더는 미리 존재해야 하고 파일명은 `comp.motionGraphicsTemplateName`. 내보내기 전에 프로젝트를 한 번 저장(`_work.aep`)해 두어야 «저장하시겠습니까» 모달에 안 막힌다. 로컬 글꼴 동기화 경고는 `app.beginSuppressDialogs()` … `endSuppressDialogs(false)` 로 억제.
- 내보낸 뒤 **기존 `comp` 참조가 무효화**된다 → 검증을 export 앞으로 옮기거나 `app.project.items` 를 다시 돌아 이름으로 재조회. 이펙트를 추가하면 같은 레이어의 **기존 이펙트 속성 참조도 무효화** → 속성은 들고 다니지 말고 쓰기 직전에 이펙트 이름으로 다시 찾기.
- EGP 컨트롤 인덱스는 **1부터**(0 은 `undefined`). `addProperty` 는 matchName 이 틀리면 예외 — try/catch 로 로그만 남기고 빌드를 살린다. 확인된 matchName: `ADBE Fill` · `ADBE Glo2` · `ADBE Drop Shadow` · `ADBE Gaussian Blur 2`(`property(1)`=흐림) · `ADBE Tint`.
- **폰트를 항상 명시**(기본이 굴림). PostScript 이름으로: `var td = prop.value; td.font="MalgunGothic"; prop.setValue(td);` (TextDocument 는 값 타입이라 고쳐서 되돌려 넣는다).
- **텍스트 외곽선**(`applyStroke`·`strokeColor`·`strokeWidth`, `strokeOverFill=false`)을 쓸 때 색 노출은 `ADBE Fill` 이 아니라 **`ADBE Tint`** — Fill 은 외곽선까지 한 색으로 칠한다. 노출하는 것은 둘째 색(`Map White To`), 첫째(Black)는 `[0,0,0]` 유지.
- 다른 레이어의 이펙트 속성을 표현식으로 참조할 때는 로캘 이름이 아니라 **인덱스**로(`effect("글자색")(2)`), 대상 레이어는 표현식 전에 이미 존재해야 하고 레이어 이름을 명시(기본 이름 = 텍스트 내용이라 문구를 바꾸면 깨진다).
- **로그는 append 모드**(`open("a")`) — 덮어쓰기면 죽는 순간 0바이트가 되어 증거가 사라진다. (※ 1~3장의 장면 JSX `HEAD.log` 는 한 번 쓰고 닫는 방식이라 "w" — 템플릿 공장에서는 append 로.)
- **종료는 항상** `app.project.close(CloseOptions.DO_NOT_SAVE_CHANGES); app.quit();` — 저장 확인 모달 하나가 무인 실행 전체를 멈춘다(300초 타임아웃 재현). `Stop-Process -Force` 로 AE 를 죽이지 않는다(다음 실행에 «비정상 종료» 창). 사용자가 작업 중일 수 있는 Premiere 프로세스는 건드리지 않는다.
- **AE 가 이미 떠 있으면 `-r` 이 비동기로 넘어간다**(스크립트를 그 인스턴스에 넘기고 즉시 반환) → 실행 전에 AE 프로세스를 확인하고 떠 있으면 중단(만들어지지도 않은 리포트를 읽고 «1층 실패» 로 오진한 적).
- fps 는 근사 비교(59.94 → `59.9400024414062`, 허용 0.01). `setTemporalEaseAtKey` 길이: Position 1 · Opacity 1 · **Scale 3**(2D 레이어여도) → 후보 길이 `[추정, 3, 2, 1]` 을 순서대로 시도하고 전부 실패하면 예외를 올린다(조용히 넘기면 «이징 없이 통과» 가 검증을 속인다).
- `comp.saveFrameToPng(time, File)` 은 공식 문서에 없지만 26.3 에 있다. 파일 쓰기 권한 설정이 꺼져 있어도 `.mogrt` 내보내기는 된다.
