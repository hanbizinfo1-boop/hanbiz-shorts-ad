# 납품 전 점검표 — 한 줄씩 확인하고 결과를 보고에 적는다

사장님 09-28 «규칙 누락 현상 심함» — 알고도 빠뜨리지 않는 게 핵심이다. 규칙마다 **어떻게 확인하는지**를 같이 적었다. 사장님에게 보여 드리기 **직전**에 아래를 한 줄씩 본다. 새 피드백이 오면 **규칙 한 줄 + 점검표 한 줄**(기계로 볼 수 있으면 `tools/rule_check.py` 에도)을 바로 추가한다.
어느 표를 쓰나: **말하는 사람 위 애펙 장면 → A표** / **분양·광고 쇼츠(전체 편집) → B표** / **AI 영상 → C표** / **대본·화면 문구 → F표** / 효과음 → sfx.md 11장.

## D. 자동 점검기 — `tools/rule_check.py`

렌더 도구가 **렌더 전**(`check_plan`) · **소리 섞은 뒤**(`check_sfx`) 부르고, ERROR 면 멈춘다. `--무시` 로 넘겼으면 위반 목록을 보고에 적는다. **새 렌더 도구를 만들면 이 점검기를 반드시 끼운다.**

```python
import rule_check as R
shots = [dict(t0=0.0, t1=1.8, seg=0, src="a.mp4", kind="video", tr="cut", label=None, props=[]), …]
#   kind: video | image | doc(PDF 장표) | black | grad | speed     tr: cut | slide | punch | fly | push | move …
items = R.check_plan(shots, segs_text=["줄0", "줄1"], model_ok=(), ref_lines=None)   # → [(수준, 규칙, 메시지)]
n_err = R.report(items, path="점검_장면.txt", title="03")                              # ERROR 개수
sf = R.check_sfx([(초, 파일, 길이초), …], 장면길이초)                                    # 5-2 · 5-2b · 5-3
```
| 자동으로 보는 것 | 규칙 |
|---|---|
| 같은 소스 파일 두 번 이상 | 1-1 |
| 모형 소재 — `model_ok` 에 사장님이 지정한 것만 통과 | 1-2 |
| 까만 화면·그라데이션·집중선 / 소품·큰 글자·제목 띠·도장 | 1-4 · 1-5 · 4-2 |
| 타입을 말하는 줄(«84타입», «국평», «대형평수» …)인데 화면 `label` 없음 | 1-8 |
| 첫 화면이 영상인지 | 1-9 |
| 자료·이미지 2초 미만 / 모든 화면 1초 미만 / 영상 3초 초과(경고) | 2-1 · 2-2 |
| 같은 전환이 연속 | 3-1 |
| 자막이 원문(타임라인·SRT)과 다름 (`ref_lines`) | 4-1 |
| 같은 효과음 연속 / 번갈아 같은 파일 4번째 / 2.5초 넘게 소리 없음 | 5-2 · 5-2b · 5-3 |
**사람이 봐야 하는 것**: 대본·화면 정합성 1-7, 장면음 5-4, 근거 없는 문구 6-2, 모아보기 눈 확인, 겹침(애펙 장면은 `ae_scene.check_boxes`).
`MODEL_FILES`·`MODEL_DRONE` 상수는 분양 건의 모형 소스 이름이다 — 한비즈 쇼츠에서 모형이 없으면 영향 없다.
