# 그림 만드는 길 — A(Codex 이미지) · B(클로드 디자인) · 2D 플랫 애니 · 실제 로고 · 녹화 화면 재현

> **핵심 10줄 (이미지를 만들기 전에)**
> 1. **«레퍼런스 없이 상상해서 만든 이미지는 경험상 다 별로였다.»** — Codex 를 부르기 전에 그 장면을 쓰는 레퍼런스 프레임이 이미지를 어떻게 쓰는지 **먼저 본다**(8장).
> 2. **«한글은 어떤 경우에도 AI 에 맡기지 않는다.»** 바탕만 생성하고 글자는 PIL + Pretendard Bold. 화면 속 글도 AI 가 그리지 않는다(3장).
> 3. **지명·역명은 Codex 에 맡기지 않는다**(없는 지명을 지어낸다). 지도는 이미지로 받고 **선·마커·글자는 PIL**.
> 4. **도형으로 사물·배경을 흉내 내지 않는다**(사장님 «도형 가지고 조잡하게 흉내낸 거 없어 보여서 싫다»). 장식(돌판·소품)이 정보를 대신하지 않는다 — 실제 사람들이 참고할 자료를 넣는다.
> 5. 카드·이름표는 **불투명(알파 255) + 모서리 반경 12~14** — 반투명 채움·큰 반경은 뒤 영상이 «구멍»으로 비친다(`motion-graphics.md` 9장).
> 6. 길은 **구도 먼저** — 그 말이 실제로 일어나는 자리(0장). A Codex / B 클로드 디자인 / 2D 플랫 / 실제 로고·국기 / 녹화 화면 재현.
> 7. 이미지는 **Codex 가 먼저**(유료 도구 전). 프롬프트는 자기완결형 영어, 복사 대상 경로 지정(2장).
> 8. 사람 장면 이미지는 «사진기로 찍은 사진» 톤 — CG 질감은 영상에 그대로 간다(`ai-video.md`).
> 9. 한 세션 안에서 스타일 하나로 통일. 같은 캐릭터가 여러 장이면 «Same X from image N» 로 고정. **글자가 있는 인형은 좌우 뒤집기 금지**.
> 10. 실제 로고·국기는 출처를 `소재/이미지-출처.md` 에 한 줄씩. 업체명이 보이는 실자료는 쓰지 않는다.

효과음·단어 시각·반반 판·겹침 검사·납품 3종은 어느 길이나 같다. **다른 건 «그림을 어디서 만드나»뿐이다.**

## 0. 한눈에 — 장면마다 고른다 (사장님 10-06)

클라이언트 «클로드 디자인을 조합해서 영상미를 살려 보는 것도 좋아 보인다» → 사장님 «GPT 이미지에 애펙 얹는 방식도 있지만 클로드 디자인에 애펙을 얹는 워크플로우도 하나 챙겨 가자».

| | A. Codex(GPT) 이미지 + 애펙 | **B. 클로드 디자인 + 애펙** |
|---|---|---|
| 그림 | Codex image_gen 사진·일러스트(무료 한도) + PIL 로 그린 카드 | **실제 로고·이미지(받기) + Codex 이미지**를 Design 캔버스에 올려 디자인 — 도형으로 형상 흉내 금지 |
| 잘 맞는 장면 | 사진이 필요한 것(업종 카드 사진, 사람·장소) · 마스코트·2D 애니 | 글·숫자·목차·UI 모형·비교표·단계 도식 |
| 사장님·클라이언트 확인 | 렌더 뒤 미리보기로 | **캔버스 링크에서 움직이기 전에** 보고 댓글·직접 수정 |
| 마무리 | 애펙 | 움직임 필요 → `design_layers.py` 로 레이어 떼어 애펙 / 필요 없음 → 캔버스에서 마무리(한 장 납품) |

둘을 섞어도 된다: 사진은 Codex 로 만들어 캔버스에 올리고(자산 업로드), 배치·글은 캔버스에서.

**구도 먼저(사장님 10-07)**: 길을 고르기 전에 «그 말이 실제로 일어나는 자리»를 구도로 정한다. 설정·버튼 → 실제 설정 화면에서 값을 넣는 느낌(녹화 확대 + 타자) / 개념 비교 → 비교 판(연달아 쓰지 않는다) / 과정·알고리즘 → 의인화·모션 / 보는 사람 시점 → 휴대폰 구도 / 일상 상황 → 2D 애니. 직전 통과 틀(휴대폰 사진·비교 판)을 다음 장면에 그대로 가져가지 않는다.

## 1. B 경로 원칙 (사장님 10-06 원문)

> «클로드 디자인을 쓸 때는 도형을 조합해서 형상을 표현하는 방식보다는, 필요한 이미지들을 실제 로고나 이미지를 크롤링하거나 GPT 이미지로 만든 것을 클로드 디자인에 적용시켜서 디자인으로 필요한 작업을 한 뒤, 추가 작업이 필요하면 애펙으로 넘기기, 없으면 클로드 디자인에서 마무리»

1. **그림은 «진짜 이미지»로** — 휴대폰·로고·사람·제품·화면을 사각형·원·선 조합으로 흉내 내지 않는다(PIL 로 그린 휴대폰 모형 = 이제 하지 않는 방식).
   - **실제 로고·이미지 받기**: 공식 사이트·브랜드 자료실·위키미디어에서. 받은 파일·주소·받은 날을 `소재/이미지-출처.md` 에 한 줄씩. 403·봇 차단은 우회하지 않는다.
   - **고객 업체명·대표번호·계정 정보가 보이는 실자료는 쓰지 않는다** — 그 자리는 Codex 연출 이미지.
   - **Codex(GPT) 이미지**: 실물이 없거나 쓸 수 없는 것(연출 사진, 휴대폰 손에 든 장면, 배경). 사진풍, 무료 한도 안에서.
   - 녹화본 실화면도 이미지다 — 필요한 부분만 잘라(계정 ID·탭·북마크 빼고) 올린다.
2. **캔버스에서 디자인** — 이미지를 캔버스에 자산으로 올리고(로컬 원본 경로는 `자산.json`), 배치·글·색·강조는 캔버스에서. 도형은 카드 바탕·구분선·강조 밑줄 같은 «디자인 요소»에만.
3. **갈림길**
   - **움직임이 필요하다**(단어 시각에 맞춘 등장·반반 열림·반짝·게이지·화면 넘김) → `design_layers.py` 로 레이어를 떼어 애펙으로.
   - **움직임이 필요 없다**(한 장 띄우는 자료·표·정리 카드) → **캔버스에서 마무리**. `_all.png`(또는 캔버스 내보내기)를 납품하고, 프리미어에선 이미지 한 장으로 얹는다(효과음은 등장 프레임에 하나).

### B 경로 순서

1. **캔버스 만들기** — Artifact `quickstart`(intent design) → Design 타입으로 새 캔버스(제목 = 장면 이름). 비공개로 생긴다. 공유는 사장님이 정하실 때만.
2. **아트보드 = 장면의 «다 나온 모습» 한 장**(영상 크기 고정, `$preview` 같게 — 가로 장면은 1920×1080, 세로 쇼츠는 1080×1920). 반반 장면이면 오른쪽 판만 채우고 왼쪽은 비운다.
   - 움직일 덩어리마다 `data-layer="이름"`(영문·숫자·_). 카드 안 글을 따로 움직이려면 안에 또 `data-layer`.
   - `<sc-for>`·`<sc-if>`·`<dc-import>` 는 쓰지 않는다(정적 마크업). 사진·로고는 캔버스에 자산으로 올리고 로컬 원본 경로를 `자산.json` 에.
   - 업체명·계정 ID·고객 정보 금지, 글자는 대사·사장님 원문 그대로.
3. **확인** — 캔버스 링크를 드리고 사장님(·클라이언트) 댓글·수정을 받는다.
4. **레이어 떼기** — 아트보드 원본을 `Artifact read`(path `project/<이름>.dc.html`)로 받아
   `python tools/design_layers.py <받은.dc.html> _tmp/<건>/dsN [--자산 자산.json] [--크기 1080x1920]` → `_all.png`(완성) · `_base.png`(바탕) · 레이어별 PNG(화면 전체 크기 제자리, 투명) · `layers.json`(상자). `_all.png` 를 캔버스와 눈으로 맞대 본다(글꼴·자산이 빠지면 여기서 드러난다).
5. **애펙** — 장면 도구에서 `design_layers.ae_lines(폴더, AE.js)` 로 바탕·레이어를 깔면 기준점이 레이어 가운데로 잡힌다. 돌려받은 변수(레이어 이름 → JSX 변수)에 `keys()` 로 단어 시각에 맞춘 등장·강조·퇴장만 건다(반반이면 판에 `parent`). 예: `examples/bisa_learning_b.py`.
6. 효과음·`rule_check`·미리보기·납품 3종·피드백 기록은 SKILL.md 순서 그대로.

함정: 크롬 `--screenshot` 은 절대경로만. 투명은 `--default-background-color=00000000` + `html,body{background:transparent}`. 레이어 안 레이어는 부모 PNG 에서 빠진다(따로 움직이라고). 크롬 경로는 `config.CHROME`.
(원본: 후킹애펙-워크플로우.md 0장)

## 2. A 경로 — Codex 이미지

### 호출 (돈 문제 때문에 이미지는 전부 Codex 로)

- 프롬프트를 `_tmp/codex/<이름>.md` 에 UTF-8 로 쓰고:
  `powershell -NoProfile -ExecutionPolicy Bypass -File "C:/Users/user/.claude/scripts/codex-run.ps1" -PromptFile "<경로>" -Sandbox workspace-write -Effort medium` (`config.CODEX_RUN`)
- `-Sandbox workspace-write` 가 **반드시** 필요(기본은 read-only). 이때 codex 끼리 병렬 금지. timeout 은 최소 600000ms.
- 1장 약 21초, 세션 첫 호출은 기동 포함 약 60초 → **여러 장이면 한 세션에 몰아서.** portrait 1024×1536 / landscape 1536×1024 / square 1024×1024. `view_image` 로 로컬 레퍼런스를 물릴 수 있다.
- **Codex 는 세션 현재 폴더 밖에 못 쓴다**(workspace-write 루트 = 실행 위치). 생성물 원본은 `$CODEX_HOME/generated_images/<세션>/` 에 떨어지므로 **프롬프트에 복사 대상 경로(이 폴더 안)를 지정**하고, 안 되면 거기서 직접 복사한다.
- 프롬프트는 **자기완결형**(Codex 는 저장소 사정을 모른다), **영어**(한국어는 결과가 불안정), 마지막에 «복사 → 최종 경로 출력 → 아무것도 더 하지 말 것».
- 인증이 풀리면(401) 사용자가 터미널에서 `codex login`.

Style: <한 문장으로 고정 — 아래 세 가지 중>. No text, no logos, no watermark (필요한 글자는 철자를 못박는다: the word "Meta" spelled M-e-t-a).

(같은 캐릭터가 여러 장이면 «Same X from image 2: …(옷·머리 그대로)» 로 고정, 또는 view_image 로 레퍼런스를 먼저 로드)

보고 형식: 파일별 최종 경로·실제 픽셀 크기·투명(알파) 여부.

- **사람 장면(영상화할 이미지)은 항상 «사진기로 찍은 사진» 톤** — ai-video.md. CG 질감 이미지는 영상에 그대로 간다.

## 4. 2D 플랫 애니메이션 (18 «니즈 하락» — 사장님 10-08 «애니메이션 연출(3인칭 관찰자 시점) · 3D 보다는 2D 체로, 그냥 움직이는 느낌만 모션만»)

- **같은 캐릭터 여러 동작**을 투명 PNG 로 따로 만든다(신청 `char_apply` · 들뜸 `char_eager` · 늘어짐 `char_bored` · 무시 `char_ignore`) + 배경 `bg_room`(불투명, 왼쪽 아래 1/3 은 합성용 단색) + 소품 `phone_ring`. 첫 이미지를 만든 뒤 나머지는 «Same woman from Image 2 …(옷·머리 동일)».

## 5. 실제 로고·이미지 받기

- 출처는 **위키미디어 공용(Special:FilePath 또는 표준 썸네일)** — 국기는 퍼블릭 도메인, 서비스 로고(Meta·YouTube·Google Ads·Instagram·Shorts 아이콘)는 «상표 — 설명 목적 사용». 
- **표준 썸네일 크기만 받는다**: `…/thumb/…/500px-<파일>.png` 처럼 **500px**. 640px 은 표준이 아니라 400 오류가 났다(09). Special:FilePath 는 `?width=500`.
- 받을 때마다 `소재/이미지-출처.md` 한 줄(파일 · 출처 URL · 날짜 · 메모) — 예: `소재/09/flag_kr·jp·us·cn.png | 위키미디어 공용 국기(퍼블릭 도메인) — upload.wikimedia.org/…/500px-Flag_of_South_Korea.svg.png | 2026-10-07 | 640px 은 400(표준 크기 아님) → 500px`.
- 403·봇 차단은 우회하지 않는다. (재배포 금지 라이선스 소재는 공유 드라이브·저장소에 올리지 않는다 — sfx.md 9장.)
- AI 생성물 확인 항목: 실존 인물 유사 · 상표 · 손가락·글자 결함(원본 ad-video 스킬).

## 6. 녹화 화면 재현 (실제 업체가 보이면 임의로 다시 그린다)

- 녹화본 실화면을 쓸 때: **주소창(계정 ID)·탭·북마크(고객사 폴더 등)를 잘라 낸다.** 확대 때는 카메라가 기본 틀 밖(주소창·북마크)을 비추지 않게 묶는다(`cam_at`).
- **실제 광고주·업체명이 보이면 그대로 못 쓴다** → 같은 결의 **가짜 화면을 PIL 로 다시 그린다**(19: 광고 라이브러리 UI, 업체 ○○, 검색어 «피부관리», 카드 구성 ● 활성 · 라이브러리 ID · 게재 시작일 · 플랫폼 · 광고 상세 정보 보기 · 광고주 · 문구 · 소재 · 더 알아보기). 투박한 광고 소재는 일부러 촌스럽게(노랑 사선·빨강 별·굵은 테두리 글), 예쁜 광고는 Codex 사진.
- 흐린(블러) 화면 위에 상황을 재현할 때(14): **사장님 흐림 효과는 새 클립에 안 따라온다** → 흐림(예: 가우시안 40)을 구워 넣고 그 위에 흰 카드로 목록을 재현(업체명·실데이터 없이, 이름 예시는 «9/30 · 여드름 영상»).
- **녹화 글자를 덮은 판은 투명도를 낮추지 않는다** — 밑 글자가 비쳐 두 글자가 겹친다(13 «글자도 깨지고»). 꺼짐 표현은 불투명 회색판으로 교체.
- 녹화 UI 의 실제 계산식·문구를 따른다(예: 일 예산 칸 안내 «매일 ₩○○ 정도 지출됩니다. 최대 일일 지출 한도는 ₩(1.75배)입니다»).
- 계정·고객 정보: 모자이크가 필요하면 전 구간 OCR 자동보다 **가릴 구간 목록(시각·위치)부터 드리는** 쪽(사장님이 직접 블러 처리하신 이력, 10-06 «됐어 그냥 하지마 내가 알아서 블러처리할게»).

## 8. 이미지 원칙 — 만들기 전에 레퍼런스부터 (분양 레퍼런스 분석 09-22, 모든 건에 적용)

사장님 지시(09-22): **«레퍼런스 없이 상상해서 만든 이미지는 경험상 다 별로였다. 이미지 생성할 때는 레퍼런스에서 이미지를 어떻게 쓰는지 반드시 참고할 것.»** — 이 방식으로 일이 넓어진 날 사장님이 정한 규칙이다(카피·TTS 는 사장님이 주고, 컷 선택·배치·그래픽 제작은 이쪽 몫. «요청받은 것만 한다» — 초반에 파이프라인 전체를 돌리려다 «내가 요청한 것만 진행해» 로 제지받았다).

**순서**: 해당 장면을 쓰는 레퍼런스 프레임을 먼저 본다 → 그 쓰임대로 만든다. 이 판의 이미지는 대체로 아래 넷 중 하나다 — 이 밖으로 나가지 않는다.
1. **지도·노선도** — 위성 or 약도 바탕, `SITE` 빨간 마커, 역·학교 아이콘, 원형 글로우 콜아웃, 지도 위 컬러 노선.
2. **플랫 인포그래픽** — 밝은 바탕에 서류·도장·집·동전 일러스트 + 굵은 문구 + 알약 뱃지.
3. **실사/CG 인프라 사진** — 마트·병원·학교·공원. **있는 것을 쓰지 만들지 않는다.**
4. **평면도·조감도·배치도** — 실제 자료를 얹는다.

**레퍼런스가 이미지를 쓰는 법 (짚은 요소만 가져온다 — 통째 베끼기는 반려)**
- 세로 짐벌 원테이크 위에 **떠 있는 그래픽**: 조감도 · 평면도 · SITE 표시 지도 · 노선도 · 아이콘 뱃지. 찍을 수 없는 정보(개통 예정·학군)를 이 방식으로 해결.
- 자막이 2줄이면 본문 아래 **빨간 괄호 보조 문구**(규제 꼬리말이 들어갈 자리). 평면도 여러 장을 세로로 겹쳐 띄우기, 원형 글로우 지도 콜아웃, 혜택은 스티커.
- 조건은 **플랫 인포그래픽 카드**(밝은 바탕 + 서류·도장·집·동전 + 파란 알약 «실거주 의무 없음!»), 상단 고정 배너(이름 + 연락처) 내내 유지, 화면을 위아래 2단으로 사진 두 장 동시에, 지도에 `SITE` 빨간 마커 + 학교 아이콘.
- 시세 비교 막대그래프, 계약 조건은 서류에 사인하는 손 클로즈업 위 큰 글자, CTA 는 손가락 커서 + «누르고 / 상담받아봐».

**만들 때의 기법 (다음에도 그대로)**
- **한글은 AI 에 맡기지 않는다** — AI 가 그리면 글자가 뭉개지거나 없는 글자가 섞인다. 바탕만 생성(`raw-*.png`, 글자 없는 바탕은 남겨 두면 문구·색만 고칠 때 바탕을 다시 안 만든다) → 글자는 PIL + `Pretendard-Bold.otf`.
- **지명·역명은 Codex 에 맡기지 않는다.** 지도는 이미지로 받고 선·마커·글자는 PIL 로 그린다. 커뮤니티 CG 에는 «※ 시설 예시 이미지» 꼬리말(실제 촬영본이 아님).
- **누끼는 크로마 그린으로**: 프롬프트에 «flat solid chroma green background, no shadow, no gradient», 녹색 채널이 R·B 보다 40 이상 높은 픽셀을 알파 0, 경계 번짐은 G 를 max(R,B) 로 눌러 제거, 끝나고 내용물 기준으로 crop. 가끔 마젠타/검은 배경으로 나온다 → 마젠타 픽셀이 15% 미만이면 **휘도 키**(어두운 픽셀을 투명하게)로 넘어가게 해 둔다(어두운 카드 위에 얹을 때만 안전).
- **글자색은 바탕색과 반대로**(크림 박스 위 흰 글자 → 안 보여 다시 만들었다).
- **Codex 가 세션 루트 밖으로 못 쓰면**(프롬프트에 폴더 경로를 적어도 «쓰기 권한 거부») 9장을 다 만들고도 복사가 실패한다 → 원본은 `$CODEX_HOME/generated_images/<uuid>/` 에 있으니 직접 가져와 이름을 붙인다. 파일명이 랜덤이라 **생성 시각 순 = 프롬프트에 적은 순서**로 맞춘다.
- **자료는 카드에 가두지 않고 날것으로 크게**: 노선도·배치도·평면도를 PDF 에서 자료 구역만 오려(쪽 아래 «내부용·외부반출 금지» 푸터는 오림선 94.5% 로 제외) 띄우고 설명은 자막이. Codex 로 만든 항공사진처럼 실제와 무관한 그림은 겉돈다. 자료 위치는 컷마다 흔들리지 않게 **한 자리에 고정**.
- 자막에 이미 있는 말을 그래픽으로 또 쓰지 않는다(자료는 «말» 이 아니라 «근거» 라 중복이 아니다). 영상에서 쓰지 않을 AI 이미지(AI 로 만든 통장 등 실물과 결이 다른 것)는 파일은 남기되 영상에 넣지 않는다.
- 규제 표현(예정/가능 꼬리표, 한정 수량, 선착순 조건)은 갈래가 달라도 같다.
