# 모션그래픽 · 타이포그래피 — 작업별 참고 리스트 (사용 설명서)

사장님 10-08 «길라잡이에 제품사용설명서처럼 각각 작업할때 원하는 참고리스트를 누락없이 확인할수있도록 우리 초점에 맞춰서 정리해줘». 레퍼런스 9편 정독(`study/`)에서 나온 것을 **작업 단위**로 묶었다. 작업을 시작할 때 1장에서 길을 고르고 → 2장의 해당 카드(A~I)를 위에서 아래로 따라간다. 근거(시각·원문)는 카드가 가리키는 `study/<노트>.md` 에 있다.

## 핵심 12줄 — 이 문서를 일부만 읽어도 지킨다
1. **글자·UI·숫자·로고가 주인공인 컷은 렌더러(폰트)가 그린다** — 영상 생성 모델에 맡기지 않는다(Newtake 결과 «비타민B» → «에터민B», «Complex» → «Corxplex», `study/2d-mg-newtake.md` 3-5).
2. **힉스필드 없이 된다**: 타이포·UI·카드·로고·3D 판은 `tools/html_motion.py`(HTML `seek(t)` → 크롬 캡처 → ProRes 알파) 또는 AE 로, 추가 과금 없이(10-08 이 PC 실측). 유료는 **새 실사(사람·장소·제품) 영상**에만.
3. 모든 움직임은 **말의 단어 시각**에 건다 — 레퍼런스들은 박(BPM)에 걸지만 우리는 `words.py` 시각표. 말 없는 구간(오프닝·엔딩)만 박.
4. **3색**(바탕·글·강조 하나) · 핵심어 하나만 강조 · 등장 4~8프레임 감속 · **오버슈트 0**(크기가 100%를 넘었다 돌아오는 튕김 — 레퍼런스 10편 104개 사건에서도 0, 10-12 실측) · 글리치 한 편 한 번. **«톡톡 튀는 느낌»은 튕김이 아니라 역팝·번짐→정착·하드컷·크기 대비로 낸다(J 카드)**.
5. **새 요소는 0.6초 이상 혼자** — 레퍼런스는 0.4~0.5초 연타가 많다. 한글은 영문보다 읽는 시간이 길어 장면 길이 1.5~2배. **예외: 말 없는 타이포 장면(J 카드)** 은 박 격자에 «키워드 카드 1박(≈0.47초)»까지.
6. 화면 글은 **말 따라 쓰지 않는다**(개념어·구조), 숫자는 **말·사장님 확정 문구에 나온 것만**(광고 주장 숫자는 근거 표 · 한 문장에 숫자 하나 — `copy.md`), 업체명 ○○, 영문 장식 슬로건 금지(HUD 소형 라벨만).
7. **도형으로 사물(휴대폰·액자·사람) 흉내 금지** — 사물은 Codex 이미지·실사진 `<img>`. 버튼·슬라이더·탭·차트 같은 **UI 그 자체**는 코드로 그려도 된다(녹화 화면 재현과 같은 결).
8. 레퍼런스는 **짚은 요소(팔레트·비율·구간·동작)만** 장면 스펙으로 옮긴다 — 통째 모사·타사 이미지 입력 금지.
9. 장면 스펙(3장)에 **EXACT STRINGS** — 화면 글 목록을 문장부호까지 고정하고 렌더 결과·자막과 대조.
10. 큰 변화 앞에는 **0.5초 숨**(소리·움직임 비움) → 쿵(`study/dynamic-mg-sfx.md` 카드 2). 시작과 끝은 같은 모티프로 닫는다(북엔드).
11. 글자가 사람·제품·자막 자리에 **가려지거나 겹치면 렌더 전에 멈춘다**(`html_motion` 점검 · `ae_scene.check_boxes`).
12. 영상 생성(AI)은 **많이 뽑아 고르지 않는다** — 고르기는 Codex 시작프레임 단계에서 끝내고, 유료는 장면당 1건(`ai-video.md`).

**강령 (7줄 — 장면을 짜기 전에 읽는다)**
1. **글자는 «나타나지» 않는다, «사건»이 된다.** 글자마다 이름 붙은 등장 어휘 하나(J-2). 이름 없는 페이드·슬라이드 금지.

## 3. 장면 스펙 틀 (모든 모션그래픽 컷 공통)

강의들의 «촬영 지시서»(Newtake)와 «6블록 프롬프트»(Claude 강의)를 우리 규칙으로 합친 것. 받는 쪽은 실행자(`sonnet-5`)·렌더러(html_motion / AE). 영어 자기완결형.

```
SCENE: <id> · DURATION <s> · 1080x1920 · 29.97 fps · alpha <yes|no>
MOTIF: <one motif for the whole film>          # 브랜딩 모티프(C)
PALETTE: paper #… · ink #… · accent #…          # 3 colors (comparison: one color per side)
TYPE: <font path: Pretendard Bold | Noto Sans KR VF>, word-break: keep-all, min size <☐>
KEEP-OUT BOXES: person <☐> · caption <☐>         # SKILL 6장 재서 채울 칸
WORD-TIME TABLE (words.txt, s): "…" t=… · "…" t=…
SHOT TABLE: id | t_in–t_out | element (≥0.6 s apart) | motion (entrance 4–8 f ease-out, NO overshoot) | exact string
EXACT STRINGS (immutable, rendered by font engine): "…", "…"
TRANSITIONS: <one family for the film>; flash ≤ section changes only; glitch ≤ once
END HOLD: last 0.85 s, no new elements
SOUND: role → file (sfx.md); hits on EVENTS; 0.5 s breath before the big hit
GUARDRAILS: no logos/company names (○○), no invented numbers, no emoji, no template-card lists,
            no neon/rainbow gradients, no CSS-drawn phones/people (use <img>), text never copies the narration
START: show the word-time table + 3 stills before writing code   # 설계자 검수
BUILD (html_motion contract): window.W/H/FPS/DURATION, async window.seek(t) (pure function of t —
       no CSS transitions/timers/Math.random), window.EVENTS=[{t,role,text}], window.PALETTE, data-box on elements,
       local @font-face + await document.fonts.ready, <img> decode() before capture
```

## 4. `tools/html_motion.py` 쓰는 법
- `python tools/html_motion.py <장면.html> --alpha [--sub 4] [--frames a:b] [--out 폴더] [--name 이름] [--무시]` → `<이름>.mov`(ProRes 4444 알파) · `_preview.mp4` · `_sheet.jpg`(0.25초) · `_events.json` · `_점검.txt`.
- 렌더 전 점검: 새 요소 간격 <0.6초 WARN · `data-box` 겹침 ERROR(멈춤) · `PALETTE` 4색 이상 WARN.
- 속도(10-08 실측): 6초 180프레임, 서브프레임 4 → 약 110초(1.7프레임/초). 길면 `--workers`(미검증).
- 설치물 없음: 크롬(`config.CHROME`) + aiohttp CDP + ffmpeg. Remotion·Playwright·HyperFrames 는 쓰지 않는다(라이선스·설치 — 필요하면 사장님께 묻는다).

Noto Sans KR VF 도 그대로.

- 사장님 «흠 후킹부분이 멋이안사네 여기부분 어떻게 하면 좋을까?» → 원인: 연한 바탕 · 검정 작은 글자 · 무게감 없음. 선택지 질문은 물리시고 «3개다 시도해봐 각각 버전다르게해서 보여줘» → A 2×2 입체 블록 / **B 어두운 시네마틱** / C 두꺼운 3D 블록 글꼴 → **«b로가자»**.
- **B 문법**: 남색 방사 조명(가운데 밝고 가장자리 거의 검정) + 떠다니는 금빛 먼지 · 날아오는 글자에 **빛 꼬리**(진행 반대쪽 drop-shadow 2겹) · 합쳐지는 순간 **번쩍**(가운데 원형 빛이 10프레임에 퍼지며 사라짐) · 글자는 **금색 그라데이션 입체**(아래로 3단 그림자 + 은은한 빛) · 둘째 줄은 흰 글자. 장면 `tools/scenes/html/hanbiz_3an_typo.html` 의 `HOOK` 스위치('B' 기본, 'A'/'C'/'0' 보존).
