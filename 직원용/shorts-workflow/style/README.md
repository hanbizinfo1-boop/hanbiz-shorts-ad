# style/ — 편집 디자인 · 분위기 (비워 둠 · 디렉터가 채운다)

이 칸은 일부러 비어 있다. **작업 방식(SKILL.md · references/)과 부딪히지 않게** 디자인·분위기 판단은 전부 여기로만 모은다.
SKILL 과 이 폴더가 다르게 말하면 **디자인 문제는 이 폴더가 이긴다.**

## 채우는 법

- 디렉터 말씀은 **원문 그대로** + 그래서 무엇을 바꿨는지 한 줄.
- 통과한 시안·반려된 시안은 이미지 경로나 납품 폴더 경로를 같이.
- 한 파일에 한 주제. 아래 목록 중 필요한 것부터 만든다(없는 파일은 «아직 정하지 않음»).

| 파일(만들면) | 담을 것 |
|---|---|
| `subtitle.md` | 자막 모양(띠·테두리·색·글꼴·크기·위치·등장 방식·강조색 역할) |
| `color-type.md` | 색 체계 · 글꼴 · 화면 글 크기 · 상자/판 모양 |
| `motion.md` | 등장 속도·감속·튕김 여부 · 전환 종류 · 카메라 움직임 · 컷 리듬 |
| `composition.md` | 구도 습관 · 사람 자리/자막 자리 · 첫 3초 규칙 · 비교 장면 표현 |
| `sfx-tone.md` | 효과음 성격(쓰는 소리/안 쓰는 소리) · 목소리 대비 크기 · 반복 한도 · 빈 구간 |
| `bgm.md` | 음악 취향 · BPM · 라이선스 출처 |
| `pass-reject.md` | 통과/반려 이력(장면 · 원문 · 이유) |
| `references.md` | 디렉터가 좋다고 한 레퍼런스(링크 · 짚은 요소만) |

## 비어 있는 동안

- 디자인 판단이 필요하면 **시안 2~5개를 실제로 만들어** 고르게 한다(글로 묻지 않음).
- 기존 디렉터 편집(프리미어 저장본)이 있으면 거기서 **재서** 따른다(자막 위치·클립 볼륨 등). 값을 지어내지 않는다.
- 고른 결과는 바로 이 폴더에 기록 — 그게 학습이다.
