# 검증 — 납품 직전 한 줄씩 (결과를 보고에 적는다)

여기는 **품질 사고를 막는 기술 기준**만 있다. 보기 좋은지(디자인)는 `style/` 와 디렉터 눈이 판단한다.
`(스타일에서 바꿀 수 있음)` 표시는 기본값일 뿐이고 `style/` 에 다른 값이 있으면 그쪽을 따른다.

## 점검표

```
[ ] 0  요구 대장의 R 번호를 전부 짚었다(빠진 요구 없음) · 지시 없는 구간은 «판단»으로 기록
[ ] 1  앞뒤 맥락을 읽고 기록했다(앞 30초 · 뒤 15초 대사·컷)
[ ] 2  움직임·화면 글·효과음이 그 말의 단어 시각에 걸렸다(단어 시각표 기록)
[ ] 3  대본·자막 = 디렉터 원문 diff 0 · 화면 숫자는 전부 근거 있음(출처 기록) · 효능/보장 표현 0
[ ] 4  업체명·전화번호·계정·고객 정보·타사 상표 노출 0 · 모델 사진은 허락 범위 안
[ ] 5  단어 시각마다 프레임을 뽑아 봤다 + 전체 렌더본을 «영상으로» 봤다(떨림·깜빡임·잘린 구도)
[ ] 6  깜빡임 0(프레임별 밝기가 번갈아 튀지 않음) · 화면 갈라짐 0(해상도 읽기 오류)
[ ] 7  읽혀야 할 글자가 플랫폼 UI 에 가리지 않음(세로 1920 기준 아래쪽 약 1/3 피함) · 디렉터 자막 자리와 겹침 0
[ ] 8  음량: 완성 −14 LUFS 근처 · 트루피크 −1.5dB 이하 · 짧은 소리 0dB 잘림 없음
[ ] 9  효과음: 효과음끼리 겹침 0 · 들리는 중 잘림 0 · 바로 연달아 같은 파일 없음
[ ] 10 소리를 귀로 들었는지 — 못 들었으면 보고에 «못 들었다»
[ ] 11 납품: XML 이 가리키는 파일 전부 존재 · XML 만으로 다시 조립해 미리보기와 대조 · fps 가 디렉터 시퀀스와 같음
[ ] 12 같은 판이면 같은 이름 덮어쓰기(폴더 지움·이름 바꿈 없음) · 사람 포함 렌더면 «원본 컷 바뀌면 다시 렌더» 알림
[ ] 13 유료 생성: 장면당 1건 · 발주 전 가격 · 잔액 누계 기록
[ ] 14 디렉터 말씀 원문 기록(작업기록 + feedback-log/style)
[ ] 15 납품 폴더를 탐색기로 열었다
```

## 효과음 기술 기준

| 기준 | 값 |
|---|---|
| 맞추는 시각 | 파일 시작이 아니라 **들리는 시각**(어택 −20dB 지점)을 화면 동작에 맞춘다 |
| 밀림 허용 | ±34ms 안(넘으면 큐 시각을 옮긴다) |
| 큐 간격 | 0.12초 이상 |
| 겹칠 때 | 앞 소리를 다음 소리 **들리는 어택 10ms 전**에 끝나게 0.2초 감쇠. 잘려서 0.15초도 안 남으면 큐를 옮긴다 |
| 길이 | 자연 길이(잦아드는 데까지, 최대 약 2.5초). **길이 맞추려 파일을 자르지 않는다 — 더 짧은 파일로 바꾼다**(잘라서 «끊긴다» 반려 이력) |
| 반복 | 바로 연달아 같은 파일 금지 · 쇼츠 한 편 같은 파일 2번까지 (스타일에서 바꿀 수 있음) |
| 크기 | 목소리 대비로 정한다 — 값은 `style/` (없으면 디렉터가 넣어 둔 기존 효과음 볼륨을 재서 맞춘다) |
| 볼륨 읽기 | 프리미어 저장값 **0dB = 0.17783** (1.0 을 0dB 로 읽으면 거꾸로 읽는다) |
| 연타 | 여러 번 치는 소리는 한 파일로 묶어 트랙 하나에 |

## 영상 기술 기준

- **해상도·fps 는 디렉터 시퀀스에서 잰 값**(예: 900×1600 · 59.94). 지어내지 않는다.
- 24/30fps 생성 영상을 59.94 시퀀스에 넣을 땐 보간(`recipes.md` 3장) 후 1배속.
- 짝수 해상도 유지(인코더).
- 손떨림 보정은 **바탕 위주 컷만**, 사람·손 움직임이 큰 컷은 하지 않는다. 보정 뒤 이동량을 재서 좋아졌는지 확인(부호 반대면 두 배가 된다).
- 같은 소스 클립을 한 편에서 두 번 쓰지 않는다(대체 없으면 보고).
