# 실무 레시피 — 실제로 써서 통한 명령과 함정

환경: Windows · ffmpeg/ffprobe · Python 3.11(numpy·Pillow·faster-whisper) · 헤드리스 Chrome(HTML 장면 렌더) · 프리미어.

## 1. 녹음 정리 (휴대폰·현장 녹음 → 깨끗한 나레이션)

순서(이 순서로 통과):
1. 70Hz 고역통과
2. 180Hz 아래만 미리 보는 리미터(파열음 «퍽» 잡기 — 평소 저음은 거의 안 건드리게)
3. 1.5ms 외톨이 고역 바늘 깎기(딸깍) → `adeclick`
4. `afftdn` 약 10dB(바닥 잡음)
5. −14 LUFS · 트루피크 −1.5dB

- 진단 먼저: 말 평균 · 바닥 잡음 · 파열음 의심 지점(200Hz 아래가 평소보다 15~20dB 큰 곳) · 딸깍 의심 지점 → 정리 뒤 같은 표로 비교.
- ★ **함정: `afftdn` 은 소리를 약 1200표본(25ms @48k) 늦춘다**(길이는 같게 끝을 자름). `apad` + `atrim` 으로 당기고, 원본과 상호상관으로 0ms 인지 확인. 확인 못 하면 멈춘다.

## 2. 단어 시각

- faster-whisper(medium · CPU int8) 단어 단위 → 디렉터 컷 조각대로 이어 붙인 시각.
- 자막 글은 받아쓰기가 아니라 **대본·디렉터 타임라인 원문**. 받아쓰기는 시각만 쓴다.
- 오인식은 표 옆에 적는다(전문용어가 자주 틀림).
- ★ 함정: **무음 구간에서 whisper 가 문장을 지어낸다**(«다음 영상에서 만나요»). 무음 클립은 받아쓰기하지 않는다.
- 자막 시작은 말 시작으로 당기고 0.05초 앞세운다.

## 3. 배속 · fps

| 할 일 | 방법 |
|---|---|
| **완성 믹스(목소리+BGM+효과음 섞인 것) 배속, 1.0~1.1배** | `setpts=PTS/R,fps=60000/1001` + **`atempo=R`** + `alimiter`(원본 피크가 0dB 넘으면) |
| 목소리만 따로 있는 트랙 배속 | `rubberband=tempo=R:pitch=1:formant=preserved` 가능 |
| 24/30fps 생성 영상 → 59.94 시퀀스 | `minterpolate=fps=60000/1001` 후 1배속 |

- ★ **함정: 완성 믹스에 rubberband(포먼트 유지)를 걸면 위상이 번져 목소리가 «울리고 두 개가 겹친» 느낌**이 난다(반려 이력). 믹스는 atempo.
- 디렉터 쪽 대안: 프리미어 속도 105/107% + 피치 유지. 캡컷 30fps·4K 업스케일 내보내기는 끊김·흐림(프레임 절반 · 재압축).
- 배속 뒤 확인: 길이 = 원본 ÷ R · LUFS · 피크 · 목소리가 겹쳐 들리면 원본 녹음과 상호상관 피크가 하나인지.

## 4. 프리미어 프로젝트 읽기

- **저장한 뒤** 읽는다. 자동저장본이 더 최신일 수 있다.
- 원본은 열려 있으니 **사본을 `_tmp/` 로** 떠서 읽는다(prproj = gzip XML).
- 읽을 것: 시퀀스 크기·fps · 트랙별 클립 위치/소스 인점 · 모션(비율·위치) · 볼륨 · 자막 글 · 전환 이름.
- 함정:
  - 0초에서 시작하는 클립은 `<Start>` 태그가 없다 → 0.
  - 참조가 `ObjectRef`(숫자)·`ObjectURef`(UID) 두 가지 → 둘 다 따라간다.
  - In/Out 은 `<Clip>` 한 겹 안쪽.
  - 볼륨 0dB = 0.17783.
  - 같은 이름 시퀀스가 여럿이면 아이템 많은 것.
  - 시간 단위: 1초 = 254016000000 틱.
- 읽은 결과를 «어느 저장본(시각) 기준»으로 기록. 디렉터가 다시 저장하면 다시 읽는다.

## 5. 납품 XML («얹을 것만»)

- FCP7 XML(`xmeml`)로 시퀀스 크기·fps 를 디렉터 시퀀스와 같게. **시각은 시퀀스 초 그대로** → 붙여 넣으면 그 자리에 앉는다.
- 트랙 약속(디렉터와 정한다 — 한 예): 화면 전체를 바꾸는 장면 = **V1**(그 구간 사람 클립 자리, 자막 트랙이 저절로 위) · 사람 위에 얹는 그래픽 = **위 트랙(V4 등) 알파** · 효과음 = 디렉터가 안 쓰는 오디오 트랙.
- 알파 영상: ProRes 4444(무겁다 — 디렉터가 렉을 말하면 장수·크기 줄이기).
- 전환 효과(렌즈 블러 등)는 XML 에 못 담는다 → 미리보기에만, XML 엔 마커.
- XML 소리엔 리미터가 없어 미리보기보다 작을 수 있다 → 보고에 적는다.
- 미리보기 mp4 = 디렉터 V1 컷을 모션값대로 재현 + 얹은 층 + 목소리(디렉터 볼륨) + 효과음.
- 검증: XML 이 가리키는 파일 존재 · XML 로 다시 조립한 화면과 미리보기 대조.
- 프리미어에서 실제로 열어 보지 못했으면 «열기는 시험 못 함».

## 6. 화면 렌더 (코드로 그리는 그래픽)

- HTML 장면을 `seek(t)` 하나로 모든 상태가 정해지게 짜고(이전 프레임 상태에 기대지 않음 → 깜빡임 방지), 헤드리스 Chrome 으로 프레임 캡처 → 알파 MOV.
- 사진이 많은 장면은 seek 뒤 그려질 때까지 기다린다(`--settle`).
- CSS `will-change` 금지(캡처에서 깨짐).
- 글자·숫자·로고는 폰트로 그린다(생성 모델에 맡기지 않음). 한글 글꼴 지정.
- 렌더 전 요소끼리·자막 자리 겹침 검사, 렌더 뒤 전체 MOV 에서 프레임 뽑아 확인.

## 7. 이미지 · 유료 영상

- 무료 이미지 도구가 먼저(시안·시작프레임·레퍼런스). 프롬프트는 **자기완결형**(도구는 저장소 사정을 모른다) + 저장 경로 지정 + «후처리 명령 금지».
- 레퍼런스 이미지를 같이 물린다(상상한 이미지는 대부분 반려됐다).
- 유료 영상화: 발주 전 가격 → 디렉터 확인 → 장면당 1건 → 작업 ID·차감·잔액 기록 → 원본(24fps)과 시퀀스 fps 보간본 둘 다 납품 폴더에.
- 영상 모델은 상자·간판 글자를 뭉갠다 → 글자가 주인공인 컷은 실물/렌더러.

## 8. 자료 수집

- 광고 레퍼런스: 광고 라이브러리 검색 → «오래 게재 / 반응 좋은 것»만 → 링크 + 한 줄.
- 공식 SNS 이미지: 스크래퍼로 게시물 목록 → 이미지 내려받기 → 목록 csv + 주의사항 md(효능 문구·지난 행사가가 박힌 것 표시).
- 비용이 드는 API 는 대략 비용 기록. 로그인·비밀번호 입력은 사람이 직접.

## 9. 문서 산출물

- 대본 확인용 워드: 한 대본 = 한 쪽. 기본 문서 격자가 켜져 있으면 한글 글꼴이 줄마다 두 칸을 먹어 두 쪽으로 넘친다 → 격자 끔 · 제목 문단 «쪽 나눔 앞».
- 옮긴 뒤 원문 줄 = 문서 줄 글자 단위 검산.
- 스토리보드 PDF: 컷별 정지 화면 + 표, 방향·«정할 것» 쪽을 앞에.

## 10. 이 PC(Windows) 함정

- 텍스트 파일은 UTF-8(BOM 없음) + LF. PowerShell 스크립트(.ps1)만 BOM 있게.
- Python 은 `python -X utf8`, 콘솔 한글은 `PYTHONIOENCODING=utf-8`.
- **bash heredoc 안 Python 문자열에 Windows 경로를 넣지 않는다** — `\26` 같은 게 8진 이스케이프로 바뀌어 기록이 깨진다. 스크립트 파일 + raw 문자열(`r"…"`).
- 한글·공백 경로는 항상 따옴표.
- 프로세스는 정확한 PID 로만 끈다.
- 파일 삭제는 명시 목록으로(상대 경로 와일드카드 금지).
