# 한 편 워크플로우 — 단계마다 «무엇을 하고 · 무엇을 남기고 · 어디서 멈추나»

디자인 판단(어떤 모양·색·움직임)은 `style/` 몫이다. 이 문서는 순서와 산출물만 정한다.

## P0 접수

| 할 일 | 남기는 곳 |
|---|---|
| 지시 **원문 그대로** 붙이기 | `기록/작업기록.md` 그 건 맨 위 |
| 받은 자료 전부 정독 → **요구 대장**(R1, R2… · 요구 · 원문 위치 · 인용 · 산출물) | 같은 곳 (`templates/요구대장.md`) |
| 문서가 길면 «읽은 범위 표»(파일 · 쪽/시각 · 읽음 ✓) | 같은 곳 |
| 건 정보: 제품·목적·대상·길이·규격(해상도·fps)·원본 위치(**경로만**) | 같은 곳 |
| **사용 허락 범위**: 초상권(모델 사진 어디까지)·음원 라이선스·상표 | 같은 곳 «사용 허락» 칸 |
| **표현 제약**: 효능 표현 가능 여부(식품 유형), 보장 표현, 쓰면 안 되는 문구 | 같은 곳 |

- 디렉터 지시가 없는 구간은 «판단»이라고 적고 판단 내용을 남긴다.
- 원본 폴더(촬영본·디렉터 프로젝트·다운로드)는 **읽기만**. 필요한 건 `소재/` 로 복사.

## P1 대본 → 확인①

1. **쓰기 전에 방향을 여쭌다**: 구조(레퍼런스 식) · 화자 · 분량(초) · 소구(타깃별 여러 안?) · 납품 형식(txt / docx / 한 쪽에 하나).
2. 레퍼런스가 필요하면 **잘된 광고 기준**(오래 게재 · 반응 지표 좋음)으로 8개 안팎 골라 링크 + 한 줄 요약을 문서로.
3. 팩트체크: 상세페이지·공고·분석서 원문에서 쓸 수 있는 사실만 뽑아 **근거 표**(문장 · 근거 · 위치).
4. 초안은 «초안»이라 표시. 길이 어림 = 음절 ÷ 5.5음절/초.
5. 디렉터가 대본을 **직접 고쳐 저장**하면 그 파일이 정본. 작업자 md·화면 표는 옛 대사가 된다 → 덮어쓰지 않고, 바뀐 점과 남은 위험(효능·근거 없는 숫자·띄어쓰기)만 **브리핑**.
6. 디렉터가 «이대로 간다»면 **글자 하나 바꾸지 않는다.** 워드/한글로 옮길 때도 원문 줄 = 문서 줄 검산.
7. 확정되면 `납품/<건>_확정대본_<MMDD>/` 에 글자 그대로 txt.

## P2 소재 · 스토리보드 → 확인②

1. **목소리**: 녹음본이면 정리(`recipes.md` 1장) → 대본 원문에 맞춰 **단어 시각표**(`words.txt`). 받아쓰기 오인식은 표 옆에 적는다.
2. **실촬영 목록**: 클립마다 길이·내용·쓸 수 있는 구간·**상표/개인정보 노출**(가려야 할 것)·흔들림.
3. **컷 배정 표**(스토리보드의 정본 데이터): 컷 번호 · 대사 · 시각 · 클립(구간) · 화면 글 · 효과음 계기 · 비고. 촬영본에 없는 것은 «없음»으로 표시하고 대안(무료 이미지 / 유료 영상 / 다른 컷)을 적는다.
4. 무료 이미지 생성은 **한 세션에 몰아서**. 유료 영상화 후보(시작프레임)도 여기서 2~4장씩.
5. **스토리보드 PDF**: 방향 한 쪽 · «정할 것» 한 쪽(추가 촬영? 모델 이미지 출처? 유료 몇 컷? BGM? 오퍼? 규격?) · 컷별 정지 화면 + 표.
6. 디렉터가 고른 것만 P3 로. 유료는 고른 장면 1건씩.

## P3 제작

- 컷 순서: 디렉터 지시 → 앞뒤 맥락 → 단어 시각 → 화면 확인(그 시각 프레임) → 만들기 → 프레임 확인.
- **디렉터 프로젝트가 있으면 그게 정본**: 저장본을 사본으로 떠서 읽고(`recipes.md` 4장) 컷·길이·자막을 따른다. 디렉터가 다시 저장하면(«타임라인 고쳤어») 새 저장본으로 시각을 다시 맞춘다.
- 디렉터가 «너도 만들어 봐, 나는 나대로»면 작업자 판은 **완성 mp4**(1차·2차…), 디렉터 프리미어 위에 얹으라 하면 **XML 묶음**.
- 스크립트 하나가 그 판의 정본 데이터(CUTS · SUBS · CUES 같은 표)를 갖게 한다 → 수정은 표만 고치고 다시 돌린다.
- 무거운 렌더는 다른 작업과 겹치면 `--workers 1~2`.
- 디렉터가 «렉 걸린다»면 장수·해상도·비트레이트를 줄인다(알파 ProRes 는 무겁다).

## P4 효과음 · 마감

- 효과음은 **컷이 아니라 화면 동작(등장·넘김·찍힘)에** 붙인다.
- 여러 번 연달아 치는 소리는 **한 파일로 묶어** 트랙 하나에(겹침 0, 디렉터가 옮기기 쉬움).
- 어떤 소리를 쓰는지(성격·톤)는 `style/`. 기술 기준(겹침·잘림·음량)은 `verification.md`.
- BGM 은 라이선스부터: 광고(유료 집행)에 쓸 수 있는지 확인된 것만. 출처 모를 «모음» 음원은 알린다.
- 마감 음량 −14 LUFS · 트루피크 −1.5dB.

## P5 검증 · 납품

- `verification.md` 점검표 한 줄씩 → 결과를 보고에.
- 납품 구성(XML 이면): `<묶음>.xml` + `media/`(XML 이 가리키는 소재 전부) + `<건>_XML_미리보기.mp4`. 완성본이면 mp4 하나(+ 필요 시 원본 소재 폴더).
- 같은 판 수정 → 같은 이름 덮어쓰기. 끝나면 **납품 폴더 탐색기로 열기**.

## P6 피드백

- 원문 그대로 기록(작업기록 + feedback-log 또는 style).
- 반려는 컷 번호로 받아 그 컷만. 새 묶음이면 새 판 폴더.
- 디렉터가 고른 시안(«A로 진행»)은 그 이유·원문과 함께 `style/` 에 남긴다.

## 일 나누기 (여러 에이전트를 쓸 때)

| 일 | 누가 |
|---|---|
| 범위·판단·검수·보고·디렉터 대화 | 주 세션이 직접 |
| 이미지 생성 | 무료 이미지 도구 전담(한 번에 하나, 몰아서) |
| 정해진 패턴의 대량 수정·반복 렌더 | 실행 담당 하위 에이전트 → 결과는 주 세션이 프레임 뽑아 검수 |
| 유료 영상화 | 주 세션이 직접, 확인② 뒤 장면당 1건 |

하위 에이전트에게 «맞는지 봐 달라»고 판단을 넘기지 않는다.
