# 작업 방식 피드백 — 디렉터 원문과 거기서 굳은 규칙

«…» 안은 디렉터 원문(맞춤법 그대로, 업체·인물 이름만 ○○). **디자인·분위기 피드백은 여기 넣지 않고 `style/` 에.**
새 피드백은 맨 아래 «이 작업자의 기록»에 `날짜 · 원문 · 바꾼 것` 한 줄로 추가한다.

## 굳은 규칙과 그 원문

| 규칙 | 디렉터 원문 |
|---|---|
| 묻지 말고 만들어 보여 준다. 기존 작업물은 덮지 말고 따로 | «일단 기존꺼는 건들지말고 오픈소스에서 여러가지 효과음 쓸만한거 받아봐» (선택지 질문을 물리심) |
| 열린 지시엔 후보 여러 개를 실제로 | «3개다 시도해봐 각각 버전다르게해서 보여줘» · «시안나오는대로 빠르게보여줘» · «디자인시안 5개정도 내가 고를 수 있게 뽑아봐» |
| 대본만은 쓰기 전에 방향을 묻는다 | «작업시작하기전에 대본부터짤건데 어떻게ㅉ라지물어보고해» |
| 자료는 전부 정독 + 요구 대장 | «진짜 처음붙터 끝까지 다읽고 다 정독해서 해야해 하나라도 빠짐없이 다 대충읽고하면 우리가 10개를 하려는데 7개밖에 모르는 그런상황 절대 일어나면안돼» |
| 요청받은 것만 | «내가 요청한 것만 진행해» |
| 앞뒤 맥락 먼저 | «모든 작업은 무조건 앞뒤 맥락 파악해서 연출하라» |
| 규칙 문서를 매번 다시 연다 | «같은 중복영상이 계속 나옴 — 규칙 누락 현상 심함, 길라잡이 만들 것» |
| 검수는 영상으로, 점검표를 실제로 연다 | «검수는 제대로한건지? 길라잡이는 제대로보고만든건지?» (정지 프레임만 보고 넘겨 떨림·구도 깨짐을 놓침) |
| 납품 폴더를 지우거나 이름 바꾸지 않는다 | (폴더를 지우고 다시 만들어 프리미어 파일이 오프라인 됨) «드론 소리 사라졌다» |
| 문서 개편은 새 판 | «개편사항은 덮어씌우지말고 v2로해서 뽑아줘봐» |
| 작업 끝나면 폴더를 연다 | «아니 작업 끝나면 항상 폴더 열어 줘» |
| 유료 생성은 장면당 1건 | 같은 장면 여러 개 뽑아 고르는 건 «확정적으로 한 건분을 버리는 낭비» |
| 청음본·A/B 듣기를 먼저 요청하지 않는다 | «청음본 들을 시간이없어 너모 오래걸려 그냥 실 사용에서 하고, 받아서 네가 따로 정리해» |
| 디렉터가 고친 대본은 글자 그대로, 멋대로 고치지 않는다 | «멋대로 대본 수정하지마» · «아니 그냥 이대로 컨펌받을거야 메모장에 적혀있는걸로» |
| 디렉터 파일 저장 기록을 확인하고 진행 | «저장한거 기록 확인해서진행해» |
| 디렉터 프로젝트가 정본 — 그 클립으로 시각 파악 | «타임라인은 지금 프리미어 클립으로 파악하고» |
| 기존 피드백 이력을 먼저 확인하고 브리핑 | «임의로 제작하지말고 기존 작업들로그확인해서 내가 원했던 피드백줬던 방향확인하고 어떤식으로할지 먼저 브리핑진행» |
| 컷마다 설계를 스토리보드 PDF 로 | «각 연출컷마다 어떻게 진행할건지 설계해서 스토리보드형태로 나한테 보여줘 pdf로» |
| 실촬영에 있으면 실촬영, AI 인물 금지(지시가 없으면) | «AI인물없이 썼으면 좋겠는데 인물은» · «요거트 이부분도 영상에있잖아» |
| 이미지 생성 범위는 디렉터가 정한 곳만 | «○○쪽제외하는 이미지생성X» |
| 효능 표현 금지(식품 유형에 따라) | 광고주 «효능은 제외하는 방향으로 대본 작성 요청 드립니다.» |
| 모델 사진은 공식 콘텐츠만, 주의사항 확인 | «홈페이지나 인스타에서 쓰면되는데 거기서 주의사항줬던거 가지고있어? 있으면 그 주의사항에 맞춰서 진행» |
| 렉 걸리면 개수·크기를 줄인다 | «6개만 넣자 지금 너무 렉걸린다» |
| 완성 믹스 배속은 atempo | «목소리가 왜이렇게 울리고 중복되는느낌이지?» (rubberband 위상 번짐) |
| 효과음을 잘라서 맞추지 않는다 | «효과음 또 짧게 끊기고» · «효과음이 끊기는 느낌이 너무 많이들어» |
| 효과음끼리 겹치거나 밀리지 않게 | «겹치거나 밀려서 나오는거 조정해서 깔끔하고 자연스럽게» |
| 정한 건 바로 파일로, 세션이 바뀌어도 이어지게 | «오토컴팩트 진행되더라도 길라잡이 누락되지 않게끔 장치 만들어서 적용» |
| 충돌·병목은 스스로 정리 | «여태까지 한 작업 학습해야할 부분은 다 학습해서 정리하고 충돌 병목현상은 스스로 정리해» |
| 두 세션이 같은 폴더면 따로 폴더 | «저 세션이랑 충돌 , 병목현상 일어나지않게 독립적인 폴더로해서 작업할거야 겹치지않게 해줘» |

## 실패에서 배운 것 (원인 → 해결)

| 실패 | 원인 | 해결 |
|---|---|---|
| 프리미어 클립 오프라인 | 납품 폴더를 지우고 다시 만듦 | 제자리 덮어쓰기만 |
| 자막 스타일 틀림 · 떨림 놓침 | 확정 문서·점검표를 다시 안 열고 정지 프레임만 봄 | 납품 직전 점검표 실제로 열기 + 전체 영상 보기 |
| 배속본 목소리 두 겹 | 믹스 전체에 rubberband 포먼트 유지 | atempo |
| 녹음 25ms 밀림 | afftdn 지연 | apad+atrim 보정 + 상호상관 확인 |
| 받아쓰기에 없는 문장 | 무음 클립에서 whisper 환각 | 무음 클립 제외 |
| 기록 글자 깨짐 | heredoc 안 Windows 경로가 8진 이스케이프 | 스크립트 파일 + raw 문자열 |
| 손떨림 보정 후 더 흔들림 | 흰 바탕 vidstab 튐 · 보정 부호 반대 · 크기 다른 캐시 재사용 | 바탕 위주 컷만 · 보정 후 이동량 재기 · 캐시 이름에 크기 |
| 미리보기 화면 갈라짐 | 1080×1920 보간본을 1916 으로 읽음 | 소스 해상도를 ffprobe 로 매번 읽기 |
| 세션 재개 때 규칙이 앞 2KB 만 들어감 | 재개 안내 출력이 너무 김 | «지금 상태»는 짧게, 세부는 아래 절로 |
| 장면 도구끼리 변수를 빌려 쓰다 엉킴 | 남의 스크립트를 import 해 덮어씀 | 공용 모듈 하나로 떼고, 장면 도구끼리 import 금지 |
