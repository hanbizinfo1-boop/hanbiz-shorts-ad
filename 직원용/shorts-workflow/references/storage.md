# 저장 — 폴더 · 이름 · 판 · 기록

## 1. 폴더 (작업 폴더 하나 안에서만)

| 폴더 | 무엇 | 규칙 |
|---|---|---|
| `기록/작업기록.md` | 지금 상태 · 건별 이력 · 디렉터 원문 · 결정 · 수치 | 최신이 위. «지금 상태»는 짧게(세션 재개 때 통째로 읽힌다) |
| `납품/` | 디렉터에게 드린 것 | **지우지 않는다 · 이름 바꾸지 않는다** |
| `소재/<건>/` | 원본 사본 · 생성 이미지 · 효과음 묶음 · 크롤링 자료 | 출처를 `출처.md`/`_주의사항.md` 에 |
| `tools/` | 스크립트 | `_tmp` 에 두지 않는다. 판마다 정본 데이터(표)를 스크립트 맨 위에 |
| `_tmp/` | 중간 렌더 · 프로젝트 사본 · 단어 시각 | 다시 만들 수 있는 것만. 버전관리 제외 |

- 원본(촬영본·디렉터 프로젝트·다운로드)은 **경로만** 기록하고 읽기만 한다.
- 영상·대용량은 버전관리(git)에 넣지 않는다. 넣는 것: 대본·기록·스크립트·문서.
- 커밋·푸시는 요청받을 때만.

## 2. 납품 폴더 이름

```
납품/<건>_<내용>_<판>_<MMDD>/<건>_<내용>_<판>.<확장자>
예) 납품/제품A_육아_1차_1026/제품A_육아_1차.mp4
    납품/제품A_육아_XML_1026/1_매거진/1_매거진.xml + media/
    납품/제품A_대본_부모님선물_v7_1023/
    납품/제품A_배속_1026/제품A_완성_1.05배.mp4
```

## 3. 판 나누기 — 덮어쓸까, 새로 만들까

| 상황 | 어떻게 |
|---|---|
| 같은 판을 고치는 중의 지적(소리 끊김·오탈자·위치 조금) | **같은 폴더 · 같은 이름 제자리 덮어쓰기** |
| 디렉터 피드백 한 묶음(방향·구성이 바뀜) | **새 폴더** `…_2차_MMDD`, 파일 이름 규칙은 같게 |
| 디렉터가 «V3로»처럼 새 판을 말함 | 새 폴더 |
| 문서(대본) 내용 개편 | `_v2` 새 폴더 + 파일 끝 `_v2` |
| 디렉터가 직접 고친 파일 | **그게 정본.** 작업자가 덮어쓰지 않는다 |
| 프리미어가 잡고 있어 안 써지는 파일 | `_새판` 이름으로 쓰고 XML 이 그걸 가리키게 → 보고에 알림 |
| 같은 판 수정인데 실패작 사본을 남기고 싶을 때 | `_tmp/` 로(납품 폴더에 `_old` 를 늘어놓지 않는다) |

**왜**: 디렉터는 받은 파일을 바로 프리미어에 넣어 쓴다. 폴더를 지우고 다시 만들거나 이름을 바꾸면 타임라인 클립이 오프라인이 된다. 같은 경로 파일이 바뀌면 프리미어는 다음에 열 때 자동 갱신하고 편집은 그대로 남는다.

## 4. 반려된 옛 판 정리

- 평소엔 지우지 않는다.
- 디렉터가 «정리해»라고 하면 보관 장소(예: 다른 드라이브 `폐기/<건>_<날짜>/`)로 **원래 구조 그대로 옮긴다**.
- 옮기기 전 **지금 판이 그 파일을 참조하는지 검색**한다. 참조하면 `소재/` 로 복사하고 경로를 바꾼 뒤 옮긴다.
- 삭제는 정확한 목록으로(와일드카드 금지), 지우기 전에 대상을 본다.

## 5. 기록 — 무엇을 어떻게

`기록/작업기록.md` 한 건의 줄 (`templates/작업기록.md`):
- 디렉터 말씀 **원문 그대로** («…» 안은 맞춤법 포함 그대로) → 그래서 한 것 → 산출물 경로 → 검증 수치 → 남은 것.
- 정하지 않은 질문을 기본값으로 진행했으면 «기본값: …»을 적는다.
- 유료 생성: 발주 전 가격 · 작업 ID · 차감 · **잔액 누계**.
- 디렉터 프로젝트 기준이면 «어느 저장본(시각)» 기준인지.
- 실패·함정(원인과 해결)도 적는다 — 다음 사람이 같은 데 안 빠지게.
- 귀로 못 들은 것, 시험 못 한 것.

피드백 원문은 두 곳에: 작업기록(그 건) + `references/feedback-log.md`(작업 방식) 또는 `style/`(디자인·분위기).

## 6. 출처 · 정보 취급

- 이미지·영상 출처(공식 계정·상세페이지·직접 생성·라이브러리)를 소재 폴더에 기록.
- 모델(유명인) 사진: **브랜드 공식 콘텐츠만**. 본인 개인 계정 사진은 다른 브랜드가 보이면 쓰기 전에 확인.
- 문구가 박힌 공식 이미지는 효능·행사가 문구 **밖으로 잘라** 쓴다.
- 업체명·전화번호·계정 ID·고객 개인정보는 기록에도 넣지 않는다(○○ · 010-0000-0000).
- 촬영본 속 타사 상표(우유팩·포장 등)는 가리거나 다른 컷으로.
- 크롤링·유료 API 비용도 기록(얼마 썼는지).
