# 직원용 시작하기 — 이 저장소만 보고 같은 퀄리티로 쇼츠 광고 만들기

한비즈에서 Claude Code 로 세로 쇼츠 광고를 만들어 온 **방법 전부**를 숨김 없이 공개한다.
노하우(스킬 문서) · 도구(파이썬 코드) · 실제 작업 기록(사장님 원문 피드백 포함) · 실패와 해결이 전부 들어 있다.

> 읽는 순서: **이 파일 → `../CLAUDE.md` → `../.claude/skills/shorts-ad/SKILL.md` → `../지시작업/길라잡이.md` → `../지시작업/기록/작업기록.md`(실제 사례)**

## 2. 설치 (새 PC)

1. **Claude Code** 설치 → 이 저장소를 clone → 저장소 폴더에서 `claude` 실행.
2. **Python 3.11** + `pip install numpy pillow faster-whisper opencv-python` (faster-whisper 는 CPU `int8` · `medium`).
3. **ffmpeg / ffprobe** PATH 에.
4. **Google Chrome**(HTML 장면 렌더 · 레이어 PNG).
5. **Premiere Pro**(사장님 편집본 · XML 열기). 프로젝트 읽기는 프리미어 없이도 된다(`tools/read_prproj.py`).
6. (선택) **After Effects 2026** — 애펙 장면(`tools/ae_scene.py`).
7. **Codex CLI**(무료 이미지 생성 통로 — 구독 한도 안):
   - `npm i -g @openai/codex` → `codex login`
   - `직원용/외부설정/scripts/codex-run.ps1` → `C:\Users\<나>\.claude\scripts\codex-run.ps1`
8. **하위 에이전트**: `직원용/외부설정/agents/*.md` → `C:\Users\<나>\.claude\agents\` · 공통 규칙 `global-CLAUDE.md` → `C:\Users\<나>\.claude\CLAUDE.md`. Claude Code 재시작.
9. **유료 생성 MCP**(힉스필드 등) — claude.ai 커넥터로 연결. 호출마다 돈이 나간다.
10. **글꼴**: `소재/fonts/출처.md` 의 URL 에서 받기(파일은 git 제외). 경로 `tools/config.py` `FONTS`.
11. **효과음 라이브러리**: 등급별 zip `한비즈_효과음_등급별.zip`(1,005개 · 350MB — A★ 사장님 사용 / A / B / C / 장면음 / 미등급)을 **사내 공유 드라이브 링크**에서 받는다(라이선스상 공개 저장소에 못 올림 — Mixkit·効果音ラボ 소재 단독 재배포 금지, **외부 공유 금지**). 풀고 환경변수 `HANBIZ_SFX_LIB` 를 그 폴더로. 다시 묶기 `python -X utf8 tools/sfx_pack.py <출력.zip>`. 출처 `소재/효과음-출처.md`, Mixkit BGM 은 `소재/BGM후보/라이선스.md`.
12. 경로가 다르면 `tools/config.py` 한 곳만 고치거나 환경변수로 덮어쓴다.

## 3. 실행법 — 실제로 이렇게 시킨다

Claude Code 에 한국어로 지시한다. 스킬이 자동으로 불린다.

| 하고 싶은 것 | 이렇게 말한다 | 나오는 것 |
|---|---|---|
| 레퍼런스 찾기 | «이 제품으로 메타 광고 레퍼런스 8개, 오래 게재된 것만» | 링크 + 한 줄 요약 md |
| 대본 | «육아맘 타겟으로 레퍼런스 2번 식 대본» (먼저 방향을 되묻는다) | 대본 txt + 화면 표 md |
| 녹음 정리 | «D:\…\녹음.MP3 잡음·파열음 잡아줘» | 같은 길이 정리 wav (`지시작업/tools/vo_clean.py`) |
| 스토리보드 | «연출표대로 컷마다 어떻게 할지 스토리보드 PDF» | 컷별 정지 화면 + 표 PDF |
| 완성 편집 | «실촬영은 여기, 그대로 한번 만들어봐» | 1080×1920 · 59.94 완성 mp4 |
| 프리미어 위에 얹기 | «프리미어 저장했어, 13초 구간 매거진 느낌 XML 로» | XML + media/ + 미리보기 mp4 |
| 시안 | «디자인 시안 5개 뽑아봐» | 실제 컷 위 시안 이미지 5장 |
| 배속 | «완성본 1.07배속, 피치 유지» | atempo 판 mp4 |
| 효과음 | «효과음 깔아줘, 고급스럽게» | 효과음 묶음 + 점검 결과 |

주요 명령(직접 돌릴 때) — 상세는 `지시작업/길라잡이.md` 3장:
```
python tools/read_prproj.py <prproj 사본> <시퀀스> 지시작업/_tmp/story/seq.json     # 사장님 편집 읽기
python tools/words.py --src <영상> --seg 시작,끝,원본시작 --out _tmp/words.txt          # 단어 시각
python tools/html_motion.py <장면.html> --alpha --settle --fps 59.94 --workers 2 --out <폴더> --name <이름>   # 코드 그래픽 → 알파 MOV
python tools/rule_check.py --copy <대본.txt>                                          # 광고 문구 점검
python tools/sfx_audit.py --place <배치.json> --cue <큐.json>                          # 효과음 겹침·밀림
python 지시작업/tools/vo_clean.py · vo_audit.py                                         # 녹음 정리 · 진단
python 지시작업/tools/pureva_build.py · pv_xml_build.py · pureva_storyboard.py           # 실제 건 본보기(완성편 · XML · 스토리보드)
```

## 4. 사장님이 원하는 연출 — 반려에서 굳은 것 (원문은 feedback-log)

**영상**
- **첫 3초는 무조건 사람 얼굴.** 후킹 그래픽은 자막 밑에.
- **구도는 «그 말이 실제로 일어나는 자리».** 통과한 틀을 복붙하지 않는다. 비교 연출을 연달아 쓰지 않는다.
- **말의 결과를 보여 준다.** «45채 사 봤다» = 건물 사진, «지었다» = 설계도 → 층이 차오름 → 완공.
- **덩그러니·일정 속도·정지 금지.** 사물은 실제 장소 안에 세우고, 움직임은 강약(느림 → 빠름 → 살짝 넘침 → 섬), 멈춘 사진도 천천히 흐르게.
- **도형 짜깁기 금지.** 그림은 실촬영 · 실제 이미지 · 무료 생성 이미지. 도형으로 사물 흉내 내지 않는다.
- **실촬영에 있으면 실촬영.** AI 인물은 쓰지 않는다(지시 없으면). AI 이미지는 촬영본에 정말 없는 것만.
- **글자·로고·숫자가 주인공인 컷은 폰트로 그린다**(영상 모델은 글자를 뭉갠다).
- **인지할 텀 0.6초** — 새 요소는 혼자 0.6초 이상. 급하면 «정신없다» 반려.
- **영상미**: 등장 4~8프레임 감속 · 튕김 없음 · 핵심어 하나만 강조색 · 장면 3색 · 모티프 하나.
- **밝은 바탕 위 글자는 어두운 알약·상자 안에.** 판·카드는 불투명(구멍 없이) · 모서리 12~14.
- **사진 몽타주**: 1초에 4장은 뭔지 모른다 → 넘긴 장은 작은 카드로 남긴다. 모델 화보는 «큰 몇 장»보다 «다양한 여러 장» + 마지막 장은 확실히 당겨 들어감.
- **고급 톤(식품·뷰티)**: 매거진 타이포(세리프 큰 숫자 · 얇은 선 · 작은 영문 캡션 · 상자 없음).

**자막**
- 설명형 쇼츠 = **A2 스타일**(회색빛 불투명 띠 (52,52,56) · 여백 26/14px · 모서리 12) · 숫자 초록 · 강조 노랑 · 팝 130→100% 0.216초 · 머무는 동안 키우지 않는다(떨림).
- 자막 글은 받아쓰기가 아니라 **대본·사장님 타임라인 원문**. 단어 시작 순간에 맞춘다.

**효과음**
- 효과음은 컷이 아니라 **화면 동작**에 붙인다.
- **자연 길이, 자르지 않는다**(끊기면 더 짧은 파일로) · 효과음끼리 겹침 0 · 들리는 시각을 화면에 맞춤.
- 크기(목소리 대비): 타격 −2 · 휙 −5 · 작은 소리 −7dB.
- 한 편에 같은 파일 2번까지. 음정 톤(마림바·실로폰·차임·«치링») 금지.
- **사진 장면은 셔터·종이 소리.** 고급 톤은 종이·셔터·공기·부드러운 타격만.
- 청음본을 먼저 들려 달라고 하지 않는다 — 실제 편에 넣어 반응을 받는다.

**문구**
- 쉬운 말 · 한 문장에 숫자 하나 · 시청자에게 계산시키지 않는다 · 숫자는 근거 있는 것만.
- 식품(고형차 등)은 **효능 표현 금지**. 보장·대행 표현 금지.
- 사장님이 고친 대본은 **글자 하나 바꾸지 않는다.**

## 5. 일하는 방식 — 이렇게 해야 반려가 안 난다

1. **자료는 처음부터 끝까지 정독** + 요구 대장(요구 하나에 번호 하나).
2. **앞뒤 맥락 먼저**(앞 30초·뒤 15초).
3. **묻지 말고 만들어 보여 준다.** 열린 지시엔 후보 2~5개를 실제로. 묻는 건 대본 방향 · 유료 생성 · 되돌릴 수 없는 일뿐.
4. **사장님 프리미어 저장본이 정본.** 사본을 떠서 읽고, 다시 저장하시면 다시 읽는다.
5. **납품은 같은 이름 제자리 덮어쓰기**(이미 프리미어에 들어가 있다). 새 피드백 묶음은 새 폴더. 폴더 지우기·이름 바꾸기 금지.
6. **작업이 끝나면 납품 폴더를 탐색기로 연다.**
7. **말씀은 원문 그대로 기록**(작업기록 + feedback-log). 규칙이 되면 규칙 한 줄 + 점검표 한 줄.
8. **검증은 영상으로.** 정지 프레임만 보고 «됐다» 하지 않는다. 귀로 못 들었으면 «못 들었다».

## 6. 주의사항

- **돈**: 유료 영상화(힉스필드·Kling)는 호출마다 과금 → **장면당 1건**, 발주 전 가격 확인, 잔액 기록. 이미지는 Codex(무료)로 먼저. Kling 은 settings 에서 막혀 있다.
- **원본은 읽기만**: 촬영본·사장님 프로젝트·다운로드 폴더는 수정하지 않는다.
- **정보**: 새 작업에서 업체명은 ○○, 번호는 010-0000-0000. 타사 상표는 가린다. 모델 사진은 브랜드 공식 콘텐츠만.
- **음원 라이선스**: 유료 광고에 쓰는 BGM 은 라이선스 확인된 것만(Mixkit 등). 유튜브 모음 음원 금지.
- **배속**: 완성 믹스는 `atempo`. `rubberband` 를 믹스에 걸면 목소리가 두 겹으로 울린다.
- **녹음 정리**: `afftdn` 이 25ms 늦춘다 → 보정 필수(`vo_clean.py` 가 한다).
- **받아쓰기**: 무음 구간에서 whisper 가 문장을 지어낸다.
- **Windows**: 텍스트는 UTF-8(BOM 없음)+LF, `.ps1` 만 BOM. `python -X utf8`. bash heredoc 안 파이썬 문자열에 Windows 경로 금지(8진 이스케이프). 한글 경로는 따옴표.
- **렌더**: 무거우면 `--workers 1~2`. 알파 ProRes 는 무거워서 프리미어가 렉 걸리면 장수·크기를 줄인다.
- **커밋**: Claude 는 시킬 때만 커밋한다. 강제 푸시는 막혀 있다.

## 7. 실제 사례로 배우기

`지시작업/기록/작업기록.md` 에 건마다 «사장님 원문 → 한 것 → 납품 경로 → 검증 수치 → 반려 → 고친 것»이 순서대로 있다.
- **퓨레바(식품 메타 광고)**: 레퍼런스 → 대본 3종 → 확정 → 녹음 정리 → 스토리보드 → 1~3차 완성편 → 힉스필드 2컷 → 매거진 XML → 시안 5안 → 배속.
- **한비즈 4번·7번(사람 위 연출)**: 사장님 프리미어 위에 장면을 하나씩 XML 로.
- **DB 광고 메타v2**: 한 편 조립(배치표 → 미리보기 → XML).
